# Experiment execution

Before fitting, freeze the question, candidate/control recipe, independently trained parent/source identities, coefficient arithmetic, clipping order, masks/weights, seed pairs, optimizer/sampler, update budget, checkpoint endpoint and served blend. Declare deviations from the reference recipe. Changed assumptions create a new attempt; retain the original.

Run the cheapest discriminating correctness/resource check, then the bounded fit. Scope checks to the actual arm. A homogeneous distillation control must not require unused heterogeneous-family caches. A cloud input failure must not prevent an independently valid local arm from proceeding. Preserve necessary data-membership and resource checks on every route.

Local jobs share the persistent campaign cgroup and single GPU lock. Observe aggregate memory including page cache, actualGPUmemory, exit status andOOM counters. Profile representative shapes before scaling. Use zero loader workers initially and streamed/memmapped caches. Account for simultaneous agents, notebooks and support tools. Diagnose a killed job and run a corrected attempt with a new ID; do not rerun successful science for cosmetic receipt cleanup.

Kaggle has separate headroom. Record actual mounted inputs, device, live quota, code/data hashes and phase heartbeat. Persist expected and observed identity before raising an error. Provider startup and terminal-output collection are part of ownership. A provider's RUNNING label does not prove training started; execution timeouts are not reliable elapsed deadlines from push. Reconcile provisional quota with terminal usage. Repair infrastructure autonomously within the user's authorization.

For data identity, hash the same byte ranges and representation as the producer. If physical encoding differs, establish logical dataset identity before changing the declared input; never suppress a mismatch without an explanation and evidence. Teacher caches bind producer checkpoints, row/group order, split membership, dtype/shape, finite values and actual array bytes.

Evaluate the frozen predictions against the declared reference. Preserve per-seed effects and fixed-model evaluation uncertainty separately. Exposed folds remain exposed; a local gain does not promise public transfer. Evaluate weak candidates' contributions to explicit blends/teacher combinations where scientifically useful.

Save human-readable notes, machine-readable manifests/results and plots in the lineage directory. Use marimo-pair for EDA without reactive fits. Update the frontier, tree/index and current-state specification after meaningful results. Commit/push contract, implementation, results and packaging as distinct reviewable steps.
