# ADR-0003: Diversify sources, models and roles

Status: Accepted. Date: 2026-10-07.

## Context and evidence

The user requested different coding agents/LLMs, random and directed literature, and attempts to transfer small usable components rather than dismissing whole papers. External provider access has sometimes failed; actual model use must remain auditable.

## Decision

Commit independent proposals before cross-sharing. Assign different literature passages and creativity lenses, record selection/provenance, and ask for testable transferable components including unconventional ones. Use a different implementation/criticism method when possible. Honor native Luna/max and actual authorized external routes. [Specification](../idea-generation.md).

## Alternatives and consequences

Many identical agents can agree on one blind spot. Diversity requires context/source/method changes, not model labels alone. Provider failure can consume time; bounded access checks and honest fallback preserve the leading experiment's path to results.

## Revisit when

Provider availability changes, the user changes model preferences, or proposals become semantic duplicates despite diverse sources.
