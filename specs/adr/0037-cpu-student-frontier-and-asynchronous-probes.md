# ADR0037: CPU student frontier and asynchronous public probes

Status: Accepted, 2026-10-14 Europe/Kyiv. Basis: the user's complete implementation plan and subsequent instruction to save all of it, continue theory and nonblocking work while CPU probe uploads are delayed.

## Decision

Execute the [complete plan](../../research/campaign_2026-10-14/cpu_student_frontier_r1/PLAN.md) under its [contract](../../research/campaign_2026-10-14/cpu_student_frontier_r1/CONTRACT.json). Select students by quality and measured complete-callback cost, targeting50–55minutes on the competition CPU. Preserve original xteam_h4 weights, coefficients, preprocessing and quantization for A/B/C/D engine probes. Require complete-sequence bit parity for exact optimization claims; changed arithmetic is a numerical treatment.

Prepare ordered checked CPU ZIPs for the user. Target-host uploads are asynchronous and never gate local architecture, initializer, teacher or theory work. Shared daily slots and target-host capacity remain unverified until actual portal receipts. No elapsed-time-dependent predictions or public-score-based blend optimization.

The eight-shape F0seed3 ladder uses a fixed clean teacher cohort, normalization, data exposure, update budget and checkpoint rule. Advance useful candidates across seed4, F3 and then all four source-qualified folds. Existing folds remain exposed. Preserve uncertain exploratory arms where informative.

For new admissions, this plan explicitly reinstates5decimalGB observed local VRAM, one GPU worker,5CPU cores,17GB committed memory target,18/20GB memory limits and zero swap. This supersedes the actual-device-memory-only wording in ADR0034/0036 for this campaign. Use renewable Kaggle quota after fresh checks, without new paid capacity. At most three subordinate Luna/max roles.

## Consequences

Keep A/B/C/D engine equivalence separate from architecture-quality selection and precision changes. Root owns actual fits, exports, grades, packages, quota recovery and collection. The CPU target remains provisional without competition evidence. Final recommendations require measured reasons and clean ancestry; missing public feedback does not prevent useful local research or checked packaging.
