# Legacy writeups path

The files formerly collected here mixed external source material, generated ideas, an operational comment log, and an internal strategy review. Their canonical locations are now:

- External competition writeups and transcripts: [`research/unified/sources/`](../research/unified/sources/README.md)
- Generated transfer ideas: [`research/unified/ideas/`](../research/unified/ideas/README.md)
- Internal strategy review: [`research/unified/reviews/`](../research/unified/reviews/README.md)
- Controller commentary: [`research/unified/operations/legacy/`](../research/unified/operations/legacy/README.md)

The old individual filenames remain as symlinks so historical citations and scripts continue to resolve. Add new source material to the research tree rather than this compatibility directory.
