# Independent proposal: representation and training mechanisms

Prepared before reading the independent EDA or reconstruction agents' reports. These are proposals, not measured score gains. Official evaluation is clipped Global Weighted Pearson on `need_prediction & is_scored`; compare every arm to fold-matched, component-excluded, fixed-epoch since/since controls on identical rows. The public incumbent is user-reported 0.6622. A local +0.0005 screen by itself cannot support an expected public 0.6660.

## Prior evidence that constrains these proposals

- The repeated class-3 target is mostly a future quote-event outcome, and early break direction is weakly observable. This limits causal headroom on long quiet visits: `research/panel/physicist.md` F3-F4; E-013, E-162, E-238.
- A first-order event Markov kernel distorted the scorer-weighted moments (E-253). A future quote-path auxiliary lost (E-251). Outcome-code cross entropy lost to weighted MSE (E-071/E-072). The target law is not safely invertible to a visible spread in classes 0-2 (E-073/E-074).
- In-context Markov transition features, an extra event-clock GRU, and post hoc causal calibration failed (E-014, E-056, E-160). Episode **reweighting** failed (E-212). A different merged GRU failed against the public member pair on asymmetric stored predictions (E-269).
- Train and validation source distributions differ sharply (E-094/E-231). This gives an input-representation hypothesis a reason to exist, but also makes a validation-only gain suspect.

These candidate mechanisms are distinct from a wider GRU, generic output calibration, and extra blend members. Costs below are incremental estimates, not reserved allocations. Only one GPU job may run at a time and the shared 8 GPU-hour cap still applies.

## I-01. Train-only feature gauge augmentation

**Representation change and mechanism.** Identify low-dimensional directions of *between-sequence* raw price-code offsets that leave within-sequence event differences approximately unchanged. Perturb the price-code baseline of a whole training sequence along such directions, consistently across every row. The prediction target concerns future movement, so a true absolute-level gauge should leave it unchanged. The network may then rely more on causal changes and less on source-specific code means. Keep ordinary raw levels at inference. This is an augmentation experiment, not the already negative online z-score or a post hoc correction.

**Assumptions and cheap falsifier.** Fit gauge directions from feature-only fit chains. Before training, test that translated codes remain on the observed code manifold by comparing transition-class frequencies, nearest-code distance, and a held-out feature-only discriminator. Reject if off-manifold distance rises substantially or if inferred gauge directions correlate with quote-event delta directions. Freeze one perturbation scale from the fit split. Do not use eval-chain features to fit the directions. A negative control perturbs arbitrary covariance-matched directions; a second control uses the same optimizer, noise power, and update count but no coherent per-sequence shift.

**Score gate.** One fold/seed matched parent versus coherent-gauge and arbitrary-gauge arms. Exact paired Global WP must rise >=0.0005, the coherent arm must beat arbitrary noise, and the least train-like chain slice must carry a nonnegative gain. Then freeze and check other folds; no class can lose more than 0.0005. If either arbitrary noise works equally well or the gain appears only on source-like chains, reject the claimed mechanism. **Cost:** feature-only screen <10 CPU-min; training roughly one matched parent fit per arm; inference unchanged. **Risk:** anonymized price codes may encode economically meaningful level information, so the supposed gauge may not be a symmetry. **Priority:** medium, contingent on feature-only screen.

## I-02. Label-free quote-event coordinate, then economic event tokens

**Representation change and mechanism.** Factor i0 price-code event differences into a small discrete transition lattice without reading targets. Orient the latent axes using code recurrence and feasible bid/ask-spread paths, with any final axis sign/scale determined only on fit labels. Keep a short causal stream of inferred bid/ask displacement and price-keyed liquidity updates, then expose it to a small residual encoder. This targets the ambiguity between a volume slot changing because the queue changed and a slot changing because rank shifted. The event token is a causal sufficient-statistic candidate, not a target reconstruction.

**Assumptions and cheap falsifier.** On fit sequences, build the lattice from feature-only event deltas. Freeze it, then count held-out transition coverage, loop-closure error, and impossible spread-path frequency on component-excluded eval sequences **without looking at targets**. Compare a price-keyed volume-update token to matched raw slot deltas and to a deliberately rank-transported token. If the event grammar cannot be identified feature-only, stop; a move table obtained from target jumps would not validate this claim. Only after passing this stage, train a matched residual encoder, evaluate exact Global WP, and require >=0.0005 paired gain over raw-delta control on the same budget.

**Novelty and caveat.** The existing `wnn.ticks.learn_moves` and `learn_spreads` infer moves/spread from target jumps; they cannot establish the feature-only coordinate needed here. The existing simple i1 decoder also loses transition coverage (E-191). A queue-reactive interpretation is motivated by [Huang, Lehalle and Rosenbaum's model](https://arxiv.org/abs/1312.0563), but that paper does not validate these anonymized features. **Cost:** CPU lattice/geometry stage tens of minutes; GPU only if it passes; streaming event state likely a few dozen floats and modest CPU overhead. **Risk:** coordinate non-identifiability or class-specific encoders. **Priority:** medium-high for information value, low prior for a large score gain.

## I-03. Cross-member conditional residual after shared-subspace removal

**Representation change and mechanism.** Use the two frozen incumbent-analogue hidden states jointly, but first estimate their common low-rank subspace on *fit-chain states only*. A zero-initialized rank-8 cross product of the two **residual** states predicts a small correction to their fixed average. This isolates information present only when one member's state qualifies the other's evidence. It is a stricter version of the campaign's C-H01 bilinear head; it does not presume that raw hidden coordinates are aligned between seeds.

**Matched falsifier.** Save hidden states and two predictions from the clean fold-matched since/since pair. Fit on training chains with the same number of updates: (a) cross-product residual; (b) rank/parameter-matched unary nonlinear terms; (c) output-only correction; (d) unchanged mean. Regularization and early stopping come from inner fit chains only; freeze checkpoint before outer scoring. Require the cross product to beat **both** unary and output-only controls by >=0.0005 on exact Global WP, not merely direction AUC. Also record out-of-domain chain slices. If benefit vanishes after removing shared state, the claimed interaction is unsupported. **Cost:** hidden dump GPU-forward only, then small CPU/GPU head fits; inference extra rank-8 projections and products per row, low runtime relative to two backbones. **Risk:** correlated seeds may have almost no conditional information, and a flexible head can fit chain identity. **Priority:** high because it directly tests whether the two paid-for models discard complementary state.

## I-04. Content retrieval tied to *event identity*, not row age

**Representation change and mechanism.** Keep a 16- or 32-token ring of prior i0 quote-event embeddings. Query by current price/volume-code similarity and retrieve a signed event response. A content key may find prior returns to the same book configuration after many rows; a GRU and fixed lag kernel compress these visits. This refines campaign C-H02 by defining the key around recurrent **event identity**, not a generic learned attention query.

**Cheap falsifier and controls.** Before training, measure feature-only recurrence of quote-event neighborhoods on fit versus component-excluded eval chains. Reject if repeated neighborhoods are too rare or transport poorly. Then compare content retrieval with (a) matched position-only kernel, (b) last-event token, and (c) shuffled keys preserving age and token values. Under equal parameters/FLOPs/updates, require >=0.0005 exact paired Global WP beyond the best control and robust sign across source-likeness slices. No token may contain future events, labels, mask values, or residuals. [Contrastive predictive coding](https://arxiv.org/abs/1807.03748) motivates state representations but is not evidence of score transfer here. **Cost:** feature-only CPU screen, one GPU arm if viable; online 16-32 token lookup per row may add several microseconds and must be timed on one vCPU. **Risk:** recurrent codes may reflect a seasonality already captured by the GRU; prior event-clock and simple lag corrections were negative. **Priority:** medium after the recurrence check.

## I-05. Importance-preserving episode-balanced optimizer schedule

**Training change and mechanism.** Draw training chunks from different chains and target-constant episodes per optimizer step while keeping each row's **expected** clipped `|y|`/propensity contribution to the original weighted MSE exactly unchanged. Use inverse sampling probabilities in the loss and the same 32-sequence batch, number of row forwards, updates, scheduler, and checkpoint epoch. The intent is to reduce gradient covariance from repeatedly showing the same future outcome, not to change the target distribution. This differs from E-212's inverse-sqrt episode *reweighting*, which changed the objective and lost.

**Cheap falsifier.** CPU-only log/gradient study on a frozen model: compare per-step gradient variance and autocorrelation under current shuffle and balanced schedule using a fixed list of chunks, and verify by deterministic enumeration that expected row weights agree to numerical tolerance. If variance does not fall at fixed compute, stop. If it does, use one matched fold/seed training arm and require >=0.0005 paired exact Global WP and a nonnegative gain by market class. **Cost:** CPU audit minutes; full GPU training only after; inference unchanged. **Risk:** current sequence batching may already diversify enough, and importance weights may increase variance from rare episodes. **Priority:** low-cost diagnostic, then low-medium.

## Ordering and decision rule

Run CPU falsifiers for I-02 and I-05 first, then the frozen-head I-03 screen once clean OOF states exist. I-01 follows if the inferred gauge passes a feature-only manifold check. I-04 follows if quote-event recurrence passes. Freeze all settings before confirmation; treat fold 2/3 as less-exposed, not untouched. Any positive local delta must undergo the independent calibration/transfer audit. No proposal currently supports an expected public score of 0.6660.

## Primary research inspirations

- [Huang et al., *Simulating and analyzing order book data: The queue-reactive model*](https://arxiv.org/abs/1312.0563): a state-dependent queue model, useful only as a mechanism analogy.
- [van den Oord et al., *Representation Learning with Contrastive Predictive Coding*](https://arxiv.org/abs/1807.03748): autoregressive latent prediction, relevant to event memory representation.
- [Morrill et al., *Neural Controlled Differential Equations for Online Prediction Tasks*](https://arxiv.org/abs/2106.11028): explicitly causal online processing of irregular observations. A full CDE would be too costly for this first screen; it motivates treating event time and row time separately only where the already negative dual-clock control can be beaten.
