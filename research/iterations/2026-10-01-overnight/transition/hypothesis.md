# TRANSHEAD-01 — independent hypothesis commitment

Before competing branch ideas or outcomes: explicit adaptive conditional code-history statistics may add useful longer history beyond a frozen recurrent representation. The prior controls concern code prediction only; this experiment tests price forecasting utility inside the serving ensemble.

Mechanism family: online sufficient statistics / causal head augmentation. Compare F marginal-history probability channels and T first-order conditional-history probability channels at equal width, while sharing direct current/previous mark encodings and event count/age. The claim is incremental utility, with no physical market interpretation required.

Prediction: replacing the two h128 reference slots by T-feature heads improves pooled competition weighted Pearson by at least .0003 versus matched F-feature heads and versus reconstructed V1-like two-epoch plain heads. Both folds should have nonnegative gain. Paired seed3/4 use ref/refs4 epoch3 parents, fixed two-epoch head schedule. The recipe fails its allocation gate if T adds no ensemble value over F, or if any causality/reset/native-parity check fails.

Cheapest useful test: deterministic prefix/initial-forecast checks, then eight head fits (2 arms × 2 seeds × 2 folds) on existing validation-training folds. Frozen backbone, zero-initialized added head input. A negative result rejects this bounded feature-head recipe, not all end-to-end or alternative transition representations.

Known risks: current GRU already encodes the same useful information; code state is irrelevant to price; unbalanced categories saturate probability vectors; training/evaluation distribution shift; native callback cost. Existing data are exposed and seed-paired bootstrap intervals cannot establish hidden-test transfer.

This file commits the idea to the filesystem before implementation and independent critique. Root controls allocation/commit; no empirical run is authorized by this file alone.
