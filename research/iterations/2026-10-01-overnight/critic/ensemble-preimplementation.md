# ENSHEAD-01 independent preimplementation critique

Read `ensemble/hypothesis.md` only, before its actor implementation or empirical outputs. No scores requested.

The proposal addresses a genuine objective difference: member correlation is invariant to positive member scale, while fixed-blend correlation generally is not. In-sample frozen partner predictions are legal training inputs when they use the same held-fold exclusion, but they may encode overly easy fitted residuals. Held-fold correctness therefore requires each partner's own-fold checkpoint and own-fold nuisance/normalization, never an opposite-fold model that trained on the assessed chain. Cache metadata must include model/epoch/fold/source-order hashes; training accesses must assert held rows are NaN/unavailable and requested train rows finite. Input features at serving must never include partner labels, mask or target-derived class. The aggregate is solely a training objective; exported inference still predicts from raw rows.

Both capacities start from the same parent ep3 and use the same fixed H2 partners, masks, optimizer schedule, data order and epoch1 endpoint. The full head has ordinary auxiliary gradients while the affine control's auxiliary terms are constants. Thus superiority to affine means usefulness of nonlinear/head adaptation under this complete objective recipe; it does not cleanly isolate nonlinear capacity from auxiliary representation regularization. The existing standalone H2 anchor supplies the more direct same-capacity objective comparison.

Under UNCLIPPED Pearson, a globally constant additive offset in one member shifts every ensemble prediction equally and has zero analytic gradient. Consequently the proposed four stored affine parameters have only two effective scale directions in the main objective; offsets should remain approximately zero apart from numerical noise/weight decay. Nonzero offsets alone are not evidence of learned calibration. Keep them if preserving the declared interface, but report the degeneracy. Do not introduce clipping, class-dependent offsets or a scale sweep after seeing this fact.

Compute `(own + sum(partners))/4` in float32 before the unchanged main loss. Frozen partners must have no autograd path. Verify gradients on a planted minibatch against a literal aggregate, including zero targets, mixed masks and large predictions beyond2: targets are clipped inside the loss, aggregate predictions remain unclipped by design. A one-quarter multiplicative gradient is not the whole mechanism; the correlation derivative must be evaluated at the ensemble, not at own output.

Jointly replacing two independently adapted slots is a different deployed system from either slot's training objective because each was optimized against the original other H2 slot. This interaction is already explicitly acknowledged and should be graded exactly as registered. Do not rescue a failed combined result by selecting one slot after the fact. Reserve final fitting only for a predeclared branch-selection rule; if affine can be promoted, define its utility gate before exposing affine outcomes.

For affine export, let scale=exp(log_scale), offset=b. For each target row k, export `head.2.weight[k] *= scale[k]` and `head.2.bias[k] = old_bias[k]*scale[k]+offset[k]`; preserve every other tensor. Test nonunit scales/nonzero offsets, direct-model versus folded export in float32 and native fp16, both target orderings, and exactly identity initialization. Freeze all parent tensors and assert they remain byte-identical before folding; only affine parameters may update. A learned negative scale is excluded by the exp parameterization intentionally.

Promotion conclusions stay exploratory on exposed pure chains. Seed3/4 are separate changed slots within one system, not two independent ensemble replications. Whole-chain bootstrap is conditional on those trained systems; neither training objective alignment nor an independent code critic establishes hidden-test transfer. No conceptual blocker was found after the above provenance and export checks, subject to executable tests of the actual implementation before launch.

## Pre-outcome amendment from root

Before actor execution, the controller froze a multiplier of4 on the aggregate main loss, preserving the own-slot gradient in the identical-fixed-partner limit. The scale control now trains only two log-scales, with offsets fixed to zero. Both scale and full-head branches have independent predetermined utility gates against the plain V1-like anchor; full-head additionally must not lose to scale. These changes remove the offset nullspace and resolve the initial affine-promotion ambiguity. The earlier critique remains an honest record of the initial proposal.
