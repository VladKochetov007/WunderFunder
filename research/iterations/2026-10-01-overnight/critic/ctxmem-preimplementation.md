## Mechanism and comparator limits

The question is useful explicit history of a frozen recurrent state, not missing raw information: h_t already contains history. Updating after the current GRU step is causal. The price-code AND detector is an observed two-column code-change proxy; it is not established to be a physical quote clock. No target-derived event decoder is part of this experiment.

The selected Hadamard rows are structurally special. In a Sylvester order128 matrix, rows0,8,...,120 have their low three row bits zero, so columns within each consecutive block of eight are identical. The projection therefore depends only on the 16 consecutive eight-coordinate hidden sums, followed by a Hadamard mixing. It discards every within-block contrast. This is a valid deterministic orthonormal rank16 projection, but not a generic random spread over hidden directions. A failure only rejects this fixed projection; do not rotate/permutate/select Hadamard rows after an outcome. Verify row/column convention and exact float32 matrix/hash, since a transpose or different Walsh ordering can silently define another candidate.

[q_t,q_t] has rank at most16 and is already in the ordinary head's span. The two EMA states can have rank up to32 across histories. Equal tensor size is not equal identifiable capacity. At zero initialization the duplicate control's two weight blocks receive identical gradients; with identical AdamW state they remain equal, creating a redundant parameterization/optimization control. State this limitation rather than claiming matched rank or pure memory isolation. Required memory-versus-plain and joint/single replacement gates remain necessary. No post-outcome replacement by two event lags is allowed.

## Frozen-backbone and gradient risks

Freeze all trunk parameters, normalization and P; a differentiable construction must not accidentally unfreeze the GRU through the new path. q_t may be detached before CPU transfer because the trunk is fixed. The original head must still receive its ordinary main and auxiliary gradients. Only the added map starts at zero; copied head tensors must be bit-exact. Computing q/memory must not consume RNG, change loader order, alter AMP scope for the original head, or change the original forward when W_extra=0.

The duplicate control remains algebraically foldable into the h columns of head.0.weight, but inference rounding differs if it is actually folded. Freeze whether evaluation uses the explicit control path or a folded export. Do not fold only a favorable arm or compare differently rounded controls silently. Candidate extra weight precision and native/PyTorch projection precision must be declared.

## State-machine and numerical risks

Specify state as GRU hidden plus previous raw event endpoints, two float64 memories, and an initialized flag per sequence. Chunk boundaries are not resets. The first row initializes both memories to q0 once, regardless of whether its raw values differ from zero. Later events use current q_t after the GRU update. Non-events hold memory exactly. Invalid/NaN/signed-zero raw comparison semantics must match the original detector, including whether preprocessing sanitizes raw inputs before that detector; do not substitute OR for AND or compare against the last event instead of the immediately previous row.

A CPU lfilter call uses an internal delay representation, not automatically the previous memory value. For y=lambda*y_prev+(1-lambda)*q, its initial delay must equal lambda*y_prev; its final delay must be converted back correctly if storing y_prev. Empty event chunks must preserve both memories without fake events or division drift. Event at a chunk's first/last row, repeated empty chunks, batch streams with different initialized flags, and row0 initialization deserve literal recurrence tests.

Double memories and coefficients define the state recurrence, but do not alone guarantee equivalence: lfilter order, native FMA contraction, separate multiply/add, and coefficient generation can produce different results. Freeze exact hexadecimal double coefficients and an arithmetic convention, test scalar recurrence versus lfilter and native, and preserve failure receipts. Hadamard projection is another rounding boundary: FP16 h produced by AMP must be promoted before projection, TF32 must not silently replace float32, and an optimized grouped-sum/FWHT implementation is algebraically equivalent but changes summation order. Do not introduce it under an exact-parity claim unless its arithmetic is specified before testing.

Initial hidden states should follow the original backbone. Memory computed from PyTorch h and native h inherits the baseline's recurrent numerical difference; separate feature-state exactness on identical supplied h from end-to-end tolerance. Near-canceling q values may have high relative error, so use declared absolute as well as relative tolerances and test nonzero extra weights. Prefix parity alone cannot reveal an implementation that updates on the wrong clock consistently.

## Required preflight evidence and stop conditions

1. Literal Hadamard sign oracle, orthonormality tolerance, matrix bytes/hash and selected-row rank; q control rank/duplicate-gradient behavior explicitly reported.
2. Independent scalar recurrence on supplied synthetic h, exact detector oracle, zero/non-event/first-row/event-boundary/empty-chunk cases, arbitrary chunk partitions, batching, resets and changed-future prefixes. No future target or hidden-state lookahead.
3. Zero-extra baseline output and original-head gradient parity, frozen trunk bytes after optimizer updates, duplicate-control gradient identity, head-extra learning with nonzero gradients, unchanged train/eval-loader RNG and fixed checkpoint behavior. AMP and actual fast optimizer mode must be covered before empirical fitting.
4. Native/Python feature and full-model comparisons using nonzero synthetic extra weights, explicit accumulation convention, package reset behavior and all supported static ISA paths. Keep frozen old native source and derive a new engine separately.
5. A reviewed prototype plan before any real raw fixture or timing use: modified versus unmodified fixed-three complete callbacks, same member weights and precision, alternating trials, one CPU, idle-SMT accounting, no hidden output-based skip of a zero W_extra block. Require the amendment's <=3% median overhead before training and preserve absolute projected runtime. Final selected ZIP must additionally meet the unchanged 50-minute gate. MAC counts alone do not pass either gate.

No rank, clock, half-life, matrix-order, precision, optimizer, normalization, blend or seed sweep is authorized. A failed prototype or fixed scientific gate closes this registered recipe. All folds remain exposed discovery data; a passed memory control is not a hidden-test or top-rank guarantee.
