# QRENEWAL independent preimplementation critique

Written after reading quant-reframe.md and before reading renewal implementation. The registered purpose is an input-only falsifier of a fixed representation recipe. No passing result identifies physical time, true trades, executions, side, seconds or incremental forecasting signal. A negative a5 step is an observed code decrease; especially the common negative extreme may be either an encoded origin or another coding state. Use that observable terminology in results.

1. Identifiability: a nonzero g5 range removes the constant solution but does not identify two inverse clocks. A disconnected or weakly supported joint endpoint design can have many equally fitting slope vectors; ridge picks one. Report unregularized weighted-design rank/eigenvalue conditioning and normalization residual, separately from optimizer status and regularized fit loss. Do not call uniqueness induced by ridge empirical clock identification. Normalization must be imposed during the fit, not by dividing an almost-zero fitted range afterward; reject zero/nonfinite positive-increment median.

2. Objective and regularization: define whether coefficients are knot heights or interval slopes, exactly how duplicate quantiles collapse, and whether the penalty differences actual slopes or coefficients in a normalized basis. Second differences of knot heights with unequal knot spacing do not equal smoothness of derivative. Fixed .001 only has meaning after an explicit basis/feature standardization and chain-equal weight convention. Endpoint clamp differences must be excluded from the eligible support numerator, never silently treated as zero shared time. Constrained-QP failures, failed KKT/feasibility checks, degenerate support or insufficient complete runs must stop, not trigger a new solver/ridge/knots/sample search.

3. Denominators: report all adjacent pairs, finite age pairs, raw non-reset pairs, strict nondecreasing pairs, joint fitted-support pairs, zero ties, positive common increments and fitted sample counts. The 50% gate denominator is all finite non-reset pairs, not only supported/strict/positive pairs. Reset-origin denominator includes all finite observed a5 decreases; out-of-support resets are explicit failures/coverage, not dropped from the denominator. Per-chain summaries must expose concentration; fixed equally spaced subsampling must not count retained fit rows as population coverage.

4. Origin and excursions: fix what is a complete run, handling sequence boundaries, invalid ages, resets without marks, immediate consecutive resets, no complete runs, zero excursion and clamped endpoints. The fitting origin and tolerance are fixed before auditing the opposite half. A scale denominator cannot be selected from the audit half or pooled across halves. A5/a6 exact or near ties and negative changes within reset epsilon require explicit categories.

5. Mark measurement: reproduce the exact original D detector, including previous endpoint validity, strict abs<5.19 threshold, current nonneutral ptp>1e-6, and invalid bridge handling. R* needs only current admitted mark plus the age decrease. Missing D due to invalid previous raw vector is a filter mismatch, not a recovered repeated occurrence. Keep unchanged-dv/changed-dp, unchanged complete dp/dv, and other validity differences mutually exclusive and exhaustive. No claim of genuine hidden trades follows from any category.

6. Representation gate: both clocks use identical fitting-half median/IQR scales, same fixed lambda, zero initial state and causal update-before-read convention. Fixed audit grid must not depend on future event-run lengths. State divergence must use declared units and fitting-only IQR denominators; near-zero IQR treatment must be explicit. Sequence row0 cannot emit either event. Invalid a5 rows must advance previous raw age so a later finite value cannot silently bridge missingness unless specified.

7. Data boundary: exact frozen 256 chain IDs and half/class metadata must be inherited, not resampled. Each row group must be train-only and its entire chain have no validation member. Metadata/class labels are for fixed sampling/reporting only. The parser must request exactly a5,a6,i0_dp0..3,i0_dv0..3. No target, scoring mask, valid parquet, cached forecasts, model checkpoint or price-association stage may be opened. Freeze source, manifest and schema hashes before root allocation.

8. Resource and scientific stop: input-only run is hard-capped at480 seconds, two CPU threads and4GiB with no GPU. Root alone runs real data and interprets the fixed gates; failure or timeout ends this recipe. Passing cannot authorize price association or neural forecasting because all eight scientific configuration slots are occupied. Any rank/conditioning diagnostics added before execution are descriptive checks, not another selected pass threshold.
