# Postfailure three-member quantized composition: independent feasibility critique

This is a proposal review, not authorization. The full-four VNNI experiment remains closed at its unchanged 50-minute gate. A new three-member composition is a new scientific candidate and requires the controller's explicit budget amendment before timing or metric outcomes; it must not be described as a passed rerun of full-four.

A defensible single candidate is exactly the original dist256 seed3, plain128 seed3 and chunk500 h128 members, in their original relative accumulation order, with coefficients exactly one third. Freeze checkpoint/native/quantizer/wrapper hashes and the retained seed by identity. No alternate dropped member, second seed choice, blend coefficient, quantization level, calibration or model retraining is permitted after outcomes. The proposal is informed by exposed validation evidence and the known loss from dropping dist256; this is adaptive discovery, not a fresh holdout or an unbiased confirmation. Do not claim that calling a member redundant proves it is dispensable under the new composition.

The timing gate should precede any new candidate WP readout. Use the exact complete-callback implementation, original FP32 source weights and frozen quantization rule, final weight format, all preprocessing/reset/Python overhead and every warmup row. Three members can change cache reuse and the alternating execution schedule, so subtracting one quarter of full-four time is not a valid runtime certificate. Freeze a short repeated-trace plan and one million-row trace, with the same declared idle-SMT condition and bounded noisy-attempt allowance used for baseline3. Keep every noisy/failing receipt. Prefer requiring every qualified run, including the long trace, to project below the unchanged 50-minute limit; do not average an over-limit run away. The long trace consists of independently reset 20,000-row sequences and should retain that label.

Runtime and numerical validation must use the actual hardware dispatch branch. VNNI availability on beleriand does not prove availability on organizer hardware. Any non-VNNI fallback must preserve the same member set and quantizer; silently switching to FP16 weights changes the tested numerical model. The exact-integer portable fallback and its serving cost need separate validation. Never execute AVX512/VNNI without feature checks. Static dispatch is allowed; wall-clock-dependent member pruning is not. Runtime qualification is conditional on the tested hardware until the public CPU capability is known.

Before scoring, require the existing raw-output numerical gates against FP16 of the same three members, reset/prefix/stream invariants, literal signed-integer accumulation/rescale parity, and deterministic repeated outputs. These engineering comparisons use no targets and do not select a new quantizer. Equality of an optimized kernel to its prior quantized kernel is different from quality equivalence to FP16.

If timing and correctness pass, both quality comparisons must pass rather than selecting the favorable one:

1. Quantized three versus FP16 of exactly the same three isolates quantization damage. Freeze a pooled and per-fold noninferiority tolerance before any scores; never infer the tolerance from the observed loss. This FP16 composition may be too slow to deploy, but remains a valid scientific comparator.
2. Quantized three versus the already validated fixed-three h128 package tests the actual deployment tradeoff. The existing promotion rule of at least +.0003 pooled with nonnegative deltas on both folds is a reasonable unchanged gate. If the controller chooses another rule, record it in the amendment before scoring rather than after an outcome.

Report both target coordinates and both folds, retain the ordinary full-four reference already available, and compute both comparisons from the same frozen prediction arrays, target/mask row order and global metric. Count the two new requested comparisons against the WP budget, with no further composition search if either fails. No re-fitting or per-seed selection is required or justified by this candidate. A gate pass supports this one serving compromise on exposed folds; it does not establish top rank or hidden-period gain.

Readiness conclusion: technically and statistically coherent as one explicitly amended, runtime-first candidate. It is not currently authorized, and neither runtime feasibility nor quality is implied by the full-four or all-h128 results. The original full-four failure and baseline3 artifact remain preserved regardless of the new outcome.
