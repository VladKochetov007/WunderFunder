# ENSHEAD-01 independent reserve, before implementation/results

Mechanism family: ensemble-aware head optimization. A member's standalone correlation is invariant to its positive output scale, whereas scaling one member changes its relative weight inside the fixed equal-quarter ensemble. Optimize the same batch×chunk correlation surrogate at the actual four-member aggregate, keeping the three other slots frozen. This can improve ensemble utility without increasing inference cost. In-sample partner errors may instead invite cancellation that fails on held-out chains; this is an explicit competing explanation.

Named interventions: independently adapt the ordinary h128 seed3 and seed4 slots from their original parent epoch3, with their matching fold's other three two-epoch baseline members fixed. Those partners exclude the evaluated fold in parent/head training. Never obtain training-side partner predictions from another fold's model that has trained on the evaluated fold. Use the own-fold model to predict both its eligible training sequences and held-out fold, separating their downstream uses.

Full-head treatment: freeze inp/gru, train original nonlinear head, keep auxiliaries .3/.3 and every existing training setting, replace only the two-target main loss input by `(own + sum(frozen partners))/4`. Keep predictions UNCLIPPED inside the training surrogate, matching the existing gcorr derivative convention; final evaluation clips the aggregate exactly as usual. No clipping/objective sweep.

Affine capacity control: same own parent and same frozen partners, but freeze the entire original model and train only two log-scales and two offsets, initialized zero, `p=exp(log_scale)*p_parent+offset`. Same two epochs, shuffled batches, minibatch×chunk ensemble objective, AdamW/OneCycle settings and masks. Original auxiliary outputs/losses remain unchanged constants, with no gradients into affine parameters. Export folds the resulting affine into the original main output weight/bias rows. This control addresses the narrower question of calibration accessible from the common parent; it does not test post-hoc calibration of an already adapted H2 head, which would be another recipe.

Serving estimand: PRIMARY replace both ordinary slots with their independently trained ensemble-aware heads at the unchanged quarter weights. Both treatment objectives see the ORIGINAL matched H2 partner in the other ordinary slot, so joint serving differs from either training objective. This is a declared simultaneous independent replacement, not joint optimization. Report each single-slot replacement and the combined result, plus the same affine replacements. The two slot seeds are paired against their own baseline; they are not independent replications of the four-member serving system. If interactions reverse gain, the primary gate fails; do not select one favorable slot after the fact.

Provisional allocation: eight new fits (four full-head and four affine), with eight existing standalone H2 anchors reused. Primary full-head vs original V1-like blend spending gate +.0003 pooled, both folds nonnegative; require full-head not below affine combined blend in either fold and pooled for a nonlinear-capacity claim. If affine is as good, evidence supports calibration only; any affine deployment would require its own root-approved frozen selection rule before outcomes. All chains exposed; whole-chain bootstrap conditional on predictions, no transfer guarantee.

Cost plan: generate own-fold H2 partner predictions on eligible training sequences once per baseline model/fold, eight prediction passes total, into isolated campaign/ensemble/cache. Existing held-fold arrays contain NaN outside held fold and cannot train this objective. Each four-member set can be reused by both named slots and both treatment capacities. Store each full valid-index file (~300MB) with train rows filled, held rows NaN, row-order/hash provenance and fixed checkpoint hashes. About2.4GB new predictions; sequentialGPU generation with caps. A dataset joins predictions by immutable validation row-group; no inferred target/mask enters the model. Cached partner arithmetic avoids three extra forward passes per training step. Expect 10–20GPUminutes partner generation and 10–15GPUminutes head fits, shared-host dependent; no jobs launched by this proposal.

Required preflight: synthetic gradients through own slot only, exact mean and mask/target clipping conventions, original-head/default objective parity, scale/offset export parity, frozen bytes, sampler RNG unaffected, partner fold/hash/epoch checks, no accidental held-row cache use during training, and independent critic review. Root owns allocation, grading and all job launches. No empirical fit or WP query is authorized by this file alone.

## Controller/critic amendment before implementation freeze or any execution

Supersedes the initial unscaled-main and four-parameter affine descriptions above. Use **4× ensemble main correlation loss**, preserving existing auxiliary coefficients. When all three fixed partners equal the own prediction, this yields exactly the standalone own-output gradient; otherwise ensemble-aware directions remain different. The control trains **two log-scales only**, with offsets fixed zero: aggregate additive offsets are analytically unidentifiable under the unclipped Pearson surrogate, so optimizing them would amplify numerical noise. The model is exported by multiplying main head weight/bias rows by positive scales.

Full head promotion requires pooled delta≥+.0003 against plain and nonnegative delta in each fold, plus nonnegative full-head versus scale in both folds and pooled. Scale may be promoted only if it independently passes pooled≥+.0003 and both folds nonnegative against plain. Both rules use the predeclared simultaneous two-slot replacement; no favorable single-slot selection. Shared auxiliary gradients differ between full-head and scale control because scale has no shared trainable head representation. A difference therefore concerns the whole specified adaptation, not pure nonlinear capacity. Root accepted this normalization and critic correction before outcomes.
