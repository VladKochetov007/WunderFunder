# Independent review of DETECTOR02

Reviewer: research_story, author of PRIOR02, not author of the detector study. This is a bounded specification/source review before reading DETECTOR02 real-data outcomes. No detector source file or plan was edited, and no feature arrays were read by this reviewer.

**No blocking issue found.** Joint float32 bit patterns define packets, preserving NaN payloads and signed zero in reconstruction, while the unchanged numeric detector retains its own validity/equality semantics. The packet vector and attached duration are permuted together within each original block. This preserves block row length and the raw joint multiset. Adjacent equal packets may merge; the code measures this and does not retry, reject or repair a permutation. Rerunning the exact detector on reconstructed raw rows makes this a defined observation-process control rather than a relabeled category shuffle.

Frozen old artifact hashes bind selection, centers and baseline evidence. Source and metadata identity checks preserve the selected 256 chains and explicitly exclude chains with validation members, the entire corrupt-row chain and the prior dictionary sample. Original evaluation mark hashes, priors and per-chain losses must reproduce. Each half fits both surrogate pi and R with its own frozen codebook and evaluates the opposite half with that same codebook. The half/center direction is correct and original-prior mismatch is not intentionally carried into surrogate evaluation.

The primary comparison pairs source chains with nonempty original and all three surrogate conditions. It reports omitted IDs instead of substituting zero loss. Macro-chain gain divides each chain/condition by its own event count; event-weighted gain sums each condition's losses and divides by that condition's own total events before subtracting or averaging seeds. The bootstrap resamples the same chain IDs across all conditions within half/class strata. Its synthetic unequal-denominator example targets an important potential error. Full null-CI output is used for an entirely empty paired cohort. If only some strata are empty, the remaining-cohort estimate cannot be described as preserving the original balanced-class population; stratum-size reporting makes this limitation inspectable.

The plan's interpretive limits are essential. Raw-run blocks and prior-study mark blocks have different clocks. The surrogate changes emitted frequencies, count histories, gaps, first observation and cap endpoints, so eventwise pairing or subtraction of the two studies into causal components would be invalid. Surrogate-matched priors help compare complete estimators on these different populations; they do not recover a physical exchange-event simulator. A large surrogate gain would show that this declared retained representation/occupancy structure can reproduce much of the nuisance-prediction regularity. A small gain would not identify microstructure causation because unpreserved detector topology and within-block ordering remain alternatives.

Source processing is sequential per sequence, and only capped four-vector arrays and aggregate records are retained. Memory structure fits the declared bound. Timeout/error interpretation must rely on the immutable resource/failure log if the script stops before a result file. A successful run still needs exact input identity and all preservation/reproduction checks; no result here authorizes extra sampling, threshold changes or forecasting training.

## Independent numerical interpretation after the fixed run

This section reads only the saved `detector-output/detector-result.json`; no additional source-array calculation or model fit was performed. The study completed in 36.88 seconds of script time. Every listed source, metadata, raw-preservation, prefix and original-reproduction check passed. All 256 chains are paired-complete, no exclusions occurred, and each half/class stratum retains 32 chains. The partial-empty-stratum qualification above therefore does not affect this realized result.

The original mean-chain gain `LL(F)−LL(T)` reproduces at **+0.789757**. The three raw-run surrogate gains are **−0.031121**, **−0.031361** and **−0.031370**. Their fixed-seed average is **−0.031284**, with conditional paired chain interval **[−0.033773, −0.028550]**. Original minus average surrogate is **+0.821041 [0.812124, 0.830342]**. Event weighting yields average surrogate gain −0.024118 and contrast +0.810483 [0.798710, 0.822298]. These intervals condition on the surrogate draws and matched fits; they are not confidence bounds on a physical market effect.

The nuisance advantage disappears under this particular run-packet reordering despite preserving joint row-code counts, code-duration associations and local block occupancy. Each surrogate loses to F in both halves and all four complete-prefix class slices. Class mean gains span roughly −0.0568, −0.0129, −0.0314 and −0.0240 for classes0–3. First16 surrogate gains are modestly positive, approximately +0.0253/+0.0247/+0.0285, whereas later-prefix gains are negative. Matched transferred priors can help cold start without yielding a whole-prefix context advantage; this agrees qualitatively with PRIOR02 without making the two different block clocks or emitted populations interchangeable.

The surrogate materially changes the detector path. Original full-sequence detections number 826,511; surrogates produce 804,708–804,897. After capping, original loss uses 681,335 marks versus 670,649–670,684 for surrogates. Capped-chain count changes from 80 to 77. Valid changes into neutral states fall from 264,139 to 198,407–198,724, and same-code holds rise from 4,029,080 to 4,116,107–4,116,599. Approximately 87,000 packet boundaries merge out of 1,090,920 original packets. The exact row multiset and attached packet-duration constraints are preserved, but the event population and prefix coverage are plainly not identical.

Original same-category adjacency is 5.79%; the three surrogates produce about 18.17–18.24%. Original lag1 plug-in mutual information is 0.83887 nats versus 0.04383–0.04407 under reordering. These descriptive changes show that sequential code structure was disrupted. They do not reveal whether it represented market behavior, feed-state transitions, encoding rules, neutral/reset placement or a combination. In particular, **this result does not rule out detector or representation artifacts in general**: the raw-run surrogate itself destroys much of the feed-state transition topology through which such artifacts could operate.

The warranted conclusion is narrow and useful: preserving the declared local joint-code/duration/occupancy constraints, then applying the unchanged detector and refitting the same nuisance predictors, is insufficient to reproduce the large original first-order mark advantage. Richer original code order matters for the specified predictor. It remains possible to use that order as a causal feature without physical identification, but there is no evidence here that it predicts future prices, adds information beyond the raw-history GRU, improves the competition score or transfers to an unseen test. No positive “price alpha” claim or automatic forecasting allocation follows from the +0.821041 descriptive contrast.
