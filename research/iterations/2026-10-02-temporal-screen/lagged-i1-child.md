**Exact feature, no lag/coordinate sweep.** Read only raw columns `i0_p0,i0_p11,i1_p0,i1_p11` (indices0,11,52,63). Use the existing exact float32 clocks: i0 event is change of BOTH selected i0 coordinates; i1 event is change of EITHER selected i1 coordinate. Row0 has zero deltas/events. At every i0 event reset accumulator, squared-increment energy, count and previous-i1 increment BEFORE handling the current row's i1 event. Thus simultaneous i0/i1 events initialize a new interval and cannot form a cross-boundary pair.

At i1 event n in the current interval let d_n be its two current float32 raw-code deltas, converted to float64 for accumulation. First event contributes no turn. Subsequently add `det(d_(n-1),d_n)=d_(n-1,0)*d_(n,1)-d_(n-1,1)*d_(n,0)`. Let T be the running sum, E=sum||d_n||², and define **A=T/E if E>0 else0**. This uses exactly lag1 in i1-event time. Hold A between events. Every sequence resets; chains never carry state. No future endpoint, interval midpoint, future event distance, decoded transition lookup, scoring mask or target enters this feature. Include current row before emitting prediction-time features. Synthetic checks required: prefix/chunk/one-row parity, simultaneous reset, empty interval, two-event signed determinant, reversed event pair negates turn, and equal-net-displacement paths can have different A.
