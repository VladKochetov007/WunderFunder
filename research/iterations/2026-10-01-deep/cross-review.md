# Independent training-side review of the quant branch

Reviewed the frozen `quant-plan.json`, `quant_geometry.py`, real-data result, revised `quant.md`, and the separately executed `quant_toy.py` / `quant-toy-result.json`. This is a source-and-artifact review. I did not rerun real data or reproduce the author's toy: an attempted separate local positive control stopped on the missing `pyarrow` import before any fit, and was not retried once the author's completed toy was available.

**The real-data screen supports stopping this particular feature recipe.** The four cross-chain best-two coverages are 6.91%, 7.29%, 8.97%, and 11.93%, versus the declared 80% gate; the ask fits also fail condition <100. Input columns are the documented 11 bid-volume and 11 ask-volume components, not an invented depth ordering. Targets and predictions are not read; historical target-derived class metadata is only a sampling stratum, so this is a conditioned training-data diagnostic, not an independent or label-naive validation sample. The reported geometry does not measure competition WP or establish a serving-ready physical decoder. The revised dossier states those limits correctly.

**The full fitter, not only the projection routine, has a material model limitation.** `fit_lines` assigns every unit increment to one atom and updates that atom with its cluster's principal eigenvector (`quant_geometry.py:54–70`). `errors` subsequently permits an unconstrained linear combination of two atoms (`:38–51`). The latter calculation is correct for unit atoms, including the degenerate-pair fallback, but the fitted objective does not optimize the reported two-atom error. Correlated/co-occurring latent updates can favor directions of common combinations. Thus low held-out coverage is a failure of this fixed 11-line/PCA-initialized/20-update recipe; it cannot falsify the existence of some sparse dictionary, a nonlinear transform, or physical queue coordinates. The real result's better median error than raw/PCA remains positive geometric evidence, without passing the declared downstream spending gate.

**The author's positive control is valid and usefully narrows the concern.** `quant_toy.py:13–31` fixes one random orthogonal 11-dimensional mixing and constructs separate 6000-row fitting and evaluation samples for one- and two-sparse latent updates. The second support is guaranteed distinct from the first. The true atoms are correctly transformed by the fitting-half RMS scale, then normalized; all evaluation dictionaries receive the same scaled test vectors. It calls the frozen `fit_lines` and `errors`, rather than supplying the true atoms to the learner. Both cases report 100% learned best-two coverage and 11/11 true-atom matches above .95; the oracle also gives 100%. The two-sparse learned median error is .01828, so recovery is approximate rather than exact. These outcomes show that the one-line fitting objective can recover a two-sparse dictionary in this easy case, and counter a blanket claim that it necessarily fails whenever two coordinates move.

The toy does **not** close the mismatch generally: only one condition-1 mixing is tested, with uniform support probabilities, independent Gaussian amplitudes, no noise, no censoring and no state-dependent encoding. It does not test moderately ill-conditioned mixing, correlated supports/amplitudes, or the complete two-half stability/condition gate. It is a post-diagnostic algorithm check, not a preregistered empirical confirmation and not evidence of queue semantics. The wording in `quant.md:116–118` preserves this distinction. No additional toy or real-data retry is needed for the present allocation decision.

**The proposed causal feature is now specified without a false economic claim.** Fixed train-only atoms, current/past input differences, half-wave state updates, and explicit reset/invalid flags are compatible with streaming prediction. Positive and negative coordinates are not identified as order additions/cancellations; this distinction must survive any implementation. Fitting the dictionary and scale again using a held-out fold or using full-sequence statistics to decide current trade events would change that causal contract. The current round does neither. Because the geometry gate failed, no inverse/half-wave feature training is authorized by this result; conditional trade-mark innovation remains a separate, unfitted reserve.

**Cross-branch ranking must not require a false gradient-conflict gate.** TDIAG1 finds positive summed auxiliary/main shared-head cosines in both inspected windows. Main-only head FT is still a coherent low-cost controlled intervention: it changes shared optimization and the global clipping norm, including auxiliary-private rows. Neither positive cosine nor a changed clipping factor determines the subsequent Adam step or score effect. Keep it first by cost and clean comparability, with weaker conflict motivation; the result does not warrant claiming that auxiliary conflict was observed. This also matches the architecture agent's independent review of TDIAG masks, offsets, replay and gradient slicing, which found no substantive implementation error.
