# Historical error audit — source/report review only

2026-10-01. No datasets, prediction arrays, checkpoints, new metric readouts or model executions were used. This audit searched the journal and historical reports; “not found” below is scoped to those records, not a proof that nobody ever inspected a plot. The inherited creative-research workflow applies. No new experiment is allocated here.

**Main finding:** the major class-3 error anatomy was studied extensively. Repeating “long quiet periods are hard,” a future-event shift plot, or a sequence calibration oracle will not choose a new model. The useful next distinction is **late reaction to information already observed versus genuinely missing future information**. A second, lower-priority distinction is **dependence on arbitrary initialization versus useful long history**. Existing cached predictions can describe their signatures, but cannot by themselves identify either causal mechanism.

## 1. Highest-value mechanism: delayed response after an observable event

**Hypothesis.** Some directional mistakes persist because the network retains the old forecast after an input transition has already supplied useful evidence. This differs from waiting for the *next* event’s information. The existing phase-only readout is counterevidence, but it did not test a signed input-innovation × prediction-response interaction or a backbone update mechanism.

**Diagnostic for the planned one-pass extraction.** Define events strictly from the existing causal raw-feature change flags, before examining labels; retain i0-price, i0-other and i1-only categories separately. At the event and fixed following row ages 0,1,2,4,8,16,32, retain target/prediction levels, their increments, and signed residuals for the already-fixed models. A subsequent event restarts age; report the risk-set counts/weights rather than silently keeping only completed long episodes. Inspect whether an observed transition’s target increment is systematically under-represented by the simultaneous prediction increment, and whether later prediction movement repairs that same signed error. Compare the current strong ensemble and the already-fixed alternative; inspect both targets and the target contrast. Report chain-level concentration and input-defined event categories, not only favorable examples.

Realized target changes can label a descriptive panel but **cannot define an inference gate**. The main populations must include all predeclared causal events, including those with no target change. Do not score future-shifted predictions as candidates. A coincident target jump does not prove its sign was predictable at the transition; this diagnostic only distinguishes an actionable candidate signature from the already-known future-event oracle.

**If supported:** one matched backbone intervention with an event-conditioned *current-input innovation path* into the recurrent update, initially zero so the ordinary model is the exact control. It asks the model to update faster when current evidence warrants it; it is not an extra held event GRU, a frozen-head age correction, or a future-quote auxiliary. Keep the ordinary level objective and ordinary online inputs. Serving cost is a small input projection/gate, which still requires a separate feasibility check.

**Falsifier / decision change:** no reproducible signed under-response after observable events, or error concentrated mainly *before* unseen next events, removes the rationale for faster-update architecture. A large stable under-response after specific causal events would justify a bounded matched training test, not an automatic forecast gain claim.

## 2. Lower-priority mechanism: arbitrary-origin state contamination, not cold start

**Hypothesis.** The model may carry an initialization-specific state component that changes later forecasts even after sufficient recent evidence. The old early-step score being good argues against simple missing warmup; it does not compare the **same row and same recent inputs** under different valid causal origins. The Sep30 creative report explicitly deferred this controlled comparison, and the continuation scout proposed it without executing it. The state-refresh prototype concerns stale *optimizer-time* carried state and is a different question.

**What the present one-pass error report can and cannot do.** It can describe residuals by current sequence position, causal event age and class for each fixed model, with exact weight counts. It should not interpret those associations as a reset effect. Only if a consequential unexplained position/model divergence remains would the next diagnostic replay fixed rows under a few **predeclared earlier reset origins**, holding the suffix inputs and checkpoint identical, and compare same-row prediction differences and errors after fixed burn-in lengths. Original start remains the reference. No cross-sequence state, future rows, or best-origin selection is allowed.

**If supported:** randomized-origin training with an unscored burn-in prefix, followed by ordinary uninterrupted serving and unchanged architecture. This changes training’s sensitivity to artificial segmentation; it does not add long-memory serving state or rescale residuals. Match the number of supervised rows and optimizer updates; otherwise the treatment is a data-budget change.

**Falsifier / decision change:** origin effects vanish rapidly, or the longer valid history consistently improves same-row predictions. Then random-origin augmentation is unsupported and may discard useful context. Persistent prediction differences alone establish sensitivity, **not harmful sensitivity** or a training benefit. This requires another forward-only allocation; it cannot be certified from current caches.

No third mechanism is recommended merely to fill the list. The record is already rich in unsuccessful calibration/history variants. The immediate error pass should first establish whether the strongest remaining signature is post-observation under-response, future-information uncertainty, or neither; another architecture name should follow that distinction.
