Source-only independent review, before actual replay outcomes. Existing error-analysis artifacts remain unchanged. No checkpoint values, raw feature arrays, labels or new predictions were opened for this review.

The design addresses a narrow question: for one fixed shallow256 checkpoint in each outer fold, does selectively deleting old recurrent state alter predictions/errors on the same four preassigned blocks? It does not compare naturally restarted sequences, fit a new model, identify irreversible noise, or validate deployment.

I inspected `replay.py` together with `train_rnn.build_inputs`, `forward_chunk`, `RNNModel.forward` and the frozen historical `student/predict_fixed.py`. No blocking mismatch found:

- All 211 inputs are constructed once from each full raw sequence and the same tensor is sliced for every context/engine. Checkpoint mean/std are buffers restored by strict `load_state_dict`; normalization still occurs inside the unchanged model. Age is computed from full-prefix encoded-event flag index178. Historical event features deliberately remain present after an h reset.
- Four starts are constants4096/8192/12288/16384, each512rows; reset origins are start−256/start−2048. Targets, scored masks and retrospective classes do not determine origins or choose arms. Class only annotates analysis; pure-chain/fold selection is the fixed study population.
- Full reference carries its real incoming state. All scored blocks use identical512-row forward shapes, and reset arms use the same batch and suffix inputs. First batch/first block in each fold×engine repeats the suffix from a cloned real incoming state; both outputs and resulting state must match exactly. This is four implementation controls, not a claim that every block was independently repeated.
- AMP and FP32 with TF32 disabled are both fixed in advance. Full AMP is compared with its original all20000-row cache using fixed maxabs0.003 and RMS0.0003 guards. FP32/cache differences are descriptive, because arithmetic differs. These tolerances bind model/cache identity; they do not establish that a tiny intervention effect is distinguishable from AMP rounding. Both engines must be reported, with no favorable-precision choice.
- Individual cached partners are preserved. The independent analyzer uses original float32 `(((shallow+plain3)+plain4)+chunk500)/4`, then clips the final ensemble. Pre-summing partners would change rounding and was removed before execution. In the FP32 companion only the replayed shallow member changes arithmetic; three cached partners remain fixed GPU/AMP outputs.

`analysis.py` contains no inference or fit. It requires a completed producer receipt with passing parity, pins the saved NPZ and plan/source hashes, and scores only the actual mask on the same block rows. The normalizers of each engine's **full control on the block population pooled across both folds** define its error coordinates. Old whole-validation EDA normalizers are not reused.

Two estimands are intentionally distinct. Actual WP differences recompute each arm's clipped weighted means/variances and pool all selected block rows before correlation. Fixed-reference error change retains full-control mean/SD: only its baseline equals `1−WP`; its finite intervention change is not exactly minus the renormalized WP change. First-order `q·Δp` uses the actual clipped prediction difference and is explicitly a local approximation in post-clip space.

The two planned reset−full contrasts are reported for **both engines**. Class3 quiet≥64 is the localization focus; class2 quiet/fresh and class3 fresh0–15 are fixed descriptive comparisons. Fold and target results are reported. These slices are not averaged into primary WP and are not filters for selecting an origin or new inference gate.

Uncertainty is2000 paired whole-chain draws with seed20261001, stratified by **outer fold×retrospective class**; class is analysis-only. Same draws apply to all arms and both engines. WP renormalizes every resample. Fixed-error/linear intervals instead resample original per-chain contributions with the original reference W/means/SDs held fixed; they are not fully renormalized bootstrap deficits. Intervals are marginal95%, conditional on fixed checkpoints, blocks and interventions; no model-selection/domain-shift uncertainty or familywise coverage claim.

Four generated-only checks passed before real data: original float32 blend order and postblend clipping; direct weighted pooled correlation versus sufficient sums (explicitly differs from average group correlations); baseline energy identity and finite-difference metric gradient; identical-arm paired bootstrap returns exact zero contrasts. A final repeat after pre-data wording/chain-summary additions is recorded separately in the test receipt. No actual study data were used.

Interpretation remains bounded. A benefit surviving FP32 would support harmful old recurrent context **for these checkpoints and fixed windows**, while unusual zero-state remains an alternative. Little response would weaken this specific intervention, but cannot distinguish forgotten useful information from irrelevant older history. A large response without error improvement is sensitivity, not a reason to train. No further reset lengths, mixtures or training are authorized by this analysis itself.
