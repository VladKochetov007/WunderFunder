## The task and the prediction contract

The challenge predicts two future-price indicators from anonymized sequential market features. Every sequence has 20,000 rows. A model must process rows causally, reset between sequences, use the warm-up history, and return predictions whenever `need_prediction` requests them. The private scoring mask is not a deployable input. Anonymous codes are not identified physical prices: the failure of a physical decoder does not remove their predictive information.

The official local implementation is **`global_wp_clip2_v1`**. For each target separately, clip target and prediction to ±2, assign weight `abs(clipped_target)`, and pool all selected rows (`need_prediction AND is_scored`) before computing centered weighted Pearson. Average the two target scores. This is not the average of sequence or class correlations. Read [METRIC.md](../METRIC.md), [utils.py](../utils.py), and [gmetric.py](../src/wnn/gmetric.py).

The archived submission contract is offline Python 3.11/Linux, one CPU, 16 GB RAM and 60 minutes; ZIP size limit 20 MB. See [submission guide](../docs/submission_guide.md) and [rules](../docs/rules.md). Research-compute limits are separate: locally 12 aggregate CPU cores, 30 decimal GB hard RAM/27 GB soft headroom, no swap, and 5 decimal GB GPU VRAM. Kaggle allocation must be measured per actual worker/device; two T4s do not provide twice the host RAM.

## Evidence rules for the reviewer

1. Separate public measurements, complete-predictor CV, exposed diagnostic panels, fixed-weight probes and source-only proposals.
2. A paired component bootstrap conditions on trained models. It does not include all seed uncertainty, multiple comparisons, teacher overlap or search selection. Do not average per-class WP to obtain the official score.
3. Direct row exclusion is different from connected-component exclusion and component-disjoint teacher fitting. List actual overlaps before saying “independent”.
4. A provider failure before checkpoints/export is an execution failure. A RAM guard is not a model-family negative. A numerical parity failure blocks the named implementation only.
5. When the regression control also loses against its preserved parent, a failed structured head is weak evidence against the entire representation family. Report the loss; do not erase it or call the control successful.
6. Use the actual current predictor as a transfer anchor. Keep the historical final-head procedure in candidate/control comparisons; freeze support, knot statistics and routing definitions using fitting data only.
7. Native deployment must match the declared reference and evaluator Python. A training implementation need not match an unrelated fused implementation's every optimizer update unless interchangeability is the claim.
