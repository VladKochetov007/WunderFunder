CONTRADICTIONS AND CAUSAL INTERPRETATION
Constant true labels do not imply constant conditional predictions. Additional
current information changes what can be inferred about an unchanged label.
a6 aligns label boundaries but appears insufficient as a prediction-update rule.
Age associations in f05 did not translate into a useful additive clock update.
Generic flow-pressure literature is not positive evidence for these anonymized
v/dv fields: the controlled local result is negative. Keep economic labels tentative.
Joint support exclusions constrain labels, not necessarily their conditional means;
do not round predictions onto a lattice or hard-project means without a scored test.

RANKED NEXT DIRECTIONS (not run here)
1. Decode current p-state geometry rather than freeze at label anchors.
   Cheapest test: p-only ridge versus exact-key lookup with coverage-aware backoff,
   then a small monotone/rank transform probe; use sequence splits and exact tuples.
   Control: identical capacity on anchor p, same normalization and target weights.
   Reject exact decoding on one repeated-state conflicting output; reject utility
   if sequence-level held-out gain disappears. Inference: current p inputs only.
2. Price-event smoothing versus within-state information updates.
   Cheapest test: current prediction versus carry at price events versus trailing
   input-only EMA with frozen decay; score price-static intervals separately.
   Control: five causal delayed-price streams with comparable event counts.
   Reject event-specific benefit if generic smoothing matches it. Inference:
   prefix price-change detector and prediction cache/EMA; a6 remains a soft feature.
3. Full p blocks and causal entry path, instead of assuming scalar sufficiency.
   Cheapest test: conflict counts for p0/p11 keys versus all own p columns, then
   one bounded train-only lookup with 2..3 preceding distinct input states.
   Control: same key count/capacity with delayed historical states; log unseen keys.
   Reject if apparent identities fail at a repeated key or gains depend on tiny
   coverage. Inference: current p block plus bounded transition memory, no targets.
4. Four-regime geometry and joint targets, without oracle quantum.
   Cheapest test: warm-up input membership classifier on train sequence splits,
   reporting ambiguous/unseen symbols; compare regime-marginalized and pooled heads.
   Control: class-prior mixture and no regime feature. Reject if ambiguity or lack
   of downstream gain dominates. Inference: prefix input regime probabilities only.
5. Nonlinear flow/age interaction as a residual hypothesis, lower priority.
   Cheapest test: conditional residual summaries within matched current p states
   and age bins, followed only if warranted by a small predeclared interaction model.
   Control: scrambled flow within p/age strata and current-p predictor unchanged.
   Reject if association/gain vanishes across sequences. Inference: present/past
   flow inputs and current age; never final interval duration. No GPU needed.
