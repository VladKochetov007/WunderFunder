H1 — EXACT QUOTE IDENTITIES: REJECTED; STATISTICAL STRUCTURE SURVIVES
Script: probe_quote_identity.py. Outputs: quote_identity_v1.csv/.log,
quote_identity_summary_v1.json, quote_identity_witnesses_v1.json.
Target quantum extraction is diagnostic only; max tick-grid residual <6e-6.
14.7405% of all rows have negative -(t0+t1)/q. Repeated current-state modal
agreement with this sum is 66.2306%, versus 43.1938% under 20 matched
within-sequence/trade-change-mask shuffles. All 20 sequences fail the frozen
shared-reference physical-spread criteria (negative fraction >.1% or modal
disagreement >1%). Saved witnesses give identical price vectors/different sums.
For transitions observed >=5 times, joint target-jump agreement is 91.5706%
on 104574 covered events, versus 41.2325% under 20 shuffles within sequence
and event-side mask. 15/20 fail the frozen 99% exact-transition threshold.
The largest-quantum transitions are often >99% pure; this association is useful
even though cumulative increments must not be described as actual quote prices.
Three target changes occur on 268299 no-price-change rows: the old claim that
target changes occur ONLY with book prices is almost, but not exactly, true.
Opposite-side target changes on single-side book events are almost absent.
These facts are compatible with quote-linked labels and distinct future
references. They do not identify physical spread, instrument, horizon or ticks.
Modal purity is a retrospective diagnostic, not an out-of-sample decoder score.
The shuffle does not preserve serial dependence; use it as a matched marginal
control, not as a significance test. State IDs use full-sequence equality only
for diagnostics; they never enter H2/H3 inference.

RANKED NEXT DIRECTIONS (HYPOTHESES, NOT RUN IN THIS PASS)
1. Regime means and prediction calibration before more physical decoding.
   Mechanism: pooled weighted correlation rewards between-regime target means
   and amplitudes; H3's regime constant already explains substantial association.
   Cheapest test: TRAIN-only regime intercepts and separate momentum amplitudes
   versus pooled intercept/amplitude, then freeze on a new balanced cohort.
   Control: same features/rows, intercepts pooled; reject if component-aware
   pooled WP gain disappears. Inference: input-prefix class probabilities only.
2. Regime-conditioned continuation versus flicker reversion.
   Mechanism: informed-flow persistence in small-quanta regimes, alternation in
   the largest quantum. Test TRAIN-fitted sign/gain per regime at frozen EMA
   spans20/100 versus a common sign; evaluate new own-unseen groups, not H2.
   Match scale, decoder, rows and model capacity. Reject if regime interaction
   fails to transfer. Inference: causal prefix regime and rolling input state.
3. Depletion/replenishment while the price vector is unchanged.
   Mechanism: cancellations/limit arrivals carry queue pressure before quotes
   move. Test lagged volume changes conditional on current price state against
   price-state/activity/trade-slot controls; shuffle within matched strata.
   Reject if added conditional association vanishes. Inference: past/current
   volume changes and event ages. Do not sort mixed columns into depth levels.
4. i1 information arrival after matching i0 history.
   Mechanism: common-factor price discovery rather than local queue mechanics.
   Test lagged i1 event features versus identical i0-only features; include
   reverse-direction and within-regime shuffled-event controls. Reject if only
   contemporaneous association survives. Inference: past i1 events, seq reset.
