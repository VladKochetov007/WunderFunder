## 1. Hypothesis: source-bound loss attribution can be made operationally trustworthy

For this fixed supported recipe, separately differentiated component gradients can
be reconciled with the whole-loss gradient well enough that any claimed directional
conflict is stable under an independently specified precision/operation audit.
This is a hypothesis about measurements, not optimizer performance.

Discriminating experiment: first fix only the JSON projection with tensor metadata
sentinels and canonical named optimizer identities. Independently review the fixed
synthetic-architecture-normal and real-panel-normal case bindings. Only after
controller authorization, compute the existing descriptive FP64 residual of the
already scaled/unscaled main+EMA+struct+next tensors against the whole preclip
reference, streaming parameter blocks. Do not reapply coefficients. Do not read
prestate numerical arrays to serialize metadata; bind their independently reviewed
file identity externally. An optional later operation study would use separate
predeclared whole-loss versus separate-loss differentiation at matching restored
states and a FP32 reference, with independent repeats before inspecting differences.
It must keep source loss branches and target construction identical. CUDA kernels,
precision, loss-scaling order and None participation are part of that protocol.

Failure criterion: any unauthorized access, source/metadata/name/RNG mismatch or
nonfinite/undefined required quantity fails the measurement contract immediately.
For the later precision study, a proposed local interpretability screen is residual
L2/referenceL2>1e-3 in either fixed normal case or a change across precision in the
predeclared conflict category (meaningful shared cosine<=-.1 versus no such witness).
A zero reference has undefined relative error; retain it as a separate null, never
force a finite ratio. This screen is a scientific resolution choice, NOT an accepted
operation-error bound. If independent operation-specific policy cannot be justified,
close attribution and use direct whole-loss interventions instead.

Cost ceiling: metadata correction/review<=8 single-core CPU-hours in900s bodies;
authorized saved-gradient readout<=1GiB live RSS per process; optional operation
study<=2GPU-hours, one8CPU/24GiB family, allocator<=4.8GB and observedVRAM<=5.5GB.
No actual receipt/case is authorized by this plan. Changed view: stable independently
replicated residual/categories permit local force descriptions; instability argues
against reading AMP component geometry as a mechanism. Neither outcome shows a
useful optimizer, loss decomposition into nonlinear updates, or physical coupling.

Minimal tool: versioned metadata projection, source/hash-bound branch compiler,
explicit unused support, preclip/clip/update records and streamed case inspector.
Keep all legacy artifacts and distinguish accepted metadata from accepted math.

## 2. Hypothesis: carried hidden-state inconsistency is a controllable training error

At unchanged current student weights, recomputing the same causal prefix changes
incoming h enough to alter the next whole-loss update beyond its operation-specific
repeat noise. If the effect is material and useful, a bounded state-refresh rule
might improve learning. Retention evidence alone does not imply this hypothesis.

Discriminating experiment: finish the reviewed finite guards and new runtime/caps.
For the frozen query after four warm attempts, compare captured stale student h
with a detached current-student prefix recomputation from the original None state
using exactly four1000-row calls. Hold raw preweights, laggedEMA weights AND incoming
h_ema, student normalization, full inputs, stopped targets, teachers, moments, RNG,
scaler and clocks fixed. Calibrate independent default/reference repeats before
comparing; exact target and discrete-state identities remain mandatory. This is a
single binary local intervention, not reset, EMA-substitution or full-prefix BPTT.

Failure criterion: use the existing state-drift prereg, not a newly fitted one:
hiddenrelative>=.01, predictionRMS>=1e-4, gradientORupdaterelative>=.01, each required
effect>5 times its own independently measured RMS floor. Failure to meet all required
conditions closes the material local claim on these cases; missing/nonfinite state
is INVALID/UNKNOWN, not a null. Zero floor remains exact. Report completions/skips;
(4,0) satisfies the original four-success precommit, amended skip histories do not.

A positive local result changes our view only to “state inconsistency exists here.”
Then freeze one bounded refresh rule, with matched prefix work/teacher exposures,
chunk/update/scheduler/EMA counts and a compute-matched unchanged-state sham. The
month's benefit gate would require paired component-balanced held-out improvement
with a positive preregistered95% interval and no class guard violation on a reserved
component set, fixed final checkpoint and separately replicated seed. If not, close
its predictive-benefit branch even when hidden differences are large. No mature
full-fit or deployment interpretation follows from early panel captures.

Cost ceiling: local binary review/controls<=8CPU-hours and<=2GPU-hours. If admitted,
a single refresh-vs-sham pilot<=6GPU-hours; confirmation budget<=16GPU-hours. Full
prefix recomputation for every update is not assumed affordable. Profile the fixed
rule first; if it exceeds1.25x baseline wall time or fails the5.5GB cap, reject that
implementation rather than silently shorten its scientifically required prefix.

Minimal tool: trajectory-bound initial-state sidecar, named pre/post clocks and
same-state fork/replay. A mature checkpoint must be captured online, never rebuilt
from an EMA export. State snapshots and model predictions answer different questions.

## 3. Hypothesis: gradient credit across chunk boundaries matters independently of state drift

With identical forward history and a common macrostep loss/update clock, allowing
gradients through one midpoint contributes useful learning beyond carrying the
same hidden values with detach. Existing58 controls show the derivative distinction;
they do not show real benefit or a deficit in the strong GRU.

Discriminating experiment: use two source1000-row calls at unchanged parameters,
concatenate their outputs, and evaluate ONE common2000-row four-term loss with
correct common denominators. Fork only midpoint detach versus connected graph.
Neither arm updates weights at the midpoint. Preserve original warm moments,
student and EMA incoming state, target/teacher construction, clipping, one scheduler
and EMA advance and AMP execution/skip semantics. Both arms share the same new
macrostep recipe; comparison against today's two-update recipe is a separate control,
not evidence about detach alone. Connected history is a derivative intervention;
current-weight prefix recomputation with detach in option2 is a state intervention.

Failure criterion: any forward/output/target/denominator difference or differing
attempt/skip clocks invalidates credit isolation. Positive second-half-only and
first-half-only null controls must respectively detect cross-boundary input credit
and show its absence without changing the loss. On the frozen actual cases, require
a whole-update relative difference>=.01 and>5 times independent matched repeat RMS;
otherwise close material credit at this horizon, without claiming all memory is
unimportant. An admitted month pilot fails benefit unless the same independent
held-out/seed gate as option2 passes, under matched macrostep count and wall budget.
Synthetic input derivatives alone cannot pass that benefit gate.

Cost ceiling: review and tiny protocol<=10CPU-hours; actualarchitecture memory smoke
<=10GPU-minutes before a<=8GPU-hour paired pilot and<=16GPU-hour confirmation.
Activation checkpointing may preserve the exact two-call graph but must be reviewed
for autocast/RNG recomputation semantics. If that declared graph cannot fit5.5GB,
stop it: smaller hidden width/batch/horizon would be a new hypothesis, not a rescue.
No broader length grid is included. Changed view: useful paired benefit isolates
credit at the tested horizon; local derivative sensitivity without benefit points
away from “more memory” as the missing improvement.

Minimal tool: one shared macrostep compiler and immutable loss-mass ledger. It
must not average independently normalized half-losses or sum per-loss Muon/Adam
steps. Half-loss averaging already fails the unequal-mass synthetic control.

## 4. Hypothesis: matching chunk mass to its own estimator changes learning beyond generic scaling

In the actual stopped-distilled multi-term objective, self-normalized chunk mass
creates a material directional/relative-force effect that an own-mass-aligned
multiplier can change, beyond seeing the same multiplier distribution shuffled.
The known15.16% CV is a reason to test, not evidence of benefit. Conditional label
covariance and restricted model capacity matter; deterministic full-input outcomes
can leave the optimum unchanged even with large CV.

Discriminating experiment: freeze a small full permitted fit-mixture panel, including
its true batch-dependent allowed-validation weight replacement; source-bind W(main),
R(EMA/structural branch-specific), N(next) and the stopped blended target. At matched
warm actual student states first compute whole-loss updates for default, aligned
s=W/D and a fixed within-matched-batch permuted multiset of s. D is TRAIN-estimated
and frozen before confirmation. Keep sequence/chunk order, clip, teachers, laggedEMA,
other denominators and optimizer/scheduler/update count fixed. Use direct whole-loss
replays if component attribution is unapproved. Aligned s*H/W=H/D; permuted scaling
retains the finite scalar multiset but breaks own-mass association. Auxiliary
amplitudes and clipping mean parameter updates need not be collinear.

Failure criterion: the constant-mass null must be exact; full-mixture reconstruction
must reproduce source weights/targets. If CV<5% on the new preregistered fit-mixture
panel, close its denominator-variation claim there (do not erase old TRAIN CV).
Otherwise proposed local screen: aligned-versus-permuted mean preclip AND actual
update relative difference>=.02 and>5 times independent matched-operation RMS on
the frozen panel. Failure closes this implementation's local materiality branch.
If it passes, one paired aligned/sham fit must meet a positive reserved-component
95% benefit interval, with no class guard violation and separate-seed confirmation.
No benefit or increased variance without benefit closes the adoption branch.

Cost ceiling: streamed mass reconstruction<=12CPU-hours, one process<=2GiB with
bounded rows; local whole-step forks<=2GPU-hours; paired pilot<=6GPU-hours and
confirmation<=16GPU-hours. Match update COUNT, not exact parameter updates: exact
update preservation would preserve the trajectory and nullify the hypothesis.
Changing --loss-norm running alone is not an implementation: norm_ema is unused in
the cached-distillation branch. Labels already clip; no raw-weight bug is alleged.

Changed view: an alignment-specific matched result would support estimator coupling;
equal aligned/sham results would favor generic scaling/noise or irrelevance at the
measured states. Conditional-coefficient variance reduction is a later alternative
only if its learned coefficient bias can be independently cross-fit; do not replace
weights without the matching linear target term. Nearest priors remain E160/E161,
E180 and the stopped-distillation/combined-recipe evidence, not a new optimizer sweep.

Minimal tool: source-derived numerator/divisor ledger and exact masked/teacher target
oracle, covering actual fit-mixture weights. Never silently invent structural D or
transfer default-repeat floors to a changed branch.

## 5. Hypothesis: a transportable observable interaction can be identified without physical prices

A predeclared causal cross-stream history adds future-observable predictive
information after conditioning on current inputs, focal history AND the strong
student state, and the sign/temporal specificity transports across independent
component environments. This would identify an operational predictive interaction,
not a physical connectome edge. The specific half-life16/coordinate/+32 peer test
already failed and is not reopened by changing clocks, horizons or ridge penalties.

Discriminating experiment: only after a separate reviewed input/support census,
define ONE different mechanism class before future outcomes—for example a causal
rank/relative-shape event-state representation, whose transformation invariance is
proved algebraically, with a fixed next-observable event target. Commit the target,
censoring accounting, clocks and component-environment split before extraction.
Use a capacity-matched conditional baseline including own history and frozen strong
state, and matched shifted-history plus environment/stream-donor controls. Audit
positive/null latent worlds and observationally equivalent gauge worlds first.
Count held-out COMPONENTS, not overlapping origins, and retain censored/missing mass.
A simulator passing only in its nominal generator is not a transport guarantee.

Failure criterion: no distinct support/mechanism rationale means no real experiment.
Otherwise require>2% paired held-out component-balanced MSE reduction against BOTH
conditional baseline and frozen temporal/donor controls, positive95% paired interval,
no reversal in predeclared adequately supported freshness strata, and the same sign
in a second reserved environment. Insufficient support/power is UNKNOWN, not a
negative selected into a different target. Failure closes that single representation;
no horizon/filter/coordinate sweep follows. A predictive pass only permits a separate
challenge-target study with frozen targets/fit exclusions; it predicts no LB gain.

Cost ceiling: source/simulator/support work<=24CPU-hours, streamed input panels<=2GiB
per process; one optional frozen-state extraction<=4GPU-hours; downstream testing,
if separately authorized,<=8GPU-hours. Labels/future paths are supervision only.
A causal input code or proxy teacher can be useful without naming physical prices.
Physical identification would additionally require an externally justified encoder,
units/origin/gauge and admissible intervention or additional observables that break
observational equivalence. Predictive ablation, decoder fit or a useful hidden-state
probe supplies none of those; equivalent latent graphs remain indistinguishable.

Changed view: transportable conditional information would justify investigating an
observable mechanism; failed controls would favor model saturation for THIS probe,
penalty/support confounding or absent incremental information. Counterexamples
already rule out the unsupported physical-path interpretation, not all causal
features. Minimal tool: causal feature/suffix canaries, component exposure register,
explicit clock names, censoring ledger and a generator that reports identifiable
versus merely predictive claims separately.

## Sequence, month budget and stopping rules

Week1: freeze identities/projections, resolve independent minimal blockers, reproduce
positive/null source controls and admit at most the fixed numerical/state cases.
Week2: local whole-step state and credit/estimator discriminants, with numerical
review before scientific interpretation. Week3: only ONE best-supported binary
learning pilot; retain all failed/invalid/skip cases and immutable prereg revisions.
Week4: independent reserved-component/seed confirmation, cost/variance accounting
and report the surviving claim at its actual level. Option5's input/support work
can proceed without training; it cannot borrow a negative panel as fresh confirmation.

The option maxima are alternative caps, not simultaneous reservations. Proposed
aggregate month budget<=80GPU-hours plus<=72single-core CPU-hours. At most one GPU
family:8CPU/24GiB host, no swap, allocator<=4.8decimalGB and observedVRAM<=5.5GB.
At most four concurrent CPU families:1core/2GiB each,900s bodies. Combined12CPU and
32GiB reserved host (~34.36decimalGB) leave headroom below40decimalGB and remain
inside the campaign36GiB parent cap. No full-data RAM load; stream shards and bound
activations before admissions. Any resource failure pauses work for controller
review; no unreviewed retry, clock weakening or automatic batch/horizon reduction.
Today’s23:00 deadline still prohibits launching this month plan now. New campaign
resources/deadline/admission require the controller; these are proposed ceilings,
not current bookings or measured runtimes.

The engineering deliverable is small: a versioned source/metadata contract, exact
private-engine RNG validation, named optimizer state, trajectory and clock receipts,
a whole-step fork harness and component-streamed observer. The early false-timeout
incident and six repaired fixtures show why admission provenance belongs in this
contract. Retain pre-admission failures as failures and successful fresh jobs as
new jobs. Backup source/numerics/private context with bounded streaming parts and
actually restore a paused state before claiming recoverability. None of this needs
an orchestration platform, new optimizer catalogue or a speculative physical decoder.
