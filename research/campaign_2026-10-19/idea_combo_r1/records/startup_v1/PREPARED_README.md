# Combo R1: frozen sparse features with one NLL predictor

This is a source-prepared, single-arm CPU screen. It restores the R15 sparse dictionary and its two fit-only normalizers from the separately pinned B-side archive, then trains one seed-19073 256→64 GELU predictor with the unchanged R7 bounded Gaussian NLL. The mean head alone is evaluated with the canonical clipped global WP scorer. R15 dense/sparse predictors are not replayed or regraded.

The fixed primary comparison is the new endpoint minus the stored R15 sparse-WMSE WP, `0.4824412038543008`; the stored dense-WMSE WP, `0.4798730901246624`, is secondary. Per-component and fixed-prediction drop-one contrasts are descriptive sensitivity checks, not replications. See [DESIGN.md](DESIGN.md), [DESIGN_REVIEW.json](DESIGN_REVIEW.json), [SELECTION_HISTORY.json](SELECTION_HISTORY.json), and [PREPARATION_MANIFEST.json](PREPARATION_MANIFEST.json) for the frozen protocol and source pins.

The B runner is `python -m idea_combo_r1.run_probe --sample <B/research_tmp/nf19-sample-r3-v2> --output <new direct child of B/research_tmp> --expected-sample-sha256 b89455ba449f31bb9ebe815976d4da23bb1a8e499e421b6bb5f8d44566f76e64 --expected-preparation-manifest-sha256 <pinned manifest SHA256>`. It expects the R15 archive at `sample.parent/nf19-r15-v1/model_parameters.npz`, verifies its full size/hash and key manifest, then restores only the six fixed raw-input/scaler and sparse-dictionary arrays. It does not load old predictor arrays. The compact R15 result is source-pinned as [REFERENCE_R15_RESULT.json](REFERENCE_R15_RESULT.json).

The source-only checks use synthetic tensors and the compact result fixture. The fresh-process smoke verified all 31 pinned runtime modules and left the NumPy, PyTorch, and PyArrow payload-read sentinels untouched. CPU runtime configuration reported one Torch thread and one interop thread, FP32 default dtype, CUDA uninitialized, autocast disabled, and TF32 disabled. No R3 NPY payloads, R15 model archive, fit, or evaluation were read locally. Test and formatter receipts are in [TEST_RECEIPT.json](TEST_RECEIPT.json) and `records/preparation_v2/`; they certify preparation only, not an admitted or completed B run.
