# Fixed first-cell score consumer

This packet prepares a local-only streaming consumer for the exact first F0, seed-1001, five-arm comparison. It consumes the reviewed feature-only prediction exports and the canonical metric/data/split APIs from source commit `68ff682977b822f38351aac0f621146f5f13b440`. It does not run inference, fit a model, choose an epoch, or make a public-transfer claim. No export bundle, target payload, model, or score was opened or evaluated on this Mac.

The frozen panel is ordered `control/base`, `ema/ema`, `sparse/sparse`, `nll/base`, and `allthree/ema_sparse`, all at epoch 5 and 44,760 successful updates. Its 468 F0 groups are fit-excluded but exposed development groups. The consumer requires the producer's `EXPORT_MANIFEST_V1.json`, all five exact sidecars and FP32 NPY files, matching epoch-5 checkpoints, the fixed split and membership digest, strict FP32 inference metadata, and the exact binding before mapping any prediction file. The split contract distinguishes 20,000 rows per sequence from 1,873 validation row groups.

Scoring streams the canonical `SequenceFile.read(row_group, targets=True, mask=True)` API one 20,000-row group at a time. That source API also materializes features for each group; the scorer discards them with the group object, avoiding a full validation-target or feature-array load. The official selection is `is_scored AND (t >= 99)`. Scores use source `GlobalAccumulator`; paired EMA, sparse, NLL, and AllThree contrasts use source `paired_component_moments` and `paired_component_bootstrap(centered=True, n_boot=2000, seed=271828)`. Groups with no selected rows stay in the ordered panel and bootstrap component array with zero sufficient statistics. The final JSON contains only aggregate per-arm scores, paired interval summaries, provenance pins, and scope limits; it never serializes targets, predictions, or moment arrays.

Before canonical split validation, the consumer bounds the split JSON and membership-cache archive metadata. It delegates membership, graph, fold, and disjointness validation to the pinned `load_campaign_split`. That canonical path may stream-hash registered source files, including large parquet files; it does not materialize the full validation-target array. The six admitted cache and dataset paths are checked against their exact file identities and resolved targets, including the specifically registered cache and datasets aliases; stat-only snapshots are compared before and after split loading and again around scoring. The exact portable registry from the fit launch is byte-pinned and supplied through `WNN_PORTABLE_DATA_MANIFEST`; the pinned `wnn.portability` source is included in the import closure so canonical split validation uses the already-authorized relocated-source checks. The consumer imports only six pinned WNN modules after source-hash checks and isolates the bytecode cache path so existing source-tree `.pyc` files cannot be imported. Prediction sidecars and NPY hashes are all checked before the five read-only mappings are opened.

The report is create-only in the explicitly bound private evidence root and fsyncs the new file and containing directory. The scorer has not been run against B data and is not authorized by this packet to launch itself. Root owns independent source review, fresh B-side path/resource checks, any execution, and the later interpretation. These exposed F0 results and component-bootstrap intervals are conditional on the five fixed models; they are not fresh-holdout, fit-seed, or public-transfer uncertainty.

`dependency_manifest.json` pins this source and the reviewed exporter/binding. `LOCAL_CHECKS.md` records the narrow synthetic parity tests and Ruff checks. The fixture uses only tiny in-memory arrays and the source metric helpers; it does not import the CLI, representation code, model, or dataset payloads.
