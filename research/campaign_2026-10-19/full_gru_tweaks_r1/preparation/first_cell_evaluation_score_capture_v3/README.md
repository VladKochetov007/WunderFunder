# Score result capture V3

V3 is a narrow identity rebase of the independently reviewed score-capture V2 reader. It binds the same unlaunched score-v1 unit to exporter-v3's evaluation-v3 result path and the exact four scorer V5 code pins. The exact systemd `Id` guard, invocation join, admission/launch receipt checks, bounded log tail, and strict successful terminal tuple remain unchanged.

The V3 admission, launch, and invocation literals remain unbound until an actual score launch exists. The reader is local source preparation only; it does not query B, read a result, execute scoring, or claim a metric. Root owns the eventual capture driver and any real receipt binding.
