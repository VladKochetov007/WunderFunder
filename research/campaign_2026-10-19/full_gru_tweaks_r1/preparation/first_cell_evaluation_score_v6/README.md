# First-cell streaming scorer V6

V6 is a local, source-only repair for the V5 scorer’s registered-source observation. The failed score-v1 attempt compared `cache/chain_folds.npz` against an invented static parent target. The accepted registration pins each source leaf’s lexical path, resolved target, symlink status, device, inode, byte count, and modification time; it does not register a cache-parent target. V6 retains every leaf check and instead records the actual parent resolution before and after each bounded observation, requiring the parent resolution and parent device/inode to remain stable during that observation.

The focused fixture uses the exact AllThree fit admission, accepted export binding, actual score-v2 admission, and one root-captured parent diagnostic. The diagnostic showed the cache parent resolving to its physical `/data/cache` directory and the datasets parent resolving to the registered `/WunderFunder/datasets` alias. All six fresh leaf observations match the registered leaf identities. The fixture supplies synthetic filesystem metadata and calls the real V6 leaf observer; it does not read source, cache, target, checkpoint, prediction, or model payloads.

V6 changes only `first_cell_score_core.py` relative to V5. The other three scorer modules remain byte-identical. The V4 exporter, binding, accepted export receipts, and producer review are reused unchanged. This packet has no score admission, worker execution, result, or quality claim; the previous failed scorer unit remains historical and is not queried or retried. Exact pins and the inverse proof are in [`dependency_manifest.json`](dependency_manifest.json) and [`SCORE_V6_REGISTERED_ALIAS_PROOF.json`](SCORE_V6_REGISTERED_ALIAS_PROOF.json).
