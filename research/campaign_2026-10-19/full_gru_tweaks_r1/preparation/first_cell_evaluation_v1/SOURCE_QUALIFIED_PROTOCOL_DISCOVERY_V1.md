## Metric, output, and bounded recommendation

The official metric is `global_wp_clip2_v1`: validate selected values as finite, clip targets and predictions to ±2, weight by absolute clipped target, compute pooled weighted Pearson separately for each of the two target columns, then average the two correlations. It is pooled across selected rows, not a mean of per-sequence scores ([gmetric.py:1–5, 14–17, 23–38, 159–216](../../../../../../WunderFunder-strong-gru-tweaks-20261019/src/wnn/gmetric.py:1)). Apply the canonical scored mask and `t >= 99` warmup ([evaluate_bandit_continuation.py:245–250](../../../../../../WunderFunder-strong-gru-tweaks-20261019/scripts/evaluate_bandit_continuation.py:245)). NLL’s logvariance is a training objective output, not a third official prediction column; the inference helper returns the first two outputs ([training/evaluation.py:38–44](../../../../../../WunderFunder-strong-gru-tweaks-20261019/src/wnn/training/evaluation.py:38)).

For this one fixed cell, a useful report is one official t0/t1/WP and selected-row count per fixed epoch-5 arm, then a paired AllThree-minus-matched-control WP contrast. If component uncertainty is included, resample the manifest’s feature-only successor components with the same draw for both predictions and label it conditional on these fixed models, not training-seed or public-transfer uncertainty. Existing code provides stable per-sequence centered moments and complete-component bootstrap with default 2,000 draws and seed271828 ([evaluate_bandit_continuation.py:32–37, 291–321](../../../../../../WunderFunder-strong-gru-tweaks-20261019/scripts/evaluate_bandit_continuation.py:32); [evaluation.py:10–45, 89–165](../../../../../../WunderFunder-strong-gru-tweaks-20261019/src/wnn/evaluation.py:10)). `GlobalAccumulator` supports stable streaming official scores ([gmetric.py:173–216](../../../../../../WunderFunder-strong-gru-tweaks-20261019/src/wnn/gmetric.py:173)). A narrowly scoped scorer can stream one group or a small fixed group chunk at a time, retain only per-group/per-component centered sufficient moments for the two arms, then run the existing component bootstrap; that bounds raw label/prediction working memory and avoids a full-valid in-memory grade. It must preserve the official centered-moment arithmetic rather than bootstrap raw sums.

Recommendation for a later, separately reviewed evaluation packet: reuse the pinned `predict_run.py`/canonical `predict` representation path for only the exact 468 current F0 evaluation groups, fixed `model_ep5`, and strict FP32; add only a narrow output adapter that writes to a new private create-only destination and binds source hashes, current split SHA, run/checkpoint SHA, representation-state SHA, ordered membership digest, prediction dtype/shape/hash, and sidecar before scoring. Reuse `GlobalAccumulator` and the source’s centered paired-component bootstrap logic in a small evaluator that accepts the eval-only order directly. Do not copy trainer/framework code, use the older default split, score fitting groups, run blend/epoch search, or broaden beyond this fixed cell. No implementation or evaluation is performed here.
