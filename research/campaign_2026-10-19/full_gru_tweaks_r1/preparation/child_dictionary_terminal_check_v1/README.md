It does not require a separate stop receipt for the child native unit; root retains that stop as a later, distinct operation after acceptance.

The frozen scientific identity is sparse dictionary input with WMSE, 467 input columns, a 25-value mean/variance output, six fixed epochs selecting epoch 5, 44,760 updates, and 4,476 batches. It initializes only from the accepted parent checkpoint at `@ep3`. The accepted EMA arm is verified as the required sequential predecessor and is never used as the initializer. The checker reuses the frozen EMA V3, CONTROL V3, parent V3, support, and S5 pure helpers through an exact six-file private closure. It binds the actual dictionary launch receipts, all ten ancestor receipts, source-68 identity, split, cache, data and dictionary stats, restricted checkpoint/state loads, normalizer inheritance, sparse provenance, six histories, optimizer/scheduler/RNG/sample order, and the existing native log. The approved one-path `PosixPath` exception remains scoped to the exact dictionary path and retains `weights_only=True` and `O_NOFOLLOW` state loading.
