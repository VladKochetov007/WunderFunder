# Child all-three profile adapter

This packet prepares one bounded, fit-only profile for the H256×2 all-three child initialized from the accepted parent epoch-3 checkpoint. It invokes the canonical trainer through the source-pinned profile probe; it does not copy or modify trainer code. The child inherits the accepted parent normalization (`--inherit-init-preprocessing`) and does not refit it. The six profile batches make 60 in-memory AdamW update attempts; the probe requires the initial-state hook, then returns before evaluation or checkpoint writing.

The rendered body is `REMOTE_SUBMISSION.py`, generated from `REMOTE_SUBMISSION_TEMPLATE.py`. It binds the accepted parent, exact stop, checkpoint bytes, fold-0 dictionary, homogeneous T3 cache, source manifest, split, and registered-data stats. After fresh read-only gates pass, it creates only `B/research_tmp/fg19_child_allthree_profile_v1` and stages six pinned files there: the parent acceptance and stop receipts, dictionary acceptance, child probe, child contract, and the unchanged `propensity_terminal_support.py` helper required by the probe’s restricted loader. The helper is resolved from private D at runtime. The child run output and unit must still be absent when root executes the body.

The admission requests the selected UUID GPU with one CPU, `MemoryHigh=7.5 GB`, `MemoryMax=8 GB`, no swap, a 4 GiB CUDA allocator cap plus a 1 GB free reserve, one BLAS thread, zero loader workers, and a 600-second runtime limit. It also checks the empty campaign cgroup, foreign GPU processes, physical scratch with at least 25 GiB free, source/data/split/cache identities, and the parent’s 17 GB headroom target. It preserves foreign jobs and does not stage immutable source files.

Local checks are recorded in [LOCAL_CHECKS.json](LOCAL_CHECKS.json). They cover embedded-byte identities, the fixed profile argv, a synthetic parent-checkpoint SHA/stat guard, and a cold import from a temporary private-D-shaped directory. That proof resolves the probe, contract, and restricted-loader helper from that directory while `PYTHONPATH` contains only an isolated source `src` path; it imports neither Torch nor NumPy and calls no checkpoint or array reader. The separate retained proof at [CHILD_ALLTHREE_PROFILE_LOCAL_CHECKS_V1.json](../child_allthree_profile_local_checks_v1/CHILD_ALLTHREE_PROFILE_LOCAL_CHECKS_V1.json) also imports the complete 96-module canonical WNN closure from the pinned source, verifies every origin/hash against the 167-file manifest, and records blocked payload-reader and CUDA-initialization sentinels. It checks the actual parent acceptance/stop metadata and confirms the child CLI inherits parent preprocessing; it does not load a model, optimizer, dictionary, cache array, or dataset.

The contract’s one-field inheritance guard passed its focused test: `test_profile_requires_parent_preprocessing_inheritance` (1 passed). The previous 17-test probe suite is retained as prior evidence and was not replayed after that delta.
