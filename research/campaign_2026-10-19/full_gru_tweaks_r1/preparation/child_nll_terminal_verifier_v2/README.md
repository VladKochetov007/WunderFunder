# NLL terminal verifier V2: selected-GPU ownership gate

This folder preserves a local-only V2 adaptation of the NLL CPU terminal-verifier body. V1 remains unchanged. Its source review found that the exact body did not freshly establish the selected GPU's identity and process ownership before creating the verifier output directory. V2 adds that gate and records its observation in `VERIFIER_ADMISSION.json` before any output mutation.

The selected UUID is `GPU-ec74220d-78d7-cc47-69fc-0de1fb580944`. The gate bounds each `nvidia-smi` query to 15 seconds and 64 KiB per output stream, validates the UUID and memory fields, and caps the process inventory at 256 rows. Per-process cgroup, stat, and same-user command-line reads are capped at 32 KiB, 8 KiB, and 8 KiB. It checks a stable PID inode/UID/starttime around metadata reads. A listed process whose identity becomes unavailable or changes fails closed. Command lines are read only for same-UID GPU processes; a campaign cgroup or same-user command containing the project B path also fails closed. Unrelated GPU owners are recorded and preserved. The gate does not kill processes, require an empty GPU, or reserve VRAM.

The adaptation uses the exact V1 rendered body at 613,694 bytes, SHA-256 `e0cc26f822762a96758bb88046440fc04dc7c9a4651bcc4db3509c072295f3f5`, and applies only the selected-GPU gate: the selector import and UUID constant, bounded observation helpers, the call immediately before `D.mkdir`, and the `selected_gpu_ownership` admission field. The inverse-patch check reconstructs the exact V1 bytes. The V2 body is 621,112 bytes, SHA-256 `15e6057ebe946aa15e9fea9d24fdf1755f55db57772ccabdf690bcef965fd3bf`.

The body still binds the actual NLL native terminal evidence (697 bytes, SHA-256 `ba7db247e84183695181e84a751f222f5b92366019466295388abaf9ca9150e1`), the raw native capture (79,903 bytes, SHA-256 `f3efe3369cfed72ef12b57a7e86290edd195867635ac93468427973a2b777d6e`), and the original fit launch acceptance (2,931 bytes, SHA-256 `44a708fc5a32b101c97a8a28c22e3b15e815059582de564e17f528f5369dc7a5`). It retains V1's six-file checker/helper closure and read-only predecessor gates.

`prepare_v2.py` is a local byte-pinned renderer and AST checker. `test_v2_gate_ast.py` contains five source-only fixtures for the new gate. The local checks verified the exact V1-to-V2 patch, Python AST parsing, call-before-create ordering, and admission recording; Ruff format/check passed on those two local Python files. These checks did not import or execute the remote body or checker and did not access a worker, stage files in B, or start a support unit.

V2 is an engineering candidate for independent source review only. No V2 GPU observation, admission, staging, support submission, or result exists. The parent task owns the next source review and any later actual admission.
