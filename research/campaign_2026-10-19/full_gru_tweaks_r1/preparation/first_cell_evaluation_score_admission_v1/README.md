# Conditional first-cell score admission

This folder prepares a single CPU-only launch for the fixed first F0, seed-1001 comparison after its five prediction-only exports have a root-owned acceptance and exact-stop receipt. The planned local receipt paths and schemas are recorded, but no actual export acceptance or exact-stop files exist yet, so their byte and SHA-256 pins remain unbound and rendering is refused. No B machine was queried and no export, prediction, target, model, cache, or score payload was read here.

The worker is the already-reviewed four-module streaming scorer in `../first_cell_evaluation_score_v1/`. It receives the export evidence root, export directory, binding, source manifest, source root, data root, and create-only `RESULT.json` path as explicit arguments. The export binding, source manifest, export manifest, sidecars, and prediction arrays remain at the existing export evidence root; only the four scorer modules and two root-authority export receipt copies are staged in the new score directory.

The admission template gates exact export acceptance plus stop, the five output and checkpoint metadata joins, source commit and 167-file source set, split bytes, all six registered data identities, the fourteen readonly predecessor receipts, profile/cache metadata, parent and dictionary checkpoint stats, current parent cgroup and disk headroom, selected-GPU ownership, the unused score unit, and absence of `RESULT.json`. It uses bounded standard-library leaves extracted from the reviewed AllThree V5 admission source. Its runtime limits are 50% CPU, 1.4 GB memory high, 1.5 GB memory max, no swap, and 600 seconds; CUDA is hidden and numerical-library threads are set to one.

The required worker arguments are pinned in `SCORE_ADMISSION_BINDING_PLAN_V1.json`. The outer success response is exactly `{unit, outcome, admission_base64, launch_base64}` after durable receipts and one confirmed submission. A timeout or ambiguous submission is retained and never retried. The scorer creates `RESULT.json` exclusively under the existing export evidence root and emits only its compact aggregate report.

`SCORE_ADMISSION_BODY_TEMPLATE_V1.py` is fail-closed with explicit unbound acceptance and exact-stop markers. Its pure metadata gate matches the root acceptance and exact-stop schemas, including strict stop return code, empty command streams, exact unit/invocation, and pre/post systemd state. `render_score_admission_v1.py` refuses to render until ROOT supplies the receipt lengths and SHA-256 pins. The independent source review for the scorer/exporter pair is recorded as a prerequisite; this folder does not claim that source review authorizes execution. No scoring result or quality claim exists yet.
