# R14 same-span EMA coordinate screen

This folder contains the source-pinned CPU screen for H-NF19-18. It asks whether a fixed 128-step exact steepest-descent path reaches a smaller weighted-ridge objective gap after an analytic same-span coordinate change over the 8/32/128 half-life EMA blocks. Both coordinate systems use the same fit rows, normalized raw inputs, predictor span, and equivalent mapped ridge penalty; their finite-step endpoint predictions can differ. The whitening matrix uses the infinite impulse-response Gram; it is not empirical covariance whitening. See [RESULTS.md](RESULTS.md) for the captured outcome.

The intended panel is the accepted R3 sample: 64 fit components with 31,808 scored stride-40 rows for the fit, and 32 eval components with 59,436 scored rows for secondary canonical scores. Histories are computed over each complete sequence before masks and stride. All 96 sequences and their x/y/scored files are hash-checked and mapped for integrity; eval target values are used only for secondary scores after the fixed fit. The code streams sequence histories and retains one preallocated fit design, not all panel histories.

The CLI is `python -m idea_screens_r14.run_probe --sample B/research_tmp/<sample> --output B/research_tmp/<new-output> --expected-sample-sha256 <accepted-sample-sha256> --expected-preparation-manifest-sha256 <manifest-sha256>`. It verifies the manifest, source snapshot, sample and membership identities before loading panel arrays. The prepared runtime closure contains 20 source modules across R14, reused R1/R3 helpers, and canonical WNN files; the exact paths and digests are in [PREPARATION_MANIFEST.json](PREPARATION_MANIFEST.json). [TEST_RECEIPT.json](TEST_RECEIPT.json) records local synthetic/source-only checks. [DESIGN.md](DESIGN.md) and [DESIGN_REVIEW.json](DESIGN_REVIEW.json) define the fixed question and its limits.

The fixed run completed and the B-side output was captured and root-validated. Arm B ended with a higher mean relative objective gap than arm A (0.04997652 vs 0.04348744), so the prespecified optimization-spending gate failed. Secondary pooled WPs were 0.54094749 for A, 0.54259526 for B, and 0.54173284 at the common optimum; these do not change the primary outcome. The exact recipe is closed without retuning. This result addresses only finite-step conditioning for the specified analytic convex objective on one exposed panel; it does not establish strict-FP32 campaign behavior, GRU conditioning, generalization, or public performance. Component and drop-one summaries are sensitivity checks, not independent replications.
