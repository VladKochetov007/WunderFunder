# Bounded screen figures

[screens.png](screens.png) and [screens.svg](screens.svg) show the two target scores for all nine fixed ridge views and the fit-only fixed-horizon operator-association curves. Left axis uses official clipped WP on six exposed evaluation components; right axis is a different retrospective association statistic, not official WP. No trend was fitted, horizon identified or error bars implied.

Figures were generated on Beleriand with [plot_results.py](../plot_results.py), copied as exact raw bytes and visually inspected. Read [RESULTS](../RESULTS.md) for component concentration, different GRU fitting budgets and the matched-panel reference that is not included in the ridge-only bars.

Matplotlib's generated SVG path lines contain trailing spaces. They are retained as captured to preserve the recorded output hash; whitespace checks exclude this generated asset only. Python and authored Markdown checks pass.
