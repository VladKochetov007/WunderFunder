# Bounded screen records

Read the [execution/output table](../README.md#actual-outputs-and-execution) and [independent result review](../RESULT_REVIEW.md). SAMPLE/MEMBERSHIP bind the target-blind selected groups and hashed remote array files. EDA/RIDGE START and DONE bind source bytes, sample, result, timing and memory. RESULT files contain compact summaries only; ridge progress preserves each of the nine fixed completed views. REPORT_REFERENCE checks exact selected labels/order/components against already produced FP32 predictions.

The four CAPTURE_RAW records retain exact remote file bytes as base64 with hashes plus exited unit status before stop. Corresponding decoded files are byte-identical copies; 64-bit nanosecond integers were not routed through JavaScript numbers. Arrays and model weights are not in this folder. Interpretation and data-exposure limits remain in [RESULTS](../RESULTS.md).
