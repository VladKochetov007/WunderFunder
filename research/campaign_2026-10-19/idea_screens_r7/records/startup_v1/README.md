# R7 root startup

The [outer body](remote_body_v1.py) checks the existing F3 pointer/ownership/all populated cgroups, exact quotas/current headroom/physical scratch and create-only output/source paths. It checks all six canonical source hashes before any interpreter import, stages the complete30-pin bundle plus review/test/navigation extras, rehashes every byte, then starts one0.5CPU/high1.4GB/max1.5GB/no-swap/600sunit. [Inline startup](root_inline_v1.py) runs full import/read-sentinel smoke within that unit, then uses execv for a fresh package CLI process with the exact fixed sample/manifest/output arguments. Phases are serial, with one invocation/cgroup and no checkpoint/model loading during smoke. No actual assembly/staging/launch has occurred at this preparation point. Root startup review binds these exact bytes before admission.

The body is a fragment, not a standalone launcher. [Exact assembly source](assemble_transport_v1.py) supplies its stdlib imports and hash-bound base64 CFG payload, embeds the reviewed inline program, compiles the complete script, and writes it once to private local storage. Actual assembly and script SHA are recorded separately before SSH; no script is sent without a launch intent.
