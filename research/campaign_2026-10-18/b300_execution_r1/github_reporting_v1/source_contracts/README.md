# Original GitHub contracts

`pr2.json` and `pr15.json` are API snapshots of the original open draft descriptions and source heads, retrieved through existing authorized Git credentials. PR2 describes matched-compute depth/width research; the executing R01 fixed-budget panel is materially different and gets a separate contract. PR15 describes the native four-arm60-geometry-feature CP30 panel and receives its actual endpoint updates. These files contain contract metadata, not credentials or model data.
