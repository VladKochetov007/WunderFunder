# Contract-scoped automatic GitHub results

The user's 19 October2026 instruction authorizes ten-minute and completion-driven updates to the corresponding experiment PRs. It supersedes earlier publication holds for this narrow reporting task. R01 receives its own fixed-budget draft PR; geometry results remain attached to existing PR15. PR2's matched-FLOPs proposal is not relabeled as executed.

The [R01 contract](../../../experiment_drafts/tabdata-b300-r01/README.md) and immutable source/panel/decision identities define the comparison. [Source contracts](source_contracts/README.md) retain the original PR2/PR15 distinction. The [reporter code](code/README.md) validates existing fit/export/grade receipts, retains negative and rejected evidence, creates separate evidence and weights archives, and publishes endpoint hashes and descriptive matched-cell tables. Full CP30 uncertainty review remains separate. No fit, export, grading, recipe changes, model promotion or merge is performed by the reporter.

The server deployment uses `/data/epanov_s/tabdata/runtime/github-reporting-v1`, durable outbox/cursor at `state/github-reporting-v1`, and archives at `artifacts/github-reporting-v1`. Credential material is outside the repository in a private0600 file; it is never included in comments or evidence archives. A single persistent SSH console is reused. The existing verified GitHub authorization suffices; newly pasted PATs are not needed.

The [systemd units](systemd/README.md) use an ten-minute timer plus filesystem completion triggers, shared nonblocking lock and a20-second debounce. They do not watch heartbeat journals. Each result comment is reconciled by author and deterministic marker before a retry; an ten-minute status comment is updated in place. Failed writes remain in the local outbox and do not affect training. Rate-limit responses defer reporting. Triggers stop after both panels are terminal or after the bounded reporting horizon, following a successful final publication. Deployment receipts will record the actual PR URL, source SHA, initial comment URLs and observed active unit state; preparation alone is not an enabled service.
