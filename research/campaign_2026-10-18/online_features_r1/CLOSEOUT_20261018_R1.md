## What question the work was trying to answer

The motivating idea was that within-sequence market state changes over time, and a causal state estimator or online adapter might let a fixed model respond to a changing regime. Several distinct mechanisms were separated:

1. **Causal input features:** smooth or summarize the current and past raw input; test fixed Kalman/local-trend states, innovations, or fast/slow group scales.
2. **Learned recurrent state correction:** let a trainable recurrent teacher use a gain or innovation-conditioned update, then test whether the information transfers to a conventional GRU student.
3. **Online parameter learning:** update model weights from labels observed during the test sequence. This was not tested. Label maturity and permitted feedback semantics remain unverified, so previous-row predictability is not evidence that usable online targets exist.
4. **Adaptive expert selection/blending:** use early inputs or feedback to choose between known endpoints. Existing fixed and gated mixtures were measured on exposed groups; the tests below did not establish a better candidate.

These mechanisms should not be conflated. A Kalman recurrence or GRU hidden state changes with observations while its weights stay fixed; that is causal state adaptation, not test-time training.

## Ideas and hypotheses that remain open

- **Retained-raw causal teacher features:** allow a teacher to learn when local level, slope, innovation, or uncertainty is useful without replacing the original raw representation. The limited fixed-replacement screen is motivation, not validation. Existing larger handoff: [draft PR #17](https://github.com/VladKochetov007/WunderFunder/pull/17).
- **Innovation-conditioned latent gain:** a task-trained, bounded gain could correct a latent prediction using a causal innovation; the final prize is a better standard-GRU student cache, not merely a higher teacher score. The local code draft is preserved on an unpushed isolated branch and is completely unprofiled/unfit; see the [idea](../../unified/ideas/KALMAN_INNOVATION_GAIN_STATE_GRU_20261018_R1.md), [source assessment](../../unified/sources/KALMANNET_INNOVATION_GAIN_GRU_20261018_R1.md), and [static review](../../unified/reviews/KALMAN_INNOVATION_GAIN_GRU_DRAFT_REVIEW_20261018_R1.md). No PR #22 was created. Existing causal-innovation and predictive-state handoffs are [#14](https://github.com/VladKochetov007/WunderFunder/pull/14) and [#18](https://github.com/VladKochetov007/WunderFunder/pull/18); existing Kalman teacher/student work is #17.
- **Actual online learning:** requires permitted, mature feedback that is observable at inference time, causal update/reset rules, and sequence-safe evaluation. The lagged-row proxy cannot stand in for those requirements.
- **Selective complementarity:** an ensemble can help only if its conditional errors add information and its fixed weights survive source-qualified folds. The tested R3/TL3 blends are negative; heterogeneous teacher/representation directions remain separate hypotheses, not an assumed blend gain.
- **Long-horizon robustness:** early-vs-late behavior is not by itself evidence of a future regime shift or private-set advantage. No clean long-horizon test or private score was measured here.
