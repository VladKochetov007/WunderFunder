# xteam_h4 CPU policies — R1

This folder records a fixed inference-engine comparison for the unchanged original xteam_h4 weights, blend coefficients, callback, preprocessing and dynamic-Q8 weight/activation quantization. The native source is adapted from project revision 7800d304; the shipped A package is retained as the immutable control. Related hypothesis: H-CPU-POLICY-20261014.

- [Results and limits](REPORT.md) describe the implementation, source/build hashes, selected-policy checks, assembly evidence, matrix and recurrent-cell probes, full-sequence callback parity and package checks.
- [Measured receipt](RESULTS_R1.json) records commands, host identity, probe outputs, exact-parity status, archive hashes and package sizes. It contains no competition-host runtime claim.
- [Package inventory](PACKAGE_MANIFEST_R1.json) identifies A/B/C/D/A packages in submission order and their ancestry. Package payloads and raw predictions are stored in the ignored packages/ and probes/ directories in this worktree; A points to the preserved original archive in MAIN.

- [Input export manifest](probes/input_r1/EXPORT_MANIFEST_R1.json) binds all four weight exports and two complete feature sequences to the original archive and validation file. [Native test output](probes/CARGO_TEST_R1.log), [matrix timings](probes/MATRIX_R1.log), [cell profiles](probes/CELL_A_R1.log), [B/C/D cell profiles](probes/CELL_B_R1.log), [C profile](probes/CELL_C_R1.log), [D profile](probes/CELL_D_R1.log) and [EVEX opcode evidence](probes/ASSEMBLY_R1.vpdpbusd.txt) preserve the bounded implementation and measurement evidence.
- The [A control](probes/callback_A/RESULT.json), [B](probes/callback_B/RESULT.json), [C](probes/callback_C/RESULT.json), [D](probes/callback_D/RESULT.json), final [A repeat](probes/callback_A2/RESULT.json), and [rebuilt-A control](probes/callback_A_rebuilt/RESULT.json) receipts bind selected policy, archive/native hashes, complete-sequence prediction hashes, timings and fresh-reset parity. Rebuilt A matches the original callback bitwise on both sequences. Their local prediction arrays are ignored by Git and can be recreated with the recorded script and inputs.
- benchmark_cpu_policy.py checks the selected policy at startup and captures deterministic complete-sequence callback predictions from the official xteam_h4 package interface.
- export_xteam_probe_data.py extracts the original four weight tensors and complete raw-feature row groups into bounded local probe inputs; it does not modify source artifacts or labels.

The task freezes all model and data semantics. A bitwise-equality statement applies only if the complete callback prediction arrays match exactly; otherwise the affected policy is a numerical variant and is labeled accordingly. All supplied validation rows remain exposed through prior campaign work. Public transfer and competition runtime remain unmeasured for these policies.
