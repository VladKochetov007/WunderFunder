# Student shape profile artifacts

This folder holds the bounded profile contract, its CPU-only data preflight, and the GPU one-sequence profile receipt when admitted. The profile harness reads one real clean-F0 sequence and its cached homogeneous target, copies only the H256 control's fitting-derived 211-feature mean/std, and can make one FP32 H192×2 update over rows 0–1999. It is a resource/finite-update check, not a quality fit or architecture-selection result.

- [H192×2 one-sequence profile contract](PROFILE_H192L2_B1_C2000_FP32_CONTRACT_R1.json) freezes the target/cache ancestry, seed-3 sampler order, common normalization, shape, one-update semantics, output limits, source hashes, and 3 GB host/3.5 GB allocator bounds. The original cache's historical H256×2/B16/C2000/six-epoch contract remains unchanged.
- [Profile harness](../../../../scripts/profile_student_frontier.py) performs strict producer identity checks, loads one target row by the producer's fit-row order, and records finite-update and resource evidence. It does not run the legacy cache consumer validator or alter its behavior.
- [CPU-only producer preflight](PROFILE_H192L2_B1_C2000_FP32_PREFLIGHT_R1.json) passed under the 1.5 GB support-process cap using actual F0 train group 37 (`seq_ix=7598721`) and the exact first 16 seed-3 sampler groups. It verified bounded-size cache metadata, target ancestry, split membership/sequence identity and shared H256 normalization hashes; no CUDA update or quality evaluation was performed. The final cgroup current-memory snapshot was 1.500 GB and peak RSS reported by the process was 1.599 GB, so the admitted GPU worker reserves 3 GB for additional runtime margin.
- [GPU one-sequence result](PROFILE_H192L2_B1_C2000_FP32_GPU_R1.json) is the intended output of the separately admitted CUDA update. It does not exist yet; root owns the GPU admission and launch.

The preflight does not recompute the 1.69 GB target array's whole-file hash. It binds the producer metadata's expected file SHA, validates its exact ordered fitting row-group list and hashes the sampled target row. Full payload validation remains part of the later training-consumer adapter, not this small profile. The input contract caps cache-metadata reads at 512,000 bytes before parsing.
