## Confirmed claims

1. **Population weighted-MSE / weighted-Pearson link is correctly bounded.** The official scorer clips selected targets and predictions to ±2, then uses `w = abs(clipped target)` and pools moments per target. Under that fixed population and weight measure, weighted Pearson is ordinary correlation under the reweighted distribution Q; `E_Q[Y|X] = E_P[wY|X] / E_P[w|X]` is both the weighted-MSE minimizer and a maximizing correlation direction (assuming nonzero variance and positive conditional weight). The report does not claim that this makes the actual training update equivalent to metric optimization. `primary_pair_wmse` additionally multiplies by `row_weight`, normalizes each ordered batch by that batch's total weight, and the fitter updates AdamW after each 8,192-row batch, retaining the final tail. Finite capacity, shared two-target parameters, row weights, per-batch normalization, regularization and the in-sample-parent residuals therefore remain real differences. This is the right distinction between a population identity and the implemented finite training procedure.

2. **A is described accurately and the missing control is real.** The state code uses 211 raw/event columns plus 208 relation columns (419 total). A forces slope to zero but keeps updating the decayed mean state; after maturity it supplies movement, forecast/mean and error features. The readout is a zero-initialized residual with prediction `parent + 0.1 * residual`. Thus A is not a no-history/raw-only arm, and the loss against parent is not caused by an absent residual path. The proposed Z control retains the same 211 base inputs and readout width while zeroing all 208 state slots. That is a useful capacity/control comparison, with the report correctly noting that equal parameter count does not ensure equal active feature geometry.

3. **F0/F1 scalar interpretation is accurate and appropriately limited.** F0's parent WP is `0.6811541494`; every raw head is lower, with best raw head `0.6806097840`. Applying the fixed extra 0.1 correction yields parent-relative point deltas from about `+0.0001290` to `+0.0001362`; all reported conditional component intervals cross zero. F1's parent/raw/shrunken WPs are `0.6699228637`, `0.6683554506`, and `0.6699181675`; the shrink delta is `−0.0000046962` with interval `[−0.000112863, +0.000109508]`. The result receipts identify both as exposed development evaluation. The two cells vary fold and fitting seed together, so they do not estimate a fold effect or a seed effect separately. The report does not convert these fixed-prediction intervals into training or public-transfer uncertainty.

4. **The four-fit screen is stated consistently in the final proposal and cards.** H-ASTRA24-FUND-02 calls for two cells (F0/F1), each with one Z and one A fit: four total new small-head fits, zero new parent/GRU/teacher/student fits, reusing two exact parents and caches. It requires seed identity, membership, ancestry and cache checks before execution, keeps the in-sample residual-fitting regime fixed, and says explicitly that evaluation remains exposed. The earlier [initial reframe](INITIAL_REFRAME_R1.md) contains a provisional six-fit idea, written before feasibility review; the README and final report make clear it was superseded. Root should treat the final four-fit proposal as canonical if it is carried forward.

5. **The clock claims match the scalar receipt.** The cited geometry result covers 96 fixed validation sequences, 1.92 million rows and 192,763 selected rows; it reports 65 observed event-pattern classes and 14.3923% / 11.5332% age disagreement for the specified seven-group / nine-family constructions. The receipt records no target reads. The report labels these as exact float32 change proxies and row-count ages, not physical time, future equality, missingness, or evidence that a clock improves prediction. It also correctly notes that the parent already includes causal event features and that feature indices do not establish book-depth semantics.

6. **The 10%/25% screen is not misrepresented as a clean fidelity experiment.** The cited PR summary reports the cell deltas and states that both fidelities used full 20k sequences, six epochs and OneCycle; changing support size changes component/example exposure and the number of optimizer updates and schedule progress. The report says this confounds data diversity with optimization exposure, marks the reused/nested cells as exposed, and avoids assigning the reversal to one cause. The source-reported four-fit 6.18-hour estimate is correctly described as an extrapolation, not a measurement.

## Nonblocking qualifications for any follow-up

- The proposed fidelity control should say **equal total optimizer updates and LR progress**, not simply “equal exposure.” Matching total updates still changes per-example revisit frequency, data diversity and the amount of sequence history represented. It tests the p10/p25 contrast at matched optimizer-step budget; it does not isolate every meaning of exposure. This is a qualification to card 05 and report question 6, not an error in their description of the existing screen.
- “Clean parent/cache cells” in the four-fit proposal means source-qualified fitting/evaluation separation, not fresh evaluation. The report and cards elsewhere correctly state that all folds are exposed. Keep that qualification beside any later handoff to prevent “clean” from being read as an untouched holdout.
- The underlying historical panel remains incomplete and its parent ancestry/precision remains unchanged (including the declared historical AMP/FP16 ancestry). Reusing those parents does not improve ancestry or erase prior exposure. The F0/F1 outcomes are one cell apiece, with fold and seed confounded; the four new heads would add two treatment/control pairs, not two fresh independent evaluation panels.

## Limits of this review

I checked source text and scalar/metadata receipts, not the underlying feature, prediction, target or model payloads. I did not verify inference parity, rerun the grades, review the separate direction-probe implementation, or establish causal effects. The report's primary-source literature analogies were used only at the bounded scope stated there, not as evidence of local transfer.
