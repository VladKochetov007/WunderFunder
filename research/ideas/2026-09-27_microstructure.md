# Microstructure hypotheses for class-3 quiet rows — 2026-09-27

## Decision context

The production comparator is the two-seed EMA-4 GRU at leaderboard 0.6618, with pooled `|y|`-weighted Pearson and predictions clipped to ±2. Class 3 is the useful target: its label is almost entirely the **sign of the first future i0 mid move** (E-079, E-162), although its exact construction averages the next four i0 price events. Dense-scored sequences are hard partly because scored rows are spread through long i0-quiet intervals: about 77% of the sparse/dense class-3 gap is explained by future distance to the next price event (`research/panel/physicist.md`, F1). That distance is a diagnostic **only**; it cannot be used at inference.

The key statistical unit is a quiet interval ending in one i0 price move, not each scored row. Long intervals contribute many copies of the same outcome: class-3 episodes with at least 33 scored rows carry 66% of dense-tercile metric weight (`physicist.md`, F3). All falsifiers below use the existing chain-grouped held-out folds, report both the actual row-weighted WP delta and an episode-cluster bootstrap, and require the same sign on both fold halves. Fit any decoder, coefficient, threshold, or calibration only on training folds. Evaluate on all scored rows for the contest metric; use the `33–128` and `129+` **future** distance bins solely to diagnose where a gain came from. They cannot gate a submitted prediction. These are proposals, not measured gains; no model or check was run for this note.

## Ranked hypotheses

### 1. Cross-asset **flow shock after an i1 event**, conditional on an unchanged i0 quote

**Mechanism and feature.** When i0 quotes stand still while i1 reprices, i1 order flow may reveal information before i0's queue reaches depletion. The causal state at row `t` is the decoded cumulative i1 mid displacement since the last i0 price event, plus a signed i1 volume/OFI shock over the last 4 and 16 *i1 events*, an indicator that the latest i1 event followed the most recent i0 price event, and elapsed `a6` time since that event. Set a missing-code flag rather than silently imputing an unknown i1 price transition. Apply a fixed smooth weight such as `1-exp(-N_i1/4)` so a zero-event interval cannot create a spurious lead. Fit a class-3 sign residual or provide these as class-3-specific inputs; retain the ordinary model output for the other classes. Lagged cross-asset OFI predicts future returns in Cont, Cucuringu and Zhang, while its effect decays quickly; contemporaneous cross-impact is much weaker once own multi-level OFI is included. [Primary paper](https://arxiv.org/abs/2112.13213).

**Exact cheap falsifier.** On cached class-3 validation predictions, compute the above state causally. Within each held-out chain fold, residualize next-i0-move sign and each candidate feature against the frozen two-GRU direction, current i0 ICA imbalance, and elapsed `a6` using ridge fit on the opposite folds. Test the residual slope and its episode-cluster 95% interval on *midpoints* of intervals with at least 33 rows, then compute the contest WP delta from one cross-fitted, clipped additive correction. Kill if the pooled midpoint slope's interval includes zero **or** either fold half has nonpositive full-WP delta. Cap the correction search to one predeclared coefficient per feature horizon.

**Likely gain / risk / overlap.** Speculative global gain `0–0.0007`; the full-scale i1 displacement probe was only `+0.02–0.04` partial correlation on far rows, with an estimated global upper bound near `+0.0007` (E-149). A few-sequence study overstated this effect (`physicist.md`, F5). This idea differs from the failed `i1_cross` linear family (E-088) by conditioning on an unchanged i0 quote and by using i1 *flow shocks* in i1 event time. If the cheap test fails, close class-3 i1 lead rather than expanding the encoder.

### 2. **Refill-versus-depletion race** from queue changes, measured in event time

**Mechanism and feature.** Level imbalance is already strong near a move; the remaining possibility is a change in *hazard* while the displayed queues stay large. Decode the two touch-size proxies from the train-fitted class-3 ICA factors (E-090). At each i0 **volume** event, estimate bid and ask queue innovations `Δq`; maintain separate EWMAs over 8 and 32 such events of positive refill and negative removal on each side. Candidate pressure is `log((removal_ask + ε)/(refill_ask + ε)) - log((removal_bid + ε)/(refill_bid + ε))`, multiplied by an inverse-depth or normalized queue-ratio term. Reset only the queue *reference* at a decoded price event, not the whole recurrent state. Cont and de Larrard derive next-move direction and duration from queue sizes and order-arrival/cancellation rates; Huang, Lehalle and Rosenbaum model the book as a queueing system within fixed-mid periods. [Queue-race paper](https://arxiv.org/abs/1104.4596), [queue-reactive paper](https://arxiv.org/abs/1312.0563), [queue-imbalance evidence](https://arxiv.org/abs/1512.03492).

**Exact cheap falsifier.** First require the decoded innovations to have stable bid/ask orientation on train-only reconstruction and fewer than 5% invalid touch states in held-out class 3. Then fit a two-parameter logistic next-move model on *one row per interval* (midpoint), controlling for current ICA imbalance and the frozen GRU direction. Check held-out episode-level log loss and class-3 full scored-row WP after adding a cross-fitted, clipped residual correction. Kill if midpoint log loss fails to improve by at least `0.002` in **both** chain halves, or if the full pooled WP delta is nonpositive. This check is linear/logistic and CPU-light; no GRU training is needed.

**Likely gain / risk / overlap.** Speculative global gain `0–0.0010`; near-event information may be fully exhausted already. E-090 found ICA imbalance AUC `0.62` far from moves, E-100's symbolic queue terms track about 90% of GRU class-3 direction, E-088 depth features added no linear lift, and the three-sequence midpoint proxy screen changed sign (`physicist.md`, F4). The new test asks whether **conditional refill and removal rates** add information beyond those levels. ICA factors are mixtures, so `Δq` need not equal physical order counts; treat the race formula as a feature hypothesis, not a literal reconstructed book.

### 3. **Flow surprise** across touch and deeper levels, separated by causal event clock

**Mechanism and feature.** A quiet quote can accumulate pressure through additions and cancellations without a price change. Use the train-fitted linear inverse of the 22 i0 volume codes only if stable; otherwise work in its low-rank bid/ask factors. For each i0 volume event, form signed touch OFI and an integrated 2–3-factor deeper OFI. Subtract the factor's own trailing 32-event EMA to isolate *surprise*; aggregate surprise over 4, 16, and 64 i0 volume events, with a parallel real-time decay using `a6`. Keep a distinct flag for trade-associated updates. Cont, Kukanov and Stoikov find best-level OFI explains contemporaneous price changes more robustly than trade volume; Xu, Gould and Howison find deeper levels add information for contemporaneous price formation. The prediction extension here is an inference, since those results do not establish residual forecast value in this dataset. [OFI paper](https://arxiv.org/abs/1011.6402), [multi-level OFI paper](https://arxiv.org/abs/1907.06230), [deep OFI paper](https://onlinelibrary.wiley.com/doi/10.1111/mafi.12413).

**Exact cheap falsifier.** Build a fixed `3 horizons × 2 clocks` feature matrix from past-only rows. Fit ridge residual corrections on chain folds, once with touch factors and once with touch plus deeper factors; choose the regularization on training folds only. Require a positive full pooled WP delta versus the frozen two-GRU pair and a positive *incremental* delta from deeper factors on both held-out halves. Also report the same comparison on quiet interval midpoints to guard against near-move gains merely duplicating the GRU. Kill if either positive condition fails. No new model training is needed for this screening.

**Likely gain / risk / overlap.** Speculative global gain `0–0.0008`. The earlier broad heuristic library failed as GRU inputs (E-089), depth residual lift was flat (E-088), and splitting trade flow by immediate price impact was harmful for class 3 (E-112: `-0.0068` to `-0.0085` class-3 delta). This proposal is narrower: stationary **volume-event innovations**, explicit event and real-time decay, and a deeper-factor increment. A positive contemporaneous OFI relation alone is insufficient; only held-out future-move residual lift matters.

### 4. **Event-level first-move head** with interval-balanced supervision

**Mechanism and target.** The scored target is copied through many quiet rows, while the physical outcome is a single first i0 price move. Add an auxiliary binary head for the sign of that next move, supervised at each row but weighted so each interval has total auxiliary weight one; preserve the main pooled weighted-Pearson objective and original `t0/t1` outputs. At inference, use only the causal head probability and current decoded spread to make a small, globally calibrated correction to the two target outputs, clipped to ±2. For training, an interval's length and future outcome may define the *training weight/label*, but no future interval length, distance, or event indicator enters the inference feature vector. This follows the event-clock construction in the official [DeepLOB author repository](https://github.com/zcakhaa/DeepLOB-Deep-Convolutional-Neural-Networks-for-Limit-Order-Books) and the path-target idea in the authors' [multi-horizon paper](https://arxiv.org/abs/2105.10430) and [repository](https://github.com/zcakhaa/Multi-Horizon-Forecasting-for-Limit-Order-Books); the exact first-move target and interval weighting are specific to this contest.

**Exact cheap falsifier.** Before any training, compare the frozen GRU's direction with first-move sign on one row per interval, split by causal elapsed-since-last-i0-event deciles. If its held-out episode-level calibration slope is within `[0.95,1.05]` and a cross-fitted one-parameter event-probability correction changes full WP by at most `0.0002` on both folds, stop. If there is headroom, one future training arm should be judged by full pooled WP and by unique-episode log loss; a better event loss with worse pooled WP is a failure.

**Likely gain / risk / overlap.** Speculative global gain `0–0.0008`; training cost is high, so rank fourth. The existing next-change auxiliary head helped the older recipe (E-097), but auxiliary second/fourth change horizons failed (E-107), EMA teacher targets failed (E-174), and down-weighting deep quiet stretches helped EMA-4 (E-182). E-162 found the first-move sign agrees with class-3 winner labels about `99%` and the GRU is already locally martingale-like within stretches. Thus the test specifically asks for *episode calibration* and avoids another generic horizon head.

### 5. **Post-move state transition** for the four-event readout

**Mechanism and target.** For class 3, the first move usually fixes direction, but the official score uses the rounded mean of four future i0 price events. If the first move is already predictable, the residual may depend on whether a price move is followed by continuation or reversal. Build a tiny train-fitted transition table from decoded class-3 price states: `(current spread state, last decoded move sign, last move trade-associated flag, i0 queue refill asymmetry) → P(next move sign)`; shrink cells toward a global prior by episode count. Propagate the two-state transition probabilities for four event steps to compute an expected target `F` and then map it through the established class-3 target law. Cont and de Larrard model the autocorrelation of price changes as a function of the book's reset state; the queue-reactive model treats a price change as a transition between fixed-price periods. [Price dynamics](https://arxiv.org/abs/1104.4596), [queue-reactive model](https://arxiv.org/abs/1312.0563).

**Exact cheap falsifier.** On held-out chains, compare the table with a first-move-only reconstruction using the **same** oracle first-move sign. Measure incremental weighted target MSE and full pooled WP of the oracle reconstructions, without refitting the GRU. Kill if the extra three-event transition law adds less than `0.001` full WP with that oracle, or if either chain half loses. This is an *upper-bound check*; if it passes, only then test a prediction-driven correction against the frozen two-GRU pair. Fit table counts exclusively on training chains and include unknown-state fallback.

**Likely gain / risk / overlap.** Speculative global gain `0–0.0005`. E-079 already identified the four-event law, E-162 says the first move agrees with the winner roughly `99%`, and a class-3 tick-grammar Markov model is already listed as an open branch in `research/tree.md`. This idea therefore has low priority unless the oracle readout check exposes genuine four-event residual headroom. Sparse transition cells and train/valid instrument shift are major risks; a generic GBM class-3 residual correction overfit badly (E-096).

## Practical order

Run the **read-only** CPU falsifiers for 1–3 in that order, using existing cached predictions and no model training. Check the upper bound in 5 and the calibration screen in 4 only if the cheap first three screens do not settle the quiet-row question. A candidate is worth a training slot only after it adds residual information on distinct intervals and improves the actual pooled metric across held-out chains. None of the gain ranges above is a measured improvement, and their upper ends should not be added together.
