# Autonomous local geometry continuation

[Registered R3 plan](plan.json) resumes the local GPU loop under the user’s explicit continue instruction. It compares the same four causal feature arms for eight epochs at H128×2, three paired seeds and fixed final checkpoints. This tests a longer total optimization budget with its corresponding cosine clock, not duration alone. The same tiny fitting pool and exposed evaluation remain limitations; no quality result is claimed at registration.

Source/data/preprocessing are reused from the [frozen R2 packet](../moment_geometry_r1/README.md). Exact execution, progress, artifacts and independently checked results will be linked here as they land. The separate team experiments remain owned by the team.

## All-eligible membership for the next from-scratch comparison

[all_eligible_membership_20261017.json](all_eligible_membership_20261017.json) freezes every eligible complete fitting component in folds 2/3 and every valid-bearing evaluation component in folds 0/1. The membership was generated from the two small, hash-pinned chain caches and trusted source manifest only; the generator recorded zero Parquet reads. It contains 1,645 fitting components (6,231 sequences: 5,283 train and 948 valid) and 290 evaluation components (925 valid scoring sequences). The evaluation components have 144 train-source counterpart sequences across 41 components, all held out from fitting. There is no fitting/evaluation component overlap. Train row group 528 is absent from the chain cache; the selector excludes it and its fitting component if it appears in a later cache.

The metadata pass used 74,924 KiB peak RSS and 0.57 seconds; its cache payload bound is 8,000,000 bytes. The staged arrays would require 65,405,955,776 logical bytes for raw inputs, labels, masks and indices, 132,242,880,256 bytes for base 231-channel inputs, and 155,142,080,256 bytes for the 271-channel dictionary inputs, totaling 352,790,916,288 bytes before filesystem allocation rounding. Physical scratch had 111,580,381,184 bytes free at inspection, so the full expanded array stage does not fit, even for the base feature array alone. No Parquet stage or fit was started. The exact one-sequence streaming and page-cache release path is implemented, but its expanded-scale RAM use remains unmeasured. These folds are previously exposed; no significance or quality result follows from this metadata artifact.

A one-fit/one-evaluation NPY size fixture matched the estimator exactly: 18,281,312 raw-stage bytes, 36,960,256 base-feature bytes and 43,360,256 dictionary-feature bytes. With the untouched memmaps sparse, physical allocation was 98,304 bytes; this checks logical size accounting only, not staging throughput or data values.
