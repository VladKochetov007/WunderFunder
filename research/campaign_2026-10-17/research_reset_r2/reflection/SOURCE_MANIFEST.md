# Primary-source manifest for the bottleneck reflection

Lookup date: 2026-10-17. Sources were checked after the Round 1 framework was committed and before the R1 card/review set was opened. Five primary works were selected for explicit-duration state models, latent state persistence, event-time memory, Rao–Blackwellized filtering, and learned sequence-memory compression. Their results motivate operators and distinctions; none supplies evidence of a score gain on WunderFunder.

| Primary source | Claim checked in the source | Use in this reflection | Transfer boundary |
|---|---|---|---|
| Sunita Sarawagi and William W. Cohen, [“Semi-Markov Conditional Random Fields for Information Extraction,” NeurIPS 2004](https://papers.nips.cc/paper_files/paper/2004/hash/eb06b9db06012a7a4179b8f3cb5384d3-Abstract.html), [paper PDF](https://proceedings.neurips.cc/paper/2004/file/eb06b9db06012a7a4179b8f3cb5384d3-Paper.pdf). | Their semi-CRF assigns labels to segments rather than individual sequence elements and permits segment-level features / non-Markovian within-segment behavior. | Supports the conceptual distinction between hidden-state duration and per-row output: a latent state may persist while observations and outputs continue. Motivates a duration-bearing state as a future high-risk alternative to fixed event-age traces. | The source task is structured labeling / NER. It does not establish piecewise-constant targets, a correct event clock, or the usefulness of a semi-Markov predictor for continuous, clipped WP regression.
| Emily B. Fox, Erik B. Sudderth, Michael I. Jordan, and Alan S. Willsky, [“A Sticky HDP-HMM with Application to Speaker Diarization,” *Annals of Applied Statistics* 5(2A), 2011](https://people.eecs.berkeley.edu/~jordan/papers/AOAS395.pdf), [DOI](https://doi.org/10.1214/10-AOAS395). | The paper adds a self-transition bias to address rapid switching / over-segmentation of latent speaker states in the HDP-HMM. | Separates persistence of a hidden regime from persistence of an observed numeric target. It is a primary basis for discussing latent state duration without assuming target labels are held between observed events. | Speaker diarization’s latent identities and emission model differ from these market inputs and targets. The method does not imply the target itself is a hidden Markov state or that self-transition gates improve WP.
| Hongyuan Mei and Jason Eisner, [“The Neural Hawkes Process: A Neurally Self-Modulating Multivariate Point Process,” NeurIPS 2017](https://proceedings.neurips.cc/paper_files/paper/2017/file/6463c88460bd63bbe256e495c63aa40b-Paper.pdf), [arXiv record](https://arxiv.org/abs/1612.09328). | The model represents discrete event streams in continuous time; recurrent hidden state drives event-type intensities that can self-excite or inhibit over time. | Supports a narrow analogy for event-time / waiting-time state and the distinction between event rate and a hard event gate. | WunderFunder data provides discrete row order, not documented wall-clock times, and its target is an anonymous future movement rather than a supplied event process. No causal interpretation or predictive transfer is assumed.
| Arnaud Doucet, Nando de Freitas, Kevin P. Murphy, and Stuart Russell, [“Rao-Blackwellised Particle Filtering for Dynamic Bayesian Networks,” UAI 2000](https://www.cs.ubc.ca/~murphyk/papers/rbpf_uai00.pdf), [author archive](https://ora.ox.ac.uk/objects/uuid:7dbf5fe6-8e61-4e74-9075-bcacd9585527). | When a state-space model has a conditionally tractable substructure, it can be marginalized analytically while sampling only the remaining latent variables, reducing the sampled state dimension. | Clarifies the real prerequisite for a Rao–Blackwellized state estimator: an explicit, exact conditional factorization. This is different from applying a smoothing filter to labels or adding an informal uncertainty head. | It is a filtering/inference method for specified probabilistic graphical models, not a generic neural model improvement. No suitable tractable latent decomposition has been shown for this task, and the cited work does not address the official WP objective.
| Jack W. Rae, Anna Potapenko, Siddhant M. Jayakumar, and Timothy P. Lillicrap, [“Compressive Transformers for Long-Range Sequence Modelling,” ICLR 2020](https://arxiv.org/abs/1911.05507), [OpenReview paper record](https://openreview.net/forum?id=SylKikSYDH). | The authors propose compressing past memory in an attention model for long-range sequence tasks and report language, speech, and a reinforcement-learning memory task. | Supports learned approximate history compression as a distinct representation family, while keeping it separate from exact duplicate-row skipping. | The evaluated domains, objectives, and compute differ. The R1 finding of no adjacent identical full vectors in a 256-sequence sample neither validates nor refutes learned compression. No quality or CPU benefit transfers.

## Retrieval notes

The first-party conference or author-hosted paper pages were opened for the claim checks. OpenReview’s PDF endpoint presented a browser challenge for Compressive Transformer, so the abstract and title metadata were checked against its arXiv preprint record, which contains the same primary work. No paper code, external dataset, pretrained artifact, or outside-market data was fetched or executed. Search-result pages and secondary summaries are not used as evidence in the reflection.

## Why these sources were chosen

- **Event-time / semi-Markov:** variable-duration latent states are the needed distinction for “quiet feature clock” versus “state lasts,” but the observed target event need not define the latent segment.
- **Persistent states:** a self-transition prior explicitly models persistence of a latent class, which makes it useful for avoiding the label-versus-state conflation.
- **Rao–Blackwell:** the method’s analytical-marginalization condition directly constrains a coherent high-risk state-estimation proposal and prevents using the term as shorthand for any smoother.
- **Sequence compression:** a learned memory mechanism illustrates that no exact repeated rows does not imply no compressible history, while offering no direct evidence for the same mechanism here.
