# R2 exception audit

This directory contains the full no-fit exception census, its source script, stable input hashes, split checkpoints, and an interpretation report. The primary human-readable result is [REPORT.md](REPORT.md); the complete machine-readable aggregates and all 1,253 exact raw need-eligible exception records are [results.json](results.json) and [exception_records.jsonl](exception_records.jsonl).

The analysis reads only four selected price-code columns (`i0_p0`, `i0_p11`, `i1_p0`, `i1_p11`), the two target columns, sequence/step metadata, and official masks. It does not read all 112 model features. The retrospective H-002 market class appears only as an exploratory result stratum. `i0 AND`/`OR` reconstructions use actual future-in-sequence labels at event times and are strictly oracle diagnostics, not legal predictors or score estimates. Training, fitting, optimizer steps, and model inference were not performed.

The full successful run was on Beleriand using `exception_audit.py`; see [run_attempt2.log](run_attempt2.log) and [manifest.json](manifest.json) for command output, exact source/data/script/output hashes, resource use, and split-checkpoint hashes. [preflight_write_test.json](preflight_write_test.json) records the synthetic no-fit final-writer check. Per-split recoverable aggregate snapshots are [train](split_aggregates/train.json) and [valid](split_aggregates/valid.json). The failed first finalization is preserved for audit in [its log](attempt1_failed_finalization.log) and [its 1,253-record output](attempt1_failed_finalization_exception_records.jsonl); the successful second pass is the authoritative result.

The source files and result artifacts are also present on the physical Beleriand research disk at `/home/grinchenkoeg/wunder_research_reset_20261017_r2/exception_audit/`. R1 recorded no Parquet content hashes, so the newly calculated data hashes establish the identity of this R2 run only; they cannot prove byte-for-byte equality to R1 inputs.
