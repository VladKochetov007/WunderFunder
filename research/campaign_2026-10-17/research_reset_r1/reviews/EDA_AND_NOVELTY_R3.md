### Additional implementation caveats

- `stream_audit.py`'s `target_changes`, `target_changes_without_i0_and`, and `target_run_quantiles` compare labels over the whole sequence. They are not masked by `need_prediction`; its age-weight arrays and label moments/zero/clipped summaries are masked by `need`, while valid `joint_scored` uses `need & is_scored`. Compare exception rates to `full_event_audit.py` only after aligning masks. The latter correctly masks its exception count by `need`, then separately reports `outside_and_scored`.
- In `full_event_audit.py`, `outside_and` means “a target changed on a need row without both selected i0 price components changing.” `outside_or` and `outside_both_instruments_or` concern only the four selected price-code columns, not all features belonging to either instrument. Keep those names literal; the metrics cannot establish that no other input feature changed.
- The all-sequence script stores only the **maximum** absolute target delta outside the conjunction per sequence/class and keeps the first 25 examples in row-group order. That is insufficient by itself to substantiate “all 1,253 full-scope exceptions are tick-scale” or characterize their size distribution. The compact `event_exceptions.json` lists the earlier 52 sampled exceptions, not all full-scope exceptions. The root's tick-scale statement applies to that sample; add exact full-run counts at predeclared tick thresholds (and minimum/quantiles, or a bounded complete list if the set is small) before extending it to the full scan. The first 25 examples are not representative.
- `full_event_audit.py` assumes each Parquet row group is one sequence (it checks length 20,000 and records only the first `seq_ix`, but does not assert all values match). That matches the documented layout, yet an explicit constant-`seq_ix` assertion would make the audit self-checking. It is not a blocker if the storage contract has already been independently verified.
- Before the first `i0_price_and` transition, `age` is counted from row 0 via the sentinel. This is a valid sequence-start fallback for a feature-age summary, but the report should distinguish “no prior conjunction yet” or document left-censoring; it should not imply an event occurred at row 0.
- `raw_identical_run_quantiles` are computed per sequence and then averaged by `aggregate`; the label “mean sequence quantiles” is accurate. They are not pooled row-run quantiles. Likewise the lag table is a set of event co-counts, not a correlation, conditional rate, or uncertainty estimate.

## Additional mechanism screen beyond the 24 cards

The two round-2 reviews already retain six synthesis ideas: reset-local soft innovation memory, cross-stream order kernels, event-paced selective memory, point-distribution distillation, prefix-calibrated masked robustness, and a causal teacher-to-student route. The four ideas below avoid simply renaming those combinations. They are future hypotheses only; all cheap gates are proposed and unrun.

### 1. Input-derived component-symmetry encoder with an identity escape path

Treat the stable `p`, `v`, `dp`, or `dv` component columns as indexed sets, not as physical depth. A shared permutation-equivariant encoder processes a feature family, with a separate identity-preserving residual path so the model can retain genuinely component-specific behavior. A more selective version constrains only a subgroup of component permutations that pass an input-only symmetry test on allowed training sequences. This is different from a graph over channel pairs: the hypothesis is that certain anonymous components share a transformation law, not that a selected edge graph carries influence. It also sharpens the existing grouped-input family into a symmetry constraint rather than a generic grouped encoder.

**Legal boundary.** Learn any fixed symmetry artifact from permitted training inputs only; keep stable IDs available to the residual, use no physical depth order, no targets to select permutations, no external data, and no hidden state shared between sequences.

**Cheapest no-fit falsifier.** For each predeclared within-family permutation, compare per-sequence marginal, lag-profile, and pair-dependence summaries across disjoint halves. If candidate symmetries fail to recur across sequences/halves, do not impose them. Conversely, symmetry of input statistics alone does not establish label invariance; any later supervised use still needs an authorized matched test.

**Counterevidence and dedup gate.** HLOB/anonymous graph proposals and grouped input encoders already exist. The old local evidence also warns against assuming channel semantics from adjacent IDs. Retain only the testable subgroup-equivariance constraint with its identity escape path; drop generic graph message passing or full permutation invariance as duplicates/overconstraints.

### 2. Within-sequence suffix-motif retrieval over feature-change symbols

Maintain a bounded suffix dictionary of recent, coarse feature-change motifs—for example, short ordered patterns across a few predeclared p/v/dp/dv groups—and retrieve feature-only state summaries from prior occurrences of the same motif **inside the current sequence**. Query before writing the current row's entry, then update from the current input. Retrieve prior hidden/input summaries, never labels, future continuations, target-change flags, or another sequence's memory. Unlike exponential event traces, this preserves order; unlike fixed-age taps, it retrieves by content; unlike a low-order signature, it retrieves a previous episode rather than only accumulating moments.

**Legal boundary.** Clear the dictionary at every sequence boundary, process warm-up rows causally, exclude any catch-all channel that makes every row a trivial event, and keep the symbolization fixed at serving. No sequence ID feature or cross-sequence cache is allowed.

**Cheapest no-fit falsifier.** On a future read-only diagnostic, define symbols before inspection and measure suffix recurrence frequency and next-input-event continuation conditional on a matched motif in a forward-chained second half. Compare with a within-sequence block-shuffled suffix control and a recency-only baseline. If useful motifs are too rare, or continuation is not more predictable than those controls, stop. This tests input dynamics only, not target gain.

**Counterevidence and dedup gate.** Event-age, Hawkes traces, signatures, next-event auxiliaries, and hidden-state taps are near neighbors, and full rows have no adjacent repeats in only the sampled sequences. The distinct mechanism is bounded content-addressed retrieval of earlier within-sequence episodes. Do not call it row compression, target-event matching, or a validated event vocabulary.

### 3. Topology of a training-fixed latent code transition graph

Map a low-dimensional, identity-preserving feature summary to a small **fixed** codebook learned from allowed training inputs, then maintain a separate per-sequence directed transition graph over visited codes. A compact readout could use return-cycle counts, local connectivity, or a few spectral summaries as state. The object is topology of the *temporal path through joint anonymous states*, not a graph connecting adjacent feature indices and not a volume-code label decoded as price direction. Codebook parameters are shared static model artifacts; transition counts and graph state reset each sequence.

**Legal boundary.** No external-market or pretrained-market dictionary, no target-assisted codebook/edge selection, no `seq_ix` input, and no cross-sequence online graph accumulation. Only past/current features can update the current sequence's transition graph.

**Cheapest no-fit falsifier.** With predeclared deterministic coarse bins, compare cycle/return summaries across within-sequence halves and against shuffled transition order while preserving per-code frequencies. If graph topology is unstable or gives no descriptive distinction beyond code occupancy and one-step transition counts, do not build the learned codebook version.

**Counterevidence and dedup gate.** The audited volume-code residual probe was +0.0062 in-sample and −0.0078 under chain-half cross-fit, so a fresh code decoder is not justified. HLOB graphs and signature/lag cards also overlap. Keep this candidate only if temporal cycle topology demonstrably differs from marginal code frequencies and the old probe's linear code mechanism; otherwise close it as a duplicate.

### 4. Deterministic, bounded, past-only associative state cache

Use a fixed-size cache keyed by a causal low-dimensional embedding of the current input; retrieve a few nearest **prior rows from the same sequence** and combine their stored feature-only state summaries with the ordinary recurrent state. Query before inserting the current row, update only after producing the current output, evict by a frozen deterministic rule, and reset on sequence change. This is not test-time training or a trainable fast-weight update: no optimizer step occurs. It is also distinct from suffix-motif retrieval: continuous state similarity, not a discrete event-string match, selects the memory.

**Legal boundary.** Store no targets, labels, score masks, predictions produced from future rows, or cross-sequence entries. The key transform must be a fixed allowed artifact or a past-only sequence-local transform. Include warm-up updates and make repeated callback invocations deterministic.

**Cheapest no-fit falsifier.** In a read-only, forward-chained input diagnostic, measure how often a current key has a materially closer prior neighbor than the nearest recency-only state, and whether retrieved prior feature summaries improve prediction of the next input summary versus recency and shuffled-key controls. If state returns are rare or add no input-continuation information, stop before implementation. Budget checks must account for bounded lookup cost; a full scan over 20,000 cache entries per row is not a viable default.

**Counterevidence and dedup gate.** Dyadic taps, TTT fast memory, and recurrent teacher distillation already cover long state and adaptation. This candidate survives only as deterministic non-gradient, content-addressed lookup with same-sequence storage. It has no evidential basis for target lift and should be low priority if existing CPU constraints make lookup expensive.

## Deduplication and next checks

The safest additional item to retain is the **component-symmetry falsification test**: it does not require interpreting physical depth or building another state model. Motif and associative retrieval are distinct but high-risk memory branches; register them as alternatives rather than stacking both. Codebook topology is the lowest-priority candidate because of the direct volume-code counterevidence.

Before reusing the full-event result, verify the actual row-group and mask totals from the compact output, calculate pooled statistics from all sequence records rather than class means, and report feature-age quantities as such. Reconcile the full exception-size distribution with the 52-example tick-scale finding. Keep all target-derived strata retrospective and all outputs available at every prediction row.
