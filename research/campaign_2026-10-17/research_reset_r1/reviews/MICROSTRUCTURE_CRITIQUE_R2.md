# Adversarial review of Learning Round 1

**Date:** 2026-10-17. **Scope:** read-only critique of [`LEARNING_ROUND1.md`](../sources/LEARNING_ROUND1.md) against the supplied [`eda/summary.json`](../eda/summary.json) and [`eda/stream_audit.py`](../eda/stream_audit.py). No training, fitting, inference, or additional data analysis was run for this review. The EDA is already-exposed, retrospective, stratified evidence; it is not a new holdout and supports no public-score forecast.

## Evidence boundary and corrections

The audit sampled 32 sequences per retrospective market class in each split (256 sequences, 5.12 million rows total), with equal class strata rather than the natural pooled mixture. Validation labels are exposed. The class names are audit strata, never permissible inference features. The train and validation samples are exploratory; sequence-level variation and the small number of sampled sequences make fine subgroup comparisons uncertain.

Three descriptive observations may guide cheap falsifiers, not establish predictive value:

- In the sampled validation strata, the combined absolute clipped-target weight at age ≥64 rows since the simultaneous `i0_p0`/`i0_p11` change is 6.16%, 9.50%, 22.88%, and 36.27% in classes 0–3. This is a retrospective class association using a narrow proxy clock, not evidence that any target is mature after a fixed delay or that age is a forecast feature.
- The initial suspicion that rare target changes without the simultaneous `i0_p0`/`i0_p11` change might be float jitter has been superseded by the root follow-up: 52 such changes are tick-scale moves (52 among 943,516 sampled target-change rows, about 0.0055%; one checked valid class-1 example is row-group 1384, step 14166, with target deltas −1.6893 and +2.17197 while both features are unchanged). The exact `p0 AND p11` rule is false. It is unsafe to freeze outputs outside that event, or to interpret the clock as a target-maturity detector. Other features may still correlate with those outcomes.
- There are no repeated complete 112-feature rows in the sampled streams (raw identical-run quantiles all equal 1); the eight extra channels change on every sampled transition. This rules out naive exact-row run compression only. It says nothing about near-duplicates, channel redundancy, or useful temporal memory.

Within-class train/validation marginal drift is largest for i1 volume channels in classes 1 and 2 (e.g. `i1_v15` JS 0.235 and `i1_v13` JS 0.177 in this sample). Treat this as a diagnostic lead only: it is a train-anchored marginal histogram, class-stratified, and neither an independent validation set nor evidence about the hidden evaluation mix. The result cannot justify selecting normalization, adaptation, or group weights against this validation panel.

The learning scout itself reports no new model fit. Its relevant local counterevidence is: the older GDN comparison had a below-GRU point estimate with an interval crossing zero; accumulated-interval memory failed to beat its instantaneous control; fixed detach-horizon screens were small or inconclusive; and local heterogeneous-GRU distillation had positive comparisons, while a newer alpha-0.9 continuation result comes from one exposed warm-parent trajectory. None selects a new teacher or proves a gain here. The public snapshot and short one-seed H512 screen are different evidence surfaces and should not set effect-size priors.

## Card-by-card disposition

### 1. Mamba-3 MIMO recurrent teacher — **DEFER**

**Novelty/equivalence.** MIMO complex-state updates are a real architectural distinction from the reviewed GRU drafts, but “large causal teacher followed by GRU KD” is already a crowded family. The experiment must isolate MIMO versus SISO at matched state size *and* compute; comparing unrelated model sizes would not establish that mechanism. **Causality.** The recurrence is conceptually causal, but a training scan and exported recurrent inference path must agree on state carry, row alignment, and per-sequence reset. **Student bottleneck.** Two per-row teacher predictions compress all MIMO state to the task output; the proposed student may be unable to retain any advantage that lives in latent event/feature state. A teacher-only result does not count as a deployable win. **Support/counterevidence.** Literature evidence is retrieval/language modeling; the local GDN result warns that another gated state-space teacher may not beat the incumbent. EDA provides no lag-response or target-quality evidence for a 20k context. **Cheapest no-fit falsifier.** Inspect whether the authors' MIMO path supports deterministic stepwise state; run a synthetic long-lag association, future-row perturbation, and reset test. If stepwise and full-sequence outputs disagree, or MIMO cannot express behavior beyond its matched SISO control on that test, stop before data fitting. This validates feasibility only, not forecast value.

### 2. xLSTM scalar/matrix memory — **DEFER**

**Novelty/equivalence.** New within the current draft inventory, but matrix memory is close to fast-weight/linear-attention and test-time-memory mechanisms; it should not become a separate broad architecture sweep without an operator-level hypothesis. **Causality.** A parallel matrix scan can conceal state-boundary mistakes; require exact chunk-to-step equivalence and sequence resets. **Student bottleneck.** Per-row point-output KD can discard the matrix's feature-association state, and an ordinary GRU student may reproduce only the mean prediction. Benchmark the student endpoint, not only teacher loss. **Support/counterevidence.** The source is language modeling; neither EDA nor prior local records show that cross-feature matrix memory is the missing signal. Old accumulated-interval memory was negative. **Cheapest no-fit falsifier.** On synthetic impulses and paired associations, test finite state, causal response, reset, and whether matrix state retains an association after the scalar baseline forgets it. If not, the architectural rationale collapses. The test cannot predict target lift.

### 3. Griffin local attention plus recurrence — **REVISE**

**Novelty/equivalence.** Local-attention plus recurrence is distinct from global causal attention in principle, but it can reduce to “GRU plus a short-window feature mixer.” That is a narrower incremental mechanism than a new teacher family. **Causality.** Local attention must be strictly left-causal; cached and full-window outputs need parity across reset and chunk boundaries. **Student bottleneck.** Distilling only the teacher's two predictions risks losing the local interaction pathway; compare the actual student endpoint and keep the same local-window features/state available to it if needed. **Support/counterevidence.** The evidence is language efficiency/length extrapolation. There is no EDA evidence that local neighborhoods add information conditional on recurrent state, and existing causal Transformer/GRU proposals are direct controls. **Cheapest no-fit falsifier.** Make a state-size and CPU inference estimate, then run synthetic tests where a local two-event order matters but a recurrent summary is held fixed. If the local branch cannot be incrementally evaluated within the submission envelope or does not change the toy output, defer. If retained, compare one fixed local window against recurrence-only; do not launch a window sweep.

### 4. Dyadic hidden-state taps — **DEFER**

**Novelty/equivalence.** The explicit snapshots differ from old accumulated interval memory, but remain adjacent to that negative result and to field-age/clock features. The 64/512/4096-row tap schedule is arbitrary until lag evidence justifies those ages. **Causality.** Past snapshots are valid if captured and read online, but their state must reset at every sequence. **Student bottleneck.** A tapped teacher's output-only distillation may erase the old-state access; first establish whether a compact tapped model can be the deployed endpoint. **Support/counterevidence.** The age-weight gradient across retrospective classes is a reason to inspect long-lag input structure, not proof of predictive memory; its clock is the falsified `p0 AND p11` proxy. Past interval memory failed against an instantaneous control. **Cheapest no-fit falsifier.** On feature inputs only, compare within-sequence autocorrelation/residual dependence at predeclared row lags 64, 512, and 4096 across disjoint halves. If long-lag structure is unstable or adds nothing after short-lag dependence, discard the taps before fitting. Do not use target events to pick tap ages.

### 5. Masked current-row reconstruction — **CONTINUE TO A NO-FIT LEAKAGE/UTILITY GATE ONLY**

**Novelty/equivalence.** It is distinct from future-observation reconstruction, but masked feature reconstruction is not automatically useful temporal pretraining: if the masked group is recoverable from same-row redundant channels, the objective may be a same-row copy task. The eight always-changing extra features and absence of exact duplicate rows do not establish that groups are or are not recoverable. **Causality.** It is causal only if the mask is applied before every encoder, normalization, delta, and auxiliary path that could reveal the held-out values. **Student bottleneck.** If only a large teacher is pretrained and the student receives two scalar KD targets, the pretrained representation may not transfer; prefer pretraining the eventual student or preserving a declared representation objective during student fitting. **Support/counterevidence.** MOMENT's external corpus is ineligible here; no local result supports this objective. **Cheapest no-fit falsifier.** Audit the feature/normalization lineage and run a synthetic known-copy mask test. Any unmasked duplicate or normalization leak is a hard stop. Before authorizing model fitting, report mask-group predictability only with a clearly specified no-label descriptive statistic; failure to show nontrivial cross-row information would make this low priority. Neither reconstruction loss nor this gate establishes forecast lift.

### 6. Randomized long-tail gradient horizon — **DEFER**

**Novelty/equivalence.** ARTBP with its compensation is different from an ordinary mixed-length detach schedule; the latter is a biased horizon sweep and overlaps local prior work. Keep those arms distinct. **Causality.** Truncated gradients are a training estimator, not an inference information path; full forward state still has to be causal and continuous. **Student bottleneck.** Longer teacher credit assignment may create a function the GRU student cannot reproduce, so any later spend must include a student endpoint at equal overall compute. **Support/counterevidence.** Earlier fixed-horizon results were small or inconclusive and interval memory was negative. EDA age/label associations do not identify a gradient horizon. **Cheapest no-fit falsifier.** Check the ARTBP implementation against analytically known gradients on a tiny recurrence and estimate estimator variance across fixed synthetic streams. A sign/scale error or variance incompatible with the fixed update budget is sufficient to stop; passing is only implementation evidence.

### 7. Context-matched causal teacher distillation — **REVISE; KEEP ONLY AS A PROTOCOL REFINEMENT**

**Novelty/equivalence.** This is not a new distillation family: causal Transformer teachers, heterogeneous GRUs, and direct causal KD are already in the inventory. The only surviving distinction is verifying that teacher and student receive the same causal context and that the teacher is free-running at the same row. **Causality/eligibility.** The bidirectional teacher arm conflicts with the current no-oracle-future-input instruction and is not eligible in this round. Future perturbation must not change earlier teacher outputs; future rows must not enter teacher statistics or teacher-forced state. **Student bottleneck.** Matching information sets removes one mismatch but does not solve compression: per-row point targets can omit teacher uncertainty, latent state, and relative target structure. The reported local KD results justify keeping the known baseline, not an effect claim for a new teacher. **Support/counterevidence.** Existing local KD positives are exposed and recipe-specific; no result establishes that a particular new teacher transfers. **Cheapest no-fit falsifier.** Audit an existing target producer for source ancestry, causal mask, row alignment, free-running state, and reset. If any fail, repair provenance before another teacher experiment; if all pass and no context mismatch exists, this card adds no distinct work.

### 8. Prefix-only running normalization — **CONTINUE TO A CAUSAL TRANSFORM AUDIT**

**Novelty/equivalence.** The strict prefix-only rule separates it from full-instance RevIN, but the operation is also a standard online location/scale filter and overlaps causal smoothing. The contribution is the information-set discipline, not a new normalization principle. **Causality.** Predict with statistics through t−1, then update with x[t]; use identical order at train, export, and callback. **Student bottleneck.** KD from a teacher with different prefix state makes the student's mapping inconsistent; use the same deterministic transform and reset in teacher and student. **Support/counterevidence.** i1 volume train/valid marginal drift in sampled classes 1–2 is a lead, but equal class sampling and the exposed validation panel prevent a generalization claim. Prefix scaling can also remove useful absolute levels. **Cheapest no-fit falsifier.** Compute prefix variance/floor stability through warm-up and all sequence resets on fixed inputs; perturb a future suffix and confirm earlier normalized rows stay byte-identical. If warm-up scale collapses or absolute-level information is removed by construction, stop before fitting. Keep all statistics sequence-local.

### 9. Feature-only test-time fast memory — **DEFER**

**Novelty/equivalence.** A small online-updated adapter is new relative to training-time recurrent state, although sufficiently small fast weights can be viewed as an expensive recurrent state update. A rule ruling is still unresolved. **Causality/eligibility.** The current input may update state for its own prediction only if contest semantics allow that order; no target, score mask, or cross-sequence optimizer state may enter. **Student bottleneck.** A static GRU distilled from an adapting teacher loses the adaptation trajectory unless the same update state is run by the student; output KD alone is insufficient. **Support/counterevidence.** The class-stratified marginal drift does not show that online adaptation helps, while the proposed 39.8M callback updates make even small per-row optimization material. No measured local evidence offsets that cost. **Cheapest no-fit falsifier.** Before data use, benchmark deterministic update/reset isolation and worst-case per-row runtime on a synthetic 20k-row sequence under the actual CPU callback shape. If it cannot fit a conservative inference budget or repeated-call output varies, stop. Confirm eligibility before any real implementation.

### 10. Sequence-group robust objective — **DEFER**

**Novelty/equivalence.** A CVaR/worst-group term is a new objective in this inventory, but changing it can optimize a different quantity from the official pooled weighted Pearson. Retrospective market classes in the EDA are target-derived strata, not legal inference inputs or a valid group definition for deployment. **Causality.** Training-only groups may be used for loss bookkeeping, but no future-derived or validation-derived group boundary may enter the predictor. **Student bottleneck.** If only a teacher uses group robustness and the student returns to pooled loss, the robust effect can disappear; if the student shares the robust objective, it still must win the exact official metric. **Support/counterevidence.** The EDA intentionally balances classes despite unequal populations, and sampled validation class sizes are small. It cannot justify reweighting rare classes or hidden-test assumptions. Prior train/valid discrimination is not evidence of future shift. **Cheapest no-fit falsifier.** Using training rows only, tabulate nonempty candidate group sizes and target-weight mass under a predeclared label-free grouping; if groups are tiny/unstable or the group objective necessarily overturns the official denominator, drop it. Never group by `market_class`.

### 11. SAM optimizer — **DEFER**

**Novelty/equivalence.** SAM is a new optimizer arm, not a new sequence mechanism; its relevant contrast is a fixed incumbent optimizer at matched updates. **Causality.** There is no inference-time leakage issue, but stochastic masks, clipping, and optimizer state must be paired so the optimizer contrast is interpretable. **Student bottleneck.** A two-pass SAM teacher can spend substantial compute to produce predictions a simple student cannot reproduce; first test the deployed GRU itself if this is revisited. **Support/counterevidence.** The source benchmark differs; EDA contains no model sharpness or seed-stability evidence. The second gradient pass competes directly with the number of scientific comparisons available. **Cheapest no-fit falsifier.** Profile one synthetic update with the actual batch and sequence shape, and verify paired RNG, perturbation restoration, and optimizer-state semantics. If the extra pass forces a smaller total experiment budget than a matched baseline comparison, defer regardless of paper results.

### 12. Process-control change-point gating — **REVISE AND DEDUPLICATE**

**Novelty/equivalence.** The basic mechanism duplicates Microstructure Round 1 card 7 (CUSUM alarm gating a slow state). BOCPD's run-length posterior is a possible distinguishing operator, but the shared claim is “feature-only change detector gates memory”; retain one registered comparison, not two scouts' overlapping ideas. **Causality.** A posterior updated from current feature residuals is causal if the residual model was fit only on allowed training rows and the state resets. Threshold/hazard selection must not use exposed validation labels. **Student bottleneck.** A teacher whose run-length-dependent state is distilled to point outputs may not pass the gate behavior to a plain GRU; either deploy the same gate or train the student through that state path. **Support/counterevidence.** EDA drift and age-stratified target weight suggest nonstationarity worth describing, not change points aligned with target predictability. The strata and validation panel are exposed. **Cheapest no-fit falsifier.** On a frozen feature-only stream, compare BOCPD alarms with the already proposed CUSUM/event-age controls and with injected synthetic shifts. If alarms are near-identical to CUSUM or mostly track ordinary event rate, merge/dismiss the extra operator. Do not use targets to define alarm quality.

## Three hybrid candidates that survive deduplication

These are mechanisms to register only if future training is authorized. They are not combinations to launch blindly; each has a no-fit gate and an explicit limit on what current EDA establishes.

### A. Event-paced selective memory with a directly deployable student

Use a compact causal recurrent model (start with the current GRU rather than another large teacher) whose **state write/decay rate** is modulated by a few sequence-local traces of observed feature-group changes and duration surprise. The interaction is the point: the event process controls how much recurrent memory is overwritten; traces are not merely concatenated flow features, and memory ages are not fixed row snapshots. Preserve feature identities, define only observable input-change families, and do not call them physical orders or target events. In particular, do not gate on `i0_p0 AND i0_p11`: the tick-scale counterexamples falsify that rule. A larger Mamba teacher is a later optional comparison only if the compact gate first survives.

**Why distinct.** It combines the event-rate mechanism with recurrent memory at the update equation, unlike independent Hawkes features, Mamba architecture swapping, or dyadic taps. The model is itself the CPU endpoint, avoiding a teacher whose state is hard to compress. **Cheapest no-fit falsifier.** On feature inputs only, test whether a small fixed set of event-family rate traces and normalized gaps have reproducible within-sequence autocorrelation/transition structure beyond row age in both halves; use a circular-shift control and no targets. If traces collapse to total event count or are unstable, do not build a gated state. Existing EDA lag counts only reach ±64 and cannot answer the proposed longer-lag question.

### B. Context-matched, distribution-preserving distillation

If a large causal teacher is ever justified, freeze a compact **per-row conditional target summary** rather than two point predictions alone: for each target, a small set of fixed quantiles or mean/scale, plus a cross-target dependence summary. Train the student on its supervised labels and these summaries using the same current/past inputs, causal state order, and sequence resets. The deployed output can remain the two point predictions required by the callback. Keep this separate from any future-aware teacher: no bidirectional context, target history, or target values as student inputs.

**Why distinct.** It directly tests whether pointwise KD creates an information bottleneck and preserves uncertainty/dependence through compression; ordinary context-matched two-output KD does not. The official objective is correlation, so distributional KD is only a representation aid and may be unnecessary. **Cheapest no-fit falsifier.** On a synthetic multimodal two-target stream, verify that the proposed serialized teacher summaries preserve distinctions that conditional means erase, while the student interface receives no future features. If the summary adds no distinguishable information over the two means on that toy, the extra loss is not warranted. No claim about challenge performance follows.

### C. Prefix-calibrated masked-feature robustness in the served student

Train the deployment-sized student—not only a large teacher—with an identical prefix-only location/scale state and a modest masked-current-group auxiliary loss. Apply feature-group masks after the causal normalizer, keep the reconstruction head through student fitting, and evaluate it as a training regularizer; no online gradient update is needed. This tests whether the observed feature-scale shift is nuisance variation that can be normalized while the masked objective preserves cross-group structure. Absolute level information remains available as a separate bounded input channel so normalization cannot silently erase it.

**Why distinct.** This links adaptation to the actual student representation and its same-row feature dependencies, instead of evaluating prefix normalization and reconstruction as unrelated modules or relying on output-only KD. **Cheapest no-fit falsifier.** On train inputs only, predeclare group masks and measure whether prefix-normalized groups remain finite/stable through warm-up and whether future-suffix perturbation leaves prior transformed rows identical. The exposed train/valid marginal drift can motivate this check but must not select masks or thresholds. If normalization destroys level ordering or the mask can be inferred by a direct duplicate path, stop. This does not make exposed validation a new holdout.

## Ordering recommendation

Keep **A** as the most mechanism-specific future candidate, but run only its deterministic feature-state falsifier first. Keep **B** conditional on an actually stronger causal teacher and report the student endpoint as the only deployment evidence. Keep **C** as a low-cost student-side design audit, not as evidence that marginal drift is harmful. Defer the remaining architecture and optimizer sweep until one candidate clears its no-fit gates and the active protocol authorizes training. No EDA figure here is an untouched validation result.
