## E532-R01 — Soft value-grid loss

- **Source:** “Task Formulation and Loss” — “cross-entropy loss as the main objective”; “exponentially smoothed probability distribution”.
- **Structural analogy:** Their 2D map is a distribution over alignment hypotheses at each position, with CE on a smoothed target and Huber on the expectation. The piece that fits this contest is a 1D distribution over the current scalar target. The horizontal-by-typewell grid does not become a joint grid of our two targets.
- **Intervention:** On an existing causal backbone, replace the point head with per-target logits on a fixed grid spanning the training label range. Build the training distribution as a normalized exponential kernel centered on the observed label. Width is a small frozen set, including one very narrow kernel. Decode the prediction as the probability-weighted grid mean. Add Huber between that mean and the label. Keep official ±2 clipping and label-magnitude weights exclusively in `global_wp_clip2_v1`. Leave their probability-weighted GR-gap penalty out: it needs an observation indexed by the alignment axis, and these channels are not that observation.
- **Assumptions:** A smoothed grid is a training geometry for a scalar regression target. Targets may be nearly a deterministic function of the causal features, so a wide kernel can wash out a sharp label. The two targets can use separate 1D grids in the first recipe. Grid edges and kernel widths are fixed from the training fold.
- **Causal leakage and validity risks:** The grid is over the current label, so time smoothing is not involved. Leakage appears if validation labels set bin edges, if early stopping uses a grid CE instead of the official metric, or if a bidirectional encoder fills the logits. Training-target clipping stays a declared switch and is not slipped into the scorer.
- **Predicted observable:** The official weighted Pearson of the decoded mean moves relative to a point-loss twin. A secondary diagnostic is training-fold reliability of bin mass versus distance to the label. The decision number is the official metric on the causal decoded mean.
- **Cheapest discriminating test and matched control:** One existing causal GRU or TCN, same split, seed, width, and row mask. Control: current point loss, identical decode path clipped only at evaluation. Arms: two kernel widths plus Huber on the expectation. Report both targets and the combined official metric.
- **Falsifier:** On this backbone, split, and grid, both kernel widths lose to the point-loss control on the official metric, or the wide kernel wins while the narrow kernel matches the control within the run’s noise. That stops this grid and these widths. Other losses stay eligible.
- **Cost tier:** T1, one local GPU fit inside the 5 GB VRAM envelope. A CPU forward-only overfit on a frozen tiny slice is the T0 smoke check before the fit.
- **Parent and interaction links:** Parent is the current teacher training objective. Interacts with heterogeneous distillation: the grid supplies soft targets. Interacts with E532-R03 if a belief histogram replaces the free logits. Interacts with E532-R05 because input augmentation changes the conditional the grid fits.
- **Level-2 successors:** Magnitude weights applied only to the Huber term. A coarse joint grid over the two targets. Distill the frozen teacher’s bin distribution into a smaller causal student. If the narrow kernel is the only survivor, keep it as label smoothing and stop wider kernels.

## E532-R02 — Causal window shape packet

- **Source:** “Features / Horizontal well” — “Quadratic fitting residual RMSE”; also slope, last-minus-first, and quadratic coefficients. “XY Neighbor Information” supplies ridge and singular-case handling as the small numerical detail, after the author called the extra engineering marginal.
- **Structural analogy:** Each downsampled bin is summarized by level, missingness, scale, and shape, then the network reads those summaries. Cross-well `(x, y)` neighbors do not exist under sequence-reset inference. The same ridge regression runs on a trailing window inside one sequence.
- **Intervention:** For a declared subset of channels, on a trailing window of length W that ends at the current row, emit only the statistics that current event, delta, and window views are least likely to already contain: last minus first, ridge linear slope, ridge quadratic coefficients, quadratic residual RMSE, and a missingness flag. If fewer than three finite samples exist, emit zeros and raise the flag. Add these channels to the existing causal feature vector. Window mean and standard deviation stay in the control feature set so this packet is not a disguised rerun of those.
- **Assumptions:** Short-window curvature and lack-of-fit can carry target-relevant signal beyond level and delta. W and the ridge are the same for every sequence. Channel subset is chosen from training-fold variance or an existing audited projection, with no geological ranking.
- **Causal leakage and validity risks:** A centered window reads future rows. Quadratic fit uses only rows `t-W+1…t`. Fitting the channel subset on the reported holdout contaminates the comparison. High-dimensional packets can blow the 20 GB RAM cap. Stream the window. Start with a small channel subset.
- **Predicted observable:** The endpoint official metric improves against the same model on the current causal feature set. Training-fold association between quadratic residual RMSE and the control model’s absolute error is a diagnostic, not the selection metric.
- **Cheapest discriminating test and matched control:** Freeze the downstream GRU or TCN architecture and the existing event, delta, recency, and window features. Add the shape packet. Matched control drops only last-minus-first, quadratic coefficients, and quadratic residual RMSE. Same split and seed. One window length.
- **Falsifier:** That packet, on that W and channel subset, does not improve the official endpoint metric versus the matched feature control. Stop that statistic set and W. Other window designs remain eligible.
- **Cost tier:** T0 to build features on CPU with a streaming window. T1 for the single matched fit.
- **Parent and interaction links:** Parent is causal heuristic window features and event views. Interacts with block memory through W. Interacts with E532-R04 as one gated feature family. Interacts with E532-R08 if the packet is computed on calibrated residuals.
- **Level-2 successors:** Two further window lengths. Shape statistics of the E532-R03 belief mean. A block-memory state that updates on the same W schedule. Stop if the first W already fails.

## E532-R03 — Rare-jump belief, bin updates, diverse filters

- **Source:** “Particle Filter” — “Allowing low-probability large jumps”; “Updating particles in bins (64 samples)”; “Blending diverse cfg profiles”; “FFBSi smoothing”. Later: “kept them in my final ensemble for diversity”. Also: when an accumulated channel is already present, accumulated level beat differences only.
- **Structural analogy:** A weak sequential estimator of a latent scalar becomes a feature stream and a diversity member. The standalone filter is allowed to lose. The latent is a belief over the target value, not a depth.
- **Intervention:** Use a deterministic histogram filter, reset at each sequence to a fixed prior. Transition kernel is `(1-ε)` local moves plus `ε` wide jumps. The likelihood comes from a frozen causal base model’s predictive density on the same grid as E532-R01. Update every B rows by summing log-likelihoods inside the closed bin, and apply the new posterior only on later rows. Inside the bin, hold the previous posterior. Emit posterior mean, variance, entropy, jump responsibility, and absolute gap versus the base mean. Run three frozen configs of `(ε, jump width, B, noise scale)` and concatenate their summaries. Serving uses this deterministic histogram. A seeded stochastic particle filter is out of the submission path.
- **Assumptions:** Some target dynamics are sticky with occasional large innovations that a smooth GRU under-represents. The frozen base model is causal and ancestry-declared. Bin size B is a computational aggregation, not a physical sample interval. Configs are a diversity set, not a copied geology tuning.
- **Causal leakage and validity risks:** Applying a bin’s update to earlier rows in that bin reads the future. FFBSi-style backward smoothing reads future labels and features. That pass may train a privileged teacher. It is absent from inference and from the reported metric. Selecting on agreement with the smoothed posterior instead of raw labels invalidates the result. Filter parameters and the base model come from the training fold only.
- **Predicted observable:** Official metric of three complete endpoints: frozen base alone, base plus forward-belief channels through one refit, and a frozen blend of base mean and filter mean. The filter-alone endpoint is recorded and may be weak. The blend is the object that can justify keeping it.
- **Cheapest discriminating test and matched control:** CPU filter on a frozen small causal model, then one T1 refit of a small GRU that sees the belief channels. Control GRU sees the base prediction as a single channel and no belief summaries. A third arm feeds innovations only, holding out level, variance, and jump responsibility, to test the accumulated-versus-difference interaction.
- **Falsifier:** For these three configs and this B, the refit with belief channels and the frozen blend both fail to beat the control GRU on the official metric. Stop this kernel family and bin schedule. A different jump family would be a new recipe.
- **Cost tier:** T0 for the CPU filter and filter-alone score. T1 for the one refit. Privileged backward distillation is a later T2 cloud fit, not part of the first test.
- **Parent and interaction links:** Parents are online feature dynamics and the current weak causal model used as the likelihood. Interacts with heterogeneous teacher distillation, E532-R01 grids, E532-R04 conditional inclusion, and E532-R07 shortcut corruption.
- **Level-2 successors:** Privileged teacher: backward-smoothed posteriors as training targets, student features limited to the forward filter, metric still on raw labels. Compress the multi-config vector with a small causal student. If the innovation-only arm loses to the level-inclusive arm, keep level channels in the distillation cache.

## E532-R04 — Reliability-gated endpoint blend

- **Source:** “Ensemble” — models without XY channels on unreliable wells, with `z_diff` in that branch; quality stats versus “the 95th percentile of the training distribution”. “What didn’t work”: removing wells with visually poor labels brought no stable gain. PF features stayed in the ensemble after they stopped helping the best single model.
- **Structural analogy:** The serving predictor is a conditional blend. A fragile feature family is dropped when a predeclared reliability statistic is extreme, and a weaker stream can keep weight on that slice. Their neighborhood statistics failed to explain a public gap. The transfer is the protocol, not those geology statistics and not a claim that any gate will survive a leaderboard shift.
- **Intervention:** Declare two causal endpoints, A and B. A consumes the extra family under test (belief channels or the shape packet). B is the fallback without that family. On the training fold, freeze a scalar reliability statistic already available causally: belief entropy, jump responsibility, or window quadratic residual RMSE. Threshold at that fold’s 95th percentile. The blend uses A below the threshold and B at or above it. Also record a constant-weight blend with no gate. Do not drop sequences or rows for suspected bad labels in the primary arms. A separate negative arm may drop a training-fold-defined high-residual slice and is scored as its own recipe.
- **Assumptions:** Feature usefulness can be conditional on a causal difficulty statistic. The statistic and threshold are frozen before the comparison. Sequence-level or row-level application is chosen up front. Row-level gates use only past and current inputs. Official metric on the full scored mask is the endpoint, so a gate that helps a slice still has to win globally or be explicitly scoped to a predeclared slice metric.
- **Causal leakage and validity risks:** Tuning the threshold on the reported comparison fold double-uses it. Inventing new quality statistics after seeing the result recreates their unresolved public-gap search. Cross-sequence neighbor features are outside this card. Dropping rows changes the population and is not a cleanup step.
- **Predicted observable:** The gated blend and the constant blend are each compared with B alone, and with A alone, under the official metric. Slice diagnostics show whether A wins only in the low-reliability region. The decision uses the predeclared full-mask metric.
- **Cheapest discriminating test and matched control:** Reuse OOF causal predictions from the E532-R02 or E532-R03 control pair. No new fit if those predictions exist. Control is B alone and the constant blend. One statistic, one percentile.
- **Falsifier:** This statistic, percentile, and A/B pair: the gated blend loses to both B and the constant blend on the official full-mask metric. Stop that gate. Keeping A at a constant small weight remains a different recipe. A failed gate does not retire the feature family.
- **Cost tier:** T0 when OOF predictions already exist. T1 only if A and B must be trained first.
- **Parent and interaction links:** Parent is the served distillation blend. Depends on one extra family from E532-R02 or E532-R03. Interacts with E532-R07, because a corrupted-auxiliary student is another B. The bad-label deletion arm is a negative control linked to the campaign’s exposure rules, not a parent model.
- **Level-2 successors:** A second predeclared statistic, only after the first is scored. A three-way blend with fixed weights fit on training-fold OOF predictions. If deletion of high-residual sequences loses, record that negative and keep those rows in later fits.

## E532-R05 — Shared affine jitter and joint augmented training

- **Source:** “Data Augmentation / GR transform” — “GR' = a × GR + b”; “Typewell GR jitter (consistent transformation of GR channels)”. “What didn’t work”: joint simulated and real training beat a two-stage simulation pretrain. Z-shift, rare faults, and reverse path are discussed below as boundaries.
- **Structural analogy:** A coherent scale-and-shift on the reference channels pushes the model toward shape. “Consistent” means one `(a, b)` shared across the transformed channels, which preserves their cross-channel pattern. Independent per-channel affines are a different, stronger nuisance model.
- **Intervention:** During training only, with targets left unchanged, apply one shared `(a, b)` to all 112 channels, with `a` near 1 and `b` small, ranges frozen in advance. A second arm uses independent `(a, b)` per channel. Mix augmented and original rows in the same updates. The comparison schedule arm trains the same shared-affine corruption jointly versus a two-stage run that fits corruption first and real rows second. Include channel masking and tail cropping only as training row transforms that respect sequence reset and the scored mask.
- **Assumptions:** A global affine can be a nuisance rather than the signal. That assumption is testable and may be false for anonymous levels. Shared and independent affines are different hypotheses. Joint optimization is the schedule the author preferred. It is a hypothesis here, not a transferred result.
- **Causal leakage and validity risks:** Block-bootstrap of new input paths while keeping the old targets needs a generative observation model we do not have, so synthetic relabeled paths are out. Path reversal assumes time-reversal symmetry we do not have. A circular shift of within-sequence residuals moves later values earlier. Z-shift that holds `TVT+Z` fixed assumes a conservation law these channels have not been given. Tail cropping must not be used to avoid hard scored rows.
- **Predicted observable:** Official metric versus an unaugmented twin. The informative pattern is which of shared affine, independent affine, and joint-versus-two-stage survives. A loss is a real outcome for that corruption range.
- **Cheapest discriminating test and matched control:** One small causal model, three training arms plus the unaugmented control: shared affine, independent affine, and shared affine with two-stage schedule. Same seeds and epoch budget. No change to inference code.
- **Falsifier:** Shared affine on this `(a, b)` range loses to the unaugmented control, and independent affine also loses. Stop both ranges. If only the two-stage schedule loses to joint training, stop two-stage pretraining for this corruption and keep joint training eligible.
- **Cost tier:** T1 per arm. Run the shared-affine arm first. Launch the others only if the training stack is stable.
- **Parent and interaction links:** Parent is whatever trainer E532-R01 or the current GRU uses. Interacts with E532-R08: calibrating after a random affine can cancel the augmentation, so calibration is fit on raw training rows and augmentation is a training-time input transform only. Interacts with E532-R07 as a second anti-shortcut method.
- **Level-2 successors:** A shared affine on a declared channel group rather than all 112. A slow causal baseline subtracted before a small residual offset, implemented with trailing means only. Rare additive input spikes as robustness noise, targets unchanged, if the affine arm is neutral rather than harmful.

## E532-R06 — Fixed causal average pooling

- **Source:** “Model” — “simple average pooling + interpolation performs better than learnable alternatives.” Same section: LayerNorm replaced by BatchNorm, with BF16 required to avoid NaN losses. “What didn’t work”: transformer backbones, and larger models or higher resolution in that contest.
- **Structural analogy:** The useful detail is the resampling operator, not the ImageNet ConvNeXt U-Net. Fixed pooling beat a learned resample there. A symmetric U-Net does not become a causal scorer. ImageNet weights are for natural images. Loading them on a raster of anonymous series is an applicability stretch and is not the first arm.
- **Intervention:** In a causal TCN, replace one learned stride with a fixed trailing average pool of length P, then a causal expand that repeats the completed bin forward (hold-last). No interpolation from a future bin. Decoder, if any, is causal. Normalization arm for this conv stack: GroupNorm or LayerNorm as the default sequence-safe choice, and one BatchNorm arm whose statistics are isolated per sequence or frozen from the training fold. Use the precision that stays finite. Their BF16 requirement is a stability warning for a BN conv teacher, not a mandate to switch every GRU to BF16.
- **Assumptions:** Alias control from a fixed pool can beat a learned stride at matched depth. Hold-last is the causal stand-in for their interpolation. Their scale ceiling does not bind our teachers. A larger teacher still needs a student path and is not this card’s first test. Their transformer loss does not retire transformers. It motivates a later matched-size negative control.
- **Causal leakage and validity risks:** “Interpolation” in a U-Net decoder mixes future rows. BatchNorm across a batch mixes sequences and can leak through running statistics if those sequences are treated as exchangeable without a declared rule. NaNs from the wrong precision are an execution failure, not a scientific negative. Random ImageNet initialization masquerading as transfer is a validity problem.
- **Predicted observable:** Official metric of the fixed-pool causal TCN versus the same TCN with a learned stride, matched parameter count as closely as the kernel allows. A separate line records whether the BN variant is numerically stable and whether its official metric differs.
- **Cheapest discriminating test and matched control:** One small causal TCN, two resampling arms, same seed and features. Control is the learned stride. Pool length P matches the receptive field the learned stride would have used. Norm and precision are locked on the first comparison, then the BN arm is a follow-up on the winner only.
- **Falsifier:** Fixed trailing pool of this P loses to the learned stride on the official metric in this TCN. Stop that P and the hold-last expand. Other causal conv designs stay eligible. A NaN BN run is an implementation failure and is rerun with the stable precision before any scientific read.
- **Cost tier:** T1 for the pair. T0 is a single-batch shape and memory check under the local VRAM cap.
- **Parent and interaction links:** Parent is the causal TCN family. Interacts with E532-R02 because both aggregate over a trailing span. P and W should be declared independently so the tests do not collapse into one knob. A future matched-size causal transformer is a negative-control cousin, not a parent.
- **Level-2 successors:** A second pool length. A wider randomly initialized causal conv teacher with an explicit compression student, only if the fixed pool wins. A transformer of matched parameter count as a bounded negative control. Pretrained public weights only if a permitted checkpoint has a real sequence interface.

## E532-R07 — Auxiliary-channel corruption

- **Source:** “Other augmentations” — “PF rotate/shift (corrupt PF channels to reduce shortcut learning)”. This is the unconventional small-component transfer. The headline filter can be irrelevant and this regularizer still stands.
- **Structural analogy:** When a strong auxiliary channel is available in training, the net can ignore the raw series and lean on the auxiliary. Corrupting that channel during training forces the other inputs to stay useful. At inference the auxiliary is clean.
- **Intervention:** For a declared auxiliary block (belief summaries from E532-R03, or an existing teacher channel block), apply a training-only corruption: with fixed probability, replace the block by a time-shifted copy of itself using a trailing shift, or add a frozen noise scale, or zero it. “Rotate” in the source is a channel perturbation. Here it means a fixed permutation of auxiliary channels or a trailing shift, chosen in advance. Raw series and targets are unchanged. Inference uses uncorrupted auxiliaries. The downstream model is the student that would otherwise see clean teacher channels.
- **Assumptions:** The auxiliary is predictive enough to become a shortcut, and the raw causal features still contain residual signal. Corruption rate and noise scale are frozen. Shift uses past values only, with a declared fill at the sequence start.
- **Causal leakage and validity risks:** A centered or forward shift of the auxiliary leaks future rows into the corruption itself. Corruptions that use labels are a second model, not this regularizer. If the student is evaluated with corrupted auxiliaries, the test no longer matches serving. Teacher channels must have audited ancestry and must sit outside the evaluated fitting groups when the comparison claims a held-out student.
- **Predicted observable:** Official metric of the student trained with corruption, evaluated on clean auxiliaries, versus the same student trained on always-clean auxiliaries. A diagnostic is performance of both students when the auxiliary is zeroed at evaluation. The clean-auxiliary official metric decides. The zeroed diagnostic shows whether raw features were retained.
- **Cheapest discriminating test and matched control:** One small student, one auxiliary block, two trainings. Control training sees clean auxiliaries every step. Same distillation cache, split, and seed.
- **Falsifier:** This corruption rate and this auxiliary block: clean-auxiliary official metric is worse than the clean-trained control, and the zeroed-auxiliary diagnostic shows no gain in raw-feature robustness. Stop that corruption recipe for that block. Other auxiliary blocks remain eligible.
- **Cost tier:** T1, two student fits, or T0 if a tiny overfit probe is used only to check that corruption changes the training loss. The official read requires the real fit.
- **Parent and interaction links:** Parent is heterogeneous recurrent teacher distillation and any arm that feeds E532-R03 channels downstream. Interacts with E532-R04: a corrupted-aux student can be the fallback model when the auxiliary’s reliability statistic is extreme. Interacts with E532-R05’s joint schedule. Corruptions are mixed into the same updates as clean steps.
- **Level-2 successors:** Two corruption rates. Corrupt only a subset of the belief channels, always leaving jump responsibility clean, to see which summary is the shortcut. If corruption helps the zeroed diagnostic and holds the clean metric, adopt it for the next teacher-channel student.

## E532-R08 — Causal bin calibration blend

- **Source:** “Features / Typewell” — GR “calibrated using the visible region” by aggregating into bins, interpolating back, and “blending with the original” values. Listed again as a major particle-filter improvement: “Calibrated typewell GR”.
- **Structural analogy:** A reference series is recalibrated from pairs observed in the already-visible prefix, then blended with the raw value. The bin key in the source is TVT. Here the key is a semantics-free causal index: position within the sequence, or a trailing mean of one channel. No depth interpretation.
- **Intervention:** For a small declared channel subset, maintain bins of `(s, x)` from earlier rows of the same sequence. Interpolate inside visited bins and blend `x_blend = (1-λ) x + λ x_bin` with λ in a frozen pair such as 0.25 and 0.5. Before the sequence has enough past mass, use a global map fit on training-fold rows only, then switch to the within-sequence map. Emit raw, blended, and residual channels. Reset bins at sequence boundaries.
- **Assumptions:** A stable relationship between the chosen index `s` and channel level exists often enough that a prefix lookup is meaningful. Position-within-sequence is allowed because it is known at inference and carries no feature semantics. The global map transfers across sequences only as a shrinkage prior for short prefixes.
- **Causal leakage and validity risks:** Bins that include the current or future rows leak. A map fit on the comparison fold leaks. Using another sequence’s suffix as if it were this sequence’s prefix breaks reset. Blending in label space would turn this into a target smoother. This card blends features only.
- **Predicted observable:** Official metric of the endpoint with calibration channels versus the same endpoint on raw channels. A training-fold diagnostic is the size of `x - x_bin` over the prefix. The official endpoint metric decides.
- **Cheapest discriminating test and matched control:** CPU feature build, then one T1 fit. Control uses the raw subset and no calibrated copy. Two keys are not both in the first fit. Start with position-within-sequence. The trailing-mean key is a successor.
- **Falsifier:** This channel subset, λ, and position key: the endpoint loses to the raw control on the official metric. Stop that key and λ. A trailing-mean key is a new recipe.
- **Cost tier:** T0 feature build under the RAM cap, using a small subset and streaming bins. T1 for the matched fit.
- **Parent and interaction links:** Parent is online feature dynamics. Interacts with E532-R02 by feeding residuals into the shape packet only after this card’s own test. Interacts with E532-R03 as an optional calibrated input to the frozen base likelihood, which would be a new ancestry declaration. Interacts with E532-R05 as described there.
- **Level-2 successors:** The trailing-mean key on the same subset. Calibration of belief-gap channels rather than raw channels. If the global prior dominates the within-sequence bins, keep the frozen global map and drop online bins.

## Top 3

1. **E532-R01.** One head swap answers whether distributional training geometry changes the official metric for every later teacher and student. The decoded mean stays compatible with the current scorer. Soft bins are reusable distillation targets. The narrow-versus-wide kernel also tells us whether the labels behave like sharp targets. No score prior is attached. A loss retires these widths only.

2. **E532-R03.** This is the mechanism most different from a smooth GRU or TCN: a reset-safe sticky state with an explicit rare jump, updated on coarse bins, run as several frozen configs. The source’s own story is that the weak filter still mattered as a diverse component after the strong net stopped using it internally. The first test already scores filter-alone, channels-in-a-refit, and a frozen blend, so a weak standalone result can remain useful without a special pleading step.

3. **E532-R04.** Information value is the conditional-inclusion rule that their final system actually used, including the warning that a hand-built quality gate can fail to explain a transfer gap. Long-term, this is how weak streams from R03 and feature packets from R02 are kept or dropped without deleting rows and without treating a standalone loss as a family kill. It should run on the first OOF pair those arms produce.

E532-R02 is the cheapest parallel probe and the natural first feature build, because it does not need a new likelihood model. It is fourth in this ordering because current window features already cover part of its ground. E532-R07 is the small unconventional component to add as soon as any auxiliary teacher channel exists. E532-R06, R05, and R08 are independent enough to run beside the top three when a lane is free. They should not replace the distributional head, the jump belief, or the gated endpoint test.
