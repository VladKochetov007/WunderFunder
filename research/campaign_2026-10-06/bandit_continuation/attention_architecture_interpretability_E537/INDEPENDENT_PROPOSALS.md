# E537 initial independent proposal commitment

These proposals precede inspection of other hypothesis cards or the scientific tree. They are hypotheses, not model-quality findings. Every numerical prior is null. Local IDs E537-A through E537-H are proposal IDs; root assigns permanent lineage IDs after duplicate review. Sources below are primary papers/author repositories opened during this task.

## The quant problem

Treat the 112 anonymous channels as outputs of an unknown measurement pipeline applied to two coupled event streams. A row may mean a new observation, a stale carried-forward value, or a new state of only one instrument. The prediction problem may therefore depend on (1) an inverse representation of the sensors, (2) the clock on which memory should change, (3) sufficient statistics of ordered events, and (4) the conditional functional targeted by the official metric. None requires guessing that channel 17 is a particular exchange field.

Working inverse-measurement model: `x_t = g(s_t, sampling_t, normalization_t)` and `s_t = F(s_previous, innovation_t)`. This is a framing, not an identified latent model. Anonymous-channel correlation cannot establish semantic labels or causal cross-impact. Keep raw features alongside any proposed quotient/invariant representation until discriminating evidence supports discarding information.

The first comparisons should separate representation from memory. A stronger scalar embedding on the current GRU can diagnose a front-end bottleneck; a changed clock at fixed representation can diagnose oversampling; a memory adapter at fixed clock can diagnose retrieval. A large Transformer should be an independently trained teacher candidate with a distillation endpoint, not a presumed cause of the teammate result.

## E537-A: content-addressed innovation memory beside a recurrent core

**Family/lens:** associative state; change the representation and the update instruction. **Source component:** a key-specific delta rewrite rather than an ever-growing sum; gating is an independent forgetting operation. [Fast-weight delta rule](https://proceedings.mlr.press/v139/schlag21a.html), [Gated DeltaNet, equation 8](https://arxiv.org/html/2412.06464v1).

**Intervention.** Feed an existing independently trained-from-scratch recurrent core an additional fixed-size associative memory read. Let `k,q` be normalized 16-dimensional projections of current observed features, feature changes, age and recurrent state, and `v` a 16-dimensional innovation representation. Per head keep `M` with shape 16×16. Update `Mbar = alpha*M`; `M = Mbar + beta*(v-Mbar*k)*k^T`; read `r=M*q`. Concatenate r with the recurrent state for two target heads. This is a recurrent adapter, with no Transformer block, KV cache or test labels. An innovation here is an input feature change or learned representation, never a future target residual available only after the horizon. Start with 2 heads. Preserve a separate row-age path so repeated observations need not be forcibly ignored.

**Assumptions and breakpoints.** Similar observable states recur and require replacing stale associations. Key collisions, rapid regimes and target-supervised collapse to an ordinary hidden vector could eliminate value. Finite-rank memory is not unlimited context. Repeated values do not prove that no economically relevant time passed.

**Predicted observable.** Relative to a matched recurrent control, the full adapter should improve on return-to-state and delayed-response diagnostics more than a parameter-matched diagonal gated accumulator. Deleting only a relevant memory key should change the model more than deleting an unrelated key. Those are model-mechanism probes, not market causality.

**Cheapest discriminating test/falsifier.** First exact toy checks: overwrite one orthogonal key while preserving another; beta=0, alpha=0, stream reset, prefix and chunk equivalence; long repeated-input stability. Then a three-arm fixed-seed GPU screen on complete training components: recurrent + equal-sized MLP, recurrent + additive gated memory, recurrent + delta memory. Freeze updates/rows and evaluation membership. If retrieval tasks fail, fix implementation; if matched delta/additive results and intervention effects are indistinguishable, the claimed targeted-rewrite advantage is unsupported for that recipe. An imprecise score delta alone does not refute all memory sizes.

**Cost/ladder.** O(H*d_k*d_v) state and work per row apart from projections; 2×16×16 = 512 FP32 numbers, 2 KiB/sequence for M. Sequential Python-loop training may be slow; profile before a fit. Small screen request: one GPU lane, ≤30 GPU-minutes after profile, not authorized here. Ladder 2×16 → 4×32 → a 2–4-layer large recurrent teacher with 8×64 memories, subject to measured headroom. Distill its two outputs and optional own-teacher hidden summary into the existing compact recurrent student.

**Interaction/artifact.** Combine with E537-C numeric embeddings or E537-D event-clock tokens through separately registered interaction nodes. Deliver independent recurrence module, deterministic state schema, ablations and exported predictions.

## E537-B: causal channel attention from prefix cross-moments

**Family/lens:** adaptive sufficient statistics; transpose what attention compares. **Source component:** XCiT compares feature channels rather than time tokens. [Paper](https://arxiv.org/abs/2106.09681), [author code](https://github.com/facebookresearch/xcit/blob/main/xcit.py). Its image-wide normalization must be replaced for streaming.

**Intervention.** Project current data to `q,k,v` of dimension 16 or 32. Maintain discounted prefix second moments `C=lambda*C+q*k^T`, `a=lambda*a+q^2`, `b=lambda*b+k^2`. Set `R_ij=C_ij/sqrt((a_i+eps)*(b_j+eps))`; compute channel mixer `A=softmax(R/tau, dim=key_channel)` and `r=A*v`. Add a residual projection of r to the recurrent head. Call these cross-moments, not centered covariance. This is an attention-like recurrent sidecar without temporal token attention. Every normalizer uses the current prefix only. Decay may use a row clock initially; event-clock decay is a distinct later intervention.

**Assumptions/prediction.** Joint sensor relationships drift more slowly than individual readings, and those relationships identify the current predictive regime. Full off-diagonal mixing should outperform a matched diagonal EMA gate specifically when cross-group co-movement changes. A static affine mixer may already suffice; highly stable covariance offers little advantage.

**Test/falsifier.** Compare static mixer, diagonal prefix gate and full prefix channel mixer with equal recurrent backbone and fixed training budget. Synthetic regime-switch cases distinguish instantaneous values from correlation history. Permute one stream's historical order while keeping marginal values in a synthetic probe. If the full mixer has no advantage over diagonal/static controls at a resolved effect scale, the off-diagonal regime hypothesis is unsupported there.

**Cost/ladder/interaction.** O(d²) state and per-row work; d=16 →32→64 teacher; softmax d² at every row is an explicit CPU serving cost. Screen ceiling ≤20 GPU-minutes after profile. Distill richer teacher into recurrent input gates. Possible interaction E537-A: use prefix relationship statistics to query associative memory; do not sum parent score deltas. Reusable artifact is a causal streaming cross-moment module with finite-state export.

## E537-C: feature-wise numerical embeddings before choosing a temporal architecture

**Family/lens:** inverse measurement; re-encode scalar geometry. **Source component:** piecewise-linear and periodic numerical embeddings can help multiple backbones, not just attention. [NeurIPS paper](https://arxiv.org/abs/2203.05556), [author repository](https://github.com/yandex-research/rtdl-num-embeddings).

**Intervention.** Fit 8 quantile knots per channel on fitting components only; handle ties/constant features explicitly. Encode scalar x by monotone piecewise-linear basis `b_j(x)` and a learned 8-dimensional embedding `E_j b_j(x)`, retaining raw x and observed delta in a residual path. Compress concatenated embeddings to the original GRU input width with one learned projection. Compare to feature-wise linear embeddings and an equal-parameter post-mixing MLP. A periodic embedding variant with bounded initial frequencies is a separate candidate, not bundled into the primary treatment. The hypothesis is that anonymous encoding changes local numerical geometry and a first global linear map makes the network relearn it inefficiently.

**Assumptions/prediction.** Feature identity is stable and the relevant response is locally nonlinear in an individual channel. Value-density knots may underserve rare high-weight target cases; knot count and raw tails must not silently erase them. At fixed recurrent capacity, gains should appear in piecewise local responses and tail/rare-range diagnostics; embedding gains surviving without attention implicate representation, not long-memory retrieval.

**Test/falsifier.** One matched small-screen pair: linear feature embedding versus PLE, same recurrent core, sampler, label treatment and step count. Add the equal-parameter MLP if PLE wins before claiming a geometry mechanism. Verify train-only fitted knot hash, tie handling, out-of-range continuity, feature-order contract and chunk invariance. If all gains are matched by the ordinary larger MLP, allocate to generic capacity instead of attributing them to sensor inversion.

**Cost/ladder/interaction.** 112×8≈896 basis values/row before compression; compute embedding on the fly rather than cache the expanded full dataset. Small comparison budget ≤20 GPU-minutes after profiling; 8-knot/8-dim →16/16 teacher → group-token Transformer E537-D. Distill outputs or retain a small learned scalar spline in the served recurrent model. Reusable artifacts: fitted training-only knots, embedding module, response curves and paired predictions.

## E537-D: causal group/event Transformer with explicit dual clocks

**Family/lens:** asynchronous observation; factor sensors and change time. **Source components:** variate tokens [iTransformer](https://arxiv.org/abs/2310.06625), subseries tokens [PatchTST](https://arxiv.org/abs/2211.14730), irregular-observation state [Neural CDE](https://arxiv.org/abs/2005.08926). We transfer tokenization ideas, not published forecasting architectures verbatim.

**Intervention.** Learn or freeze 8 sensor groups from training-only co-update structure, retaining raw-channel identity embeddings. Within each row, pool feature-wise embeddings into 8 group tokens by feature attention. Temporal layers attend causally over the last 64–256 rows for each group; a current-row cross-group layer exchanges information. Relative attention bias gets both row distance and each group's observed update-count distance, plus age since that group last changed. Keep a current-row fast path for every scored row. A second scale rung adds only *completed* 16-event summaries plus the unfinished current prefix; it never assigns a future block summary to earlier rows. A two-query readout produces t0/t1 separately, sharing the body but learning different history queries.

**Assumptions/prediction.** Co-update blocks are stable measurements of partially asynchronous entities; raw channel identity is preserved if the groups are imperfect. Same observed value can have different staleness. Event/row distances should have different learned effects and swapping only event-age metadata should affect lag-sensitive cases. If one clock dominates, the other may be unnecessary; attention alone does not prove physical influence.

**Test/falsifier.** Stage the comparison, avoiding a huge factorial: (1) small causal row-token Transformer with linear embeddings; (2) same model with feature/group embeddings; (3) same treatment with dual-clock bias. Fixed parameter/FLOP reports and updates, matched evaluation. Clock toy: duplicate repeated observations while preserving event order; event-history channel should remain stable while row-age channel may change. A no-difference result between dual and row clocks weakens the clock intervention, not the whole Transformer family. Future-suffix mutation must leave every prefix prediction unchanged.

**Cost/ladder.** Factorization avoids full attention over 20,000×112 tokens. Small: d=96, 2 temporal layers, 8 groups, local window64; medium: d=192, 4 layers, window256; teacher: d=384, 6 layers, local window512 plus completed summaries, only on admitted cloud hardware. Do not assume all rungs fit local VRAM. Prototype requires actual-device profiling; initial screen ceiling ≤30 GPU-minutes, eventual long fit separately admitted. Compression path: own teacher outputs/family summaries into the recurrent student, and fixed-blend conditional-value test.

**Artifact/interaction.** Independent grouped causal attention implementation, explicit token chronology and cache reset schema. E537-C × E537-D and E537-A × E537-D are interaction nodes with their own complete endpoint comparison. Training parity with streaming inference is mandatory; upstream iTransformer and PatchTST normalize over the complete supplied context and produce forecasts after that context, so calling either on a whole chunk to generate early-row predictions would change causality.

## E537-E: ordered path areas as a compact cross-instrument memory

**Family/lens:** geometric sufficient statistics; unconventional transfer from rough paths. **Source component:** the second signature level distinguishes order, and Chen's identity composes observed path pieces. [Signature primer, Chen identity](https://arxiv.org/html/1603.03788v2).

**Intervention.** Project observed changes to r=8 channels with fixed training-only PCA or a learned projection. Maintain first-level displacement `s` and antisymmetric second-level area `A`. For increment dx, update `A <- A + 0.5*(s*dx^T-dx*s^T)` then `s <- s+dx`. This is the area component of the piecewise-linear signature of the prefix. Use causal trailing windows of 32 and 128 events, with a ring of prefix signatures and Chen inverse composition, or explicitly declared prefix blocks; initial implementation chooses trailing windows to avoid arbitrary block resets. Augment with raw level, event count and row-age; no blanket time-warp invariance is imposed. Add these 28 pairwise area coordinates per scale to the current recurrent model.

**Assumptions/prediction.** A-then-B versus B-then-A carries useful cross-response information beyond individual accumulated changes. Endpoint-only features cannot distinguish the two. Time reparameterization invariance is useful only for the geometric branch; elapsed event/row time remains available elsewhere. Anonymous channels can be used without naming actual trades.

**Test/falsifier.** Exact synthetic rectangle: swap the two ordered increments, hold final level fixed, and verify area sign reversal. Duplicated zero increments leave area unchanged. Compare endpoint/displacement-only versus displacement+signed-area, and versus symmetric second moments with matched added dimensions. A gain that survives area-order scrambling on a controlled synthetic probe does not support an order mechanism. On real data, posthoc shuffling is a diagnostic intervention, never a claim that its counterfactual label is known.

**Cost/ladder/interaction.** O(r²) per step and O(window*r²) naive prefix ring; r8/2 windows small; r16/4 windows teacher features remain bounded but require measured overhead. Small screen ceiling ≤15 GPU-minutes. Retain compact areas at serving or distill the teacher. Interaction with E537-D: area summaries as event tokens, preserving order while compressing long intervals. Reusable artifact: independently implemented signature state and inversion tests.

## E537-F: metric-weighted distribution head

**Family/lens:** invert the evaluator's measurement. **Source basis:** inspected local official metric `src/wnn/gmetric.py`; conditional expectation argument below is our derivation, not a literature result.

Let clipped label Y lie in [-2,2], W=abs(Y), and define a weighted probability measure Q with density W/E[W] over the fixed scored population. For a causal input X, `m(X)=E_Q[Y|X]=E[WY|X]/E[W|X]`. By the projection property and Cauchy–Schwarz, this conditional mean maximizes population weighted Pearson among square-integrable functions of X, up to positive affine changes if clipping does not alter them. Because m lies in [-2,2], m itself is an admissible clipped prediction. Where E[W|X]=0 the output is irrelevant under Q. This does **not** mean an arbitrary ratio of two poorly trained heads is optimal in finite samples, nor that arbitrary rescaling remains invariant after clipping.

**Intervention.** Keep the backbone fixed initially. Compare the existing head to (a) an ordinary scalar head trained by clipped-label weighted MSE and (b) a distribution head over 17 fixed ordered bins on [-2,2]. Train probability mass with a proper categorical objective plus a within-bin bounded conditional mean if needed. Decode `sum_b p_b * E[WY|b,X] / (sum_b p_b * E[W|b,X]+eps)`, using actual within-bin moments, not assumed bin centers as an exact identity. First implementation uses fixed centers as a named approximation and retains an auxiliary direct scalar head. Each target has separate mass/mean heads. A sign-only classifier loses magnitude information and is an explicit weaker control, not the proposed endpoint.

**Assumptions/prediction.** Multi-modality or state-dependent tail mass may be easier to learn distributionally than through one scalar. Direct weighted MSE already targets the same population quantity, so any gain is optimization/representation/regularization, not a newly discovered metric optimum. The head should improve weighted calibration of tail-asymmetric states at comparable regression capacity.

**Test/falsifier.** Finite discrete toy enumeration validates the ratio versus unweighted mean, zero-weight cases and clipping saturation. GPU-only head screen on frozen own-backbone training activations, with evaluated membership excluded from backbone fitting. Compare scalar weighted-MSE, distributional decoded mean and ratio of separately estimated moment heads at matched parameter counts. If the best distribution head simply reproduces the scalar function without score/conditional contribution, no distributional complexity is justified for that recipe.

**Cost/ladder/interaction.** O(17) outputs per target; frozen-head screen ≤10 GPU-minutes, end-to-end head treatment only after useful evidence. Large teacher may emit richer tail distributions to distill into two compact moments or directly into a scalar. Combine separately with E537-A/D; official scoring stays unchanged. Reusable artifacts: exact objective derivation, head decoding tests and prediction-level calibration diagnostics.

## E537-G: recover an observation grammar before assigning semantic names

**Family/lens:** inverse measurement and instrumentation. **Sources:** identifiable nonlinear ICA requires extra structure/auxiliary information [Hyvarinen et al.](https://arxiv.org/abs/1805.08651); order-flow and lagged cross-impact motivate ordered coupled state, without establishing these channels' identities [Cont et al., OFI](https://arxiv.org/abs/1011.6402), [lagged cross-impact](https://arxiv.org/abs/2112.13213).

**Intervention.** On fitting components only, build a channel graph using exact/epsilon change support overlap, conditional rank relationships, signed-delta alignment and within-sequence constancy. Separate deterministic relations from mere correlation. Freeze graph/group identities. Hold out complete fitting components for stability checks; this is internal discovery, not a pristine competition holdout. Learn a small reconstruction/next-observation model for the graph groups; optionally contrast real `(current, causal history)` against training-only history-swapped pairs. Feed the resulting innovations/group IDs to E537-C/D. No sequence ID, future label change time or validation-fitted transform enters serving.

**Assumptions/prediction.** The measurement pipeline has stable algebraic or co-update structure despite anonymous values. A useful recovered group should be stable across components and simplify next-observation prediction; an inferred causal market meaning requires additional evidence. Nonlinear ICA assumptions may fail: interacting instruments, noninvertible aggregations and dependent sources make semantic recovery non-identifiable.

**Test/falsifier.** Stream a bounded fitting-only complete-sequence panel; save 112×112 change-overlap and rank maps, training-only transform hashes and cross-component stability. Epsilon is train-fit and paired against exact change masks. If group assignments vary arbitrarily across components or vanish after removing common normalizers, do not hard-wire them. Keep channel identity and soft learned grouping as fallback.

**Cost/ladder/interaction.** Read-only bounded CPU EDA ≤10 minutes/1.5 GB, never whole-file pairwise materialization. Learned reconstruction fits require GPU admission. Linear/grouped next-observation model → small causal autoencoder → independent predictive-state teacher, with compact innovations distilled to recurrent student. This is a dependency-removing diagnostic for E537-D, not an indefinite prerequisite: D can begin with train-only learned groups/identity tokens.

## E537-H: use interventions to find what a model actually remembers

**Family/lens:** mechanistic interpretation as an experiment generator. **Sources:** attention weights alone may fail to explain predictions [Jain and Wallace](https://arxiv.org/abs/1902.10186); activation-patching conclusions depend on corruption and metric choices [Zhang and Nanda](https://arxiv.org/abs/2309.16042). Interpret model computation separately from market causality.

**Intervention.** For an own-trained recurrent or attention teacher, save bounded prefix states around predeclared events: group updates, long unchanged spells, recurrent-state returns and opposite group lead–lag order. Use matched donor states with similar current x and row age, selected only from fitting/discovery membership. Patch one state block, memory head, or key-associated update; measure prediction change, weighted residual change on a fixed diagnostic panel, and recovery of deliberately removed input information. Compare zero ablation, matched-donor replacement and random-donor replacement. A stronger effect of unrealistic corruption is not automatically an explanation.

**Assumptions/prediction.** Useful memory is localized enough for a finite intervention to identify a representation deficit. Redundant/distributed codes may have small single-neuron effects. Attention heatmaps are merely descriptive. A stable result across at least two intervention constructions can nominate a memory horizon, feature grouping or auxiliary target for a new arm.

**Test/falsifier.** Start with whole-state and head-block interventions, not a large sparse-autoencoder project. Synthetic known-mechanism models must recover the right memory block. Real-model patches must preserve chronology/reset and report distance from the recipient activation distribution. If only out-of-distribution donors change output, semantic interpretation is unsupported. Grade intervention claims independently; an actor cannot approve its own causal explanation.

**Cost/ladder/interaction.** Bounded replay of ≤16 full discovery sequences, 3 intervention types, at most 8 state blocks; GPU export if needed, CPU statistics/plots only. Reuse frozen model and predictions; no claim of newly trained improvement. Teacher-scale circuit probes may justify compact state supervision, head pruning or history-query tokens. Save PNG/SVG plots under this lineage's `plots/` when EDA is executed; this assignment itself creates no model EDA.

## Initial qualitative allocation before seeing existing proposals

1. E537-C is the cheapest way to test whether sensor geometry is the bottleneck without changing memory.
2. E537-A tests a distinct non-Transformer retrieval mechanism with an exact overwrite falsifier.
3. E537-D is the serious causal Transformer teacher route, staged so embedding, clock and scale changes can be attributed.

E537-E is the unconventional reserve with small state and a sharp order-sensitive test. E537-B is a second non-Transformer attention family. E537-F is a low-cost objective/head interaction after checking existing objective work. E537-G/H supply bounded diagnostics and must not block ready useful training. This ordering is provisional information-value judgment, with no invented expected score.
