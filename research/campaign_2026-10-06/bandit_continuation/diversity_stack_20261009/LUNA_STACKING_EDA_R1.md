## Frozen meta-crossfit protocol

1. Freeze the source-qualified 468 group IDs, 141 feature-only connected components, selected-row mask, target index, and all candidate prediction SHA-256 values before computing any meta-score. Build the meta features from arrays only after checking each prediction's producing checkpoint, complete ancestor/teacher/propensity closure, split SHA, group order, finite float32 values, causal reset, and exact mask. Any member whose ancestor trained on the outer-evaluation component is invalid for that component. Do not use labels, sequence IDs, component IDs, or future features as inference-time inputs.
2. Assign whole connected components to five deterministic outer folds using the already-frozen component inventory. Inside each outer-training set, choose scaling, regularization, candidate subset, and any gate threshold by a second grouped component split. Fit the meta learner only on the inner/outer-training components' OOF base predictions and labels. Freeze it, then score once on the outer components with `global_wp_clip2_v1`. This evaluates the complete selection procedure; a post-hoc winner chosen across outer scores remains development evidence.
3. Keep the base predictions genuinely OOF for every meta row. Check closure recursively, not only the top-level model's `fit_valid_groups`. A teacher, initializer, family-target source, propensity model, or residual label generator that saw the row's component disqualifies that row. For a student trained on teacher targets, record both the student's label-fitting membership and every teacher target's production membership. All-data exports are usable only on the groups explicitly held out by their source's exact fold mask.
4. Report per-target pooled WP, mean WP, selected rows, fixed component-paired deltas, and a paired component bootstrap. Also report the number of inner choices and all attempted meta variants. With 141 dependent components, 808,863 rows are not 808,863 independent observations. The panel is already exposed; report the result as discovery, not untouched confirmation.
5. For eventual serving, refit the frozen meta procedure on available OOF-safe development components, but separately check the train-population shift between fold teachers and final all-data models. Do not reuse in-sample predictions to make an OOF training table. The final endpoint still needs a causal, deterministic reset test and a complete served-runtime comparison.

## Metric alignment, scaling, and shrinkage

For each target, the official implementation first clips target and prediction to ±2, fixes `w_i = |clip(y_i, −2, 2)|`, then computes pooled weighted correlation. With `Y=clip(y)`, `P=clip(p)`, weighted means `μY, μP`, standard deviations `sY, sP`, and `ρ=Cov_w(Y,P)/(sY sP)`, the local derivative before the final correlation clamp is

`∂ρ/∂p_i = 1(−2 < p_i < 2) · w_i/W · [(Y_i−μY)/(sY sP) − ρ(P_i−μP)/sP²]`.

For the final mean of two targets, average the two target derivatives. The target-derived weight is fixed; it is not differentiated. The derivative is zero at clipped prediction points (using the ordinary interior subgradient) and if the final correlation clamp is active. This is the direction for a small correction to the *current served blend*, not a replacement training loss.

Thus `y−p` is not the official score residual: it ignores correlation's prediction-variance normalization and the score's weighted centering. A correction with a large MSE residual may have negative directional score signal. On training components, use either this exact score gradient as a pseudo-response for a deliberately small corrector, or optimize the official score directly; on outer components, only evaluate the frozen corrector. Always calculate the final metric with the official implementation.

For linear stacks, standardize each prediction column using weighted means/scales computed only on the relevant meta-training components. Train against clipped labels with weights `|clip(y)|` as a stable screening surrogate, then choose the shrinkage/weighting procedure by nested inner-component official WP, not training MSE. Penalize coefficients after standardization; start with strong ridge shrinkage. A simplex version constrains weights nonnegative and summing to one. Do not individually clip every member before mixing unless that is a separately declared treatment: form the raw blend/correction first, then let the unchanged official evaluator clip the final prediction. Use float64 for small meta fits and metric reductions; store frozen inference coefficients in a deterministic float format.

## Hypothesis cards

### 1. Fixed static additions: signal before search

- **Mechanism / candidate.** Use the two existing matched seed endpoints and add one already-exported, held-out member at a predeclared 0.5 branch weight: for seed 3, candidate `0.5 × matched parent/head endpoint + 0.25 × H230 student core + 0.25 × H230 student HFT`; for seed 4, candidate `0.5 × matched parent/head endpoint + 0.5 × held-out seed-99 parent`. Score each only on its exact 468 held-out rows.
- **Control.** The corresponding unchanged matched parent/head endpoint at the same seed. Keep the seed-3 and seed-4 contrasts separate.
- **Ancestry and signal.** Use exact fold0 split and checkpoint/prediction identities above; prove zero eval-group overlap for each selected member and its ancestor closure. Record candidate-to-control paired delta and the exact official metric, not pairwise correlation alone.
- **Prediction / cheapest falsifier.** A genuinely useful branch has positive conditional WP contribution on the 141 components, not merely large disagreement. Compute these fixed additions from mmap arrays and compare to the exact frozen baseline. Falsify this fixed blend if its outer-component delta is consistently nonpositive or its gain is concentrated in one connected component.
- **Cost / successor.** No base fit; only a bounded rowwise blend and metric pass. A success earns a new prospective fold or paired-seed confirmation, not a coefficient sweep on this panel. At inference, cost is one extra member; benchmark the full sequence endpoint.

### 2. Small weighted ridge stack

- **Mechanism / candidate.** On at most five predeclared members (matched parent endpoint, exact Z3 endpoint, H230 seed-3 endpoint, held-out seed-99 parent, and optionally one additional cleanfold member after ancestry audit), fit a target-specific affine stack with weighted standardization and ridge penalty. Candidate procedure chooses one λ from a small log grid solely by inner component CV using official WP. Keep a shared member list and cap effective degrees of freedom with strong shrinkage.
- **Control.** Equal-weight blend of the exact same selected member predictions; also retain the incumbent matched parent/head endpoint as the primary competition control.
- **Ancestry / falsifier.** Every meta-training component must be OOF at level one; all selection stays inside outer-training components. If chosen weights are unstable across outer folds, collapse to the fixed blend. If tuned ridge fails to beat its inner-selected static control on outer components, no learned-stack claim.
- **Cost / serving.** Tiny analytic fit per fold; one matrix-vector product and an intercept/scale at inference. Include coefficient count and full endpoint timing. MSE is only the inner numerical surrogate; official WP is the model-selection objective.

### 3. Nonnegative simplex blend

- **Mechanism / candidate.** Fit one shared nonnegative sum-to-one vector over the same ≤5 audited members by maximizing pooled two-target WP on inner grouped OOF predictions. Use a frozen coarse simplex/coordinate search or deterministic projected optimizer with one selected step budget. A single shared weight vector is the first test; per-target weights double the flexibility and are a separate descendant.
- **Control.** Equal static weights on identical members and the matched parent/head endpoint.
- **Ancestry / falsifier.** OOF and nested component protocol above. Reject the learned procedure for this panel if its outer score does not improve on equal weights, or if the vector repeatedly collapses to one member and adds no score over selecting that member alone. Do not interpret one optimized vector as a causal model contribution.
- **Cost / serving.** Training is small; inference is a handful of multiplies. Nonnegativity and sum-to-one limit extrapolation under calibration shift. Retain raw-weight and final clipped-score diagnostics.

### 4. Tiny causal gate on a fixed residual branch

- **Mechanism / candidate.** Let `p0` be the matched static blend and `r = p_alt − p0` the fixed branch difference. Train `p = p0 + α(z_t) r`, where `α(z)=α0 + (1−α0)·tanh(aᵀz)` is strongly shrunk toward its inner-CV constant `α0`. Restrict `z_t` to a short preregistered list of current/past-only, target-independent diagnostics, e.g. clipped model disagreement and a causal state magnitude; no sequence ID, future value, label, or component identity reaches inference.
- **Control.** The inner-CV-selected constant `α0` using the same branch, plus the original static baseline.
- **Falsifier.** If the gate's outer component score does not beat the constant blend, or coefficients/signs change sharply across component folds, the conditional rule is overfit. A high conditional correlation without positive heldout score change is not success.
- **Cost / serving.** Fit is a very small regularized regression. Serving cost is a few causal feature calculations and scalar multiplies, but must be included in the actual sequence runtime/reset tests. No neural fit is part of this card.

### 5. Orthogonal conditional-diversity test

- **Mechanism / candidate.** For a new member `q`, project its centered prediction onto the current stack's centered prediction span using only meta-training components; define innovation `r⊥ = q − Proj_span(q)`. Measure the heldout directional score signal `g(p0)ᵀr⊥` and then the actual fixed small-step metric change `WP(p0+ηr⊥)−WP(p0)` for predeclared η values.
- **Control.** Raw pairwise correlation and an equal-weight blend are diagnostics, never the decision criterion. The deployed control remains `p0`.
- **Unconventional transfer.** Markowitz's covariance result says the variance of a weighted portfolio depends on the full covariance matrix, not individual variances. The useful prediction analogue is more specific: use the covariance matrix of OOF predictions *and their target-aligned covariance/score gradient*, not low correlation alone. A candidate with low correlation but zero or negative `gᵀr⊥` is disagreement without useful signal. The analogy is structural, not a claim that forecast portfolios and this clipped WP objective are identical.
- **Falsifier / cost.** If residualized candidate disagreement does not align with the WP gradient on heldout components, do not promote it as a booster. Projection and directional derivative are cheap matrix operations. Because the fold has been inspected, treat results as exploratory.

### 6. WP-gradient stagewise residual booster

- **Mechanism / candidate.** Freeze a base blend `p0`; create an inner-training pseudo-response from the exact per-row derivative above, then fit one highly regularized linear/low-rank causal residual learner `h(z_t, p0, r)` and predict `p0 + ηh`. Set η using only inner component CV against official WP. This follows functional gradient descent in the chosen score geometry rather than fitting raw `y−p0` as if MSE were the competition objective.
- **Control.** Fixed static `p0` and a same-complexity learner trained on raw MSE residual, reported as a distinct contrast; only WP-gradient version is the primary candidate.
- **Ancestry / falsifier.** Fit residual learner on OOF base predictions and training-component labels only. Hold entire connected components out for evaluation. Fail if the exact official score gradient has no positive inner-to-outer directional transfer or if the final clipped score decreases.
- **Cost / serving.** The linear first screen is CPU-cheap. Preserve full endpoint costs and reset behavior. The gradient target is score-local, so use a conservative η and require outer evidence before deepening.

### 7. Zero-initialized causal neural correction

- **Mechanism / candidate.** Only after card 6 supports residual signal, fit a small zero-initialized causal adapter that consumes current/past features, the frozen base prediction(s), and a compact causal hidden-state summary, then emits a residual `δ_t`. Start with one shallow layer and a fixed parameter ceiling. Use the WP-gradient pseudo-response or direct differentiable WP objective; compare against raw-residual MSE as a separate loss arm. Whole sequences reset state at each new sequence.
- **Control.** Same frozen base blend with `δ=0`, plus the best analytic card-6 correction at matched meta-training budget.
- **Ancestry / falsifier.** For each outer component, train the corrector only from OOF base predictions and labels on other components. No component's target may appear in its teacher, source, propensity, or corrector training. Fail if any outer fold loses score, the neural correction is unstable, or full endpoint runtime exceeds the useful serving envelope without a measured compensating gain.
- **Cost / status.** This needs a separate root-admitted small fit; no fit was run or requested here. Keep the analytic residual as the cheaper comparator. Report fitted parameters, training budget, component-fold outputs, and CPU runtime.

### 8. Matched robust-loss source diversity

- **Mechanism / candidate.** If the OOF table shows a stable conditional gap for a branch, train a fresh own student with a declared Huber target loss while holding architecture, optimizer, seed pairing, source weights, update budget and checkpoint rule fixed. Choose Huber δ in target units before fitting; do not use the public metric's clipping as training-target clipping. Measure the student's OOF residual target-gradient signal and contribution to the same fixed served blend.
- **Control.** Paired fresh student with the identical recipe except squared-error target loss; same training groups excluded from each evaluated component and same teacher/source/propensity closure.
- **Prediction / falsifier.** Huber may reduce the influence of rare large residuals; because WP weights clipped-label magnitude, that may remove useful score signal. The mechanism is supported only if the Huber branch adds outer-component WP to its matched control, not because it has lower residual variance or lower pairwise correlation.
- **Cost / descendants.** Requires two matched fresh fits after root admission, so it is lower priority than no-fit stack screens. A useful branch may be distilled into a static or gradient-aligned served blend; an isolated student win is not sufficient.

## Prioritized minimal matrix

1. **No-base-fit integrity and fixed comparisons:** verify all exact member hashes/row masks; rescore the frozen Z3 and H230 controls/candidates; evaluate only the two predeclared half-strength branch additions. Do not expand the member pool or select on many hand-designed slices.
2. **Analytic meta-screen:** with the audited prediction pool, run outer five-fold/inner component selection for equal blend, a small weighted-ridge grid and one shared simplex vector. Record every candidate and bootstrap by connected component. Root should register/admit the analytic run before it reads any new score if it will affect active allocation.
3. **Conditional signal:** if an analytic learner has stable outer value, test the single tiny causal gate and WP-gradient linear residual as separate descendants. Use raw MSE residual only as a clearly labeled diagnostic/control.
4. **Neural/recipe confirmation:** only a branch with heldout conditional signal earns a root-admitted zero-init residual adapter or paired Huber-vs-MSE fresh student fit. Confirm on another component partition/seed pair with the full deterministic endpoint. Existing fold1 exposure remains exposure; it is robustness evidence, not untouched confirmation.

This ranking is about information per base-model fit, not proof that stackers should replace the current endpoint. H230 and Z3 fixed-endpoint comparisons are nearly flat with broad intervals; they support low-cost conditional-combination checks, not a universal ensemble gain or a forecast above the public best.
