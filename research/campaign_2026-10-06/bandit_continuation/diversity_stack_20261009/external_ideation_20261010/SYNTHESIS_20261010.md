## Convergence
Both ideators independently ranked the same two ideas first: (a) causal inference-side sign handling on existing predictions (Grok: decreasing-hazard sign hysteresis; Freebuff: forward-message sign decoding) and (b) recovering structure of the anonymised event codes (Grok: lattice recovery; Freebuff: mirror decode into signed flow). Further ideas: age/run conditioning, state hold on non-events (event-driven GRU), sign-only bottleneck teacher, monotone impact kernels, shared-jump model, class-from-moments output maps, surprise-gated plasticity, test-time bias control.

## Cheap tests run today (CPU, saved predictions or data, no training)
1. Causal EMA and sign-hold post-processing of the best student (fold 1, WP 0.66938): every setting lowers WP. EMA a=0.8 -0.0005, a=0.4 -0.0060, a=0.08 -0.045; hold m0=0.05 -0.0000, m0=0.1 -0.0001, m0=0.2 -0.0005, with an age-growing margin (k=1) -0.0013 to -0.50. Grok's falsifier ("no schedule gains >= 0.004") is met with room to spare; the premise that late sign errors are chatter around a correct entry sign is false - the model's late sign flips carry information. The inference-side family is closed (script `scripts/postprocess_probe.py`). The learned forward-filter variant (Freebuff #2) is not strictly excluded but its simple special cases are.
2. Event-code alphabet (`scripts/feature_lattice_probe.py`, 40 validation sequences): no column is a small discrete alphabet (none below 3,000 distinct values; 3,000-3,700 distinct values with 86-90% of rows on the 16 most frequent values for the first 22 columns). The columns come in blocks that change on exactly the same rows: columns 0-21 change on 31.4% of rows and label changes are 3.18x more likely on those rows; 44-47 change on 40.2% (lift 2.49); 48-51 on 14.8% (0.87); 52-69 on 11.9% (0.66-0.69); 22-43 are continuous and change on 69-71% (lift 1.15). So the data is a multi-rate set of update clocks; the label-change lift of the fast-refresh block is a strong event cue that the recipe's "since" features already encode. No exact-code mirror evidence appeared; R2-8 stays high-risk.
3. Shared jump (Grok #7): t0 changes on 11.4% of rows, t1 on 11.0%, both on 2.9% versus 1.26% expected under independence (lift 2.3x): changes are only weakly shared (P(t1 changes | t0 changes) = 25% vs 11%). A joint hazard model would capture a quarter of the co-movement at best; deprioritised.
4. Class from warm-up (Grok #8, `scripts/class_from_warmup_probe.py`): the market class is predictable from the first 500 rows with 99.4% balanced accuracy (5-fold logistic regression on change-rate and difference-scale statistics of 112 columns; class 3 recall 100%). So class is a readable property of the instrument or regime, trivially inferable early, and the recurrent state already has this information. A class-conditioned output map is cheap to build but the information is not missing; expected gain small, to be tested together with a class-3-only evaluation (held in the backlog). Also useful: per-class blend weights and class-aware sampling are feasible without leakage.

## What remains open from the ideators
Event-driven state hold (exact copy of the hidden state on non-events, trigger from the fast-refresh clock block), sign-token bottleneck, age/oracle-age ablation (upper bound only), Freebuff #7 age x class atlas with stratified sampling (measurement is free), self-supervised innovation features. The strongest structural cue found is the clock-block label-change lift of 3.18x: a model that conditions its update on the fast clock (it is not a learned gate in our GRU variants; the two-clock arch in the queue used a different split) is the next concrete training experiment.
