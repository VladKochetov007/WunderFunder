# H-283 label-free causal scale calibration: fold0 468 panel

**Verdict.** No label-free gain. Every servable calibrator lowers the official WP on held-out components, and the row-shuffled-feature control loses almost as much. The damage comes from the calibration fit itself, not from the features. Exposed development panel only; not a public forecast.

Files: `H283_label_free_calibration.py`, `H283_label_free_calibration_20261008.json`, `H283_run_20261008.log`.

## Causality (serving)

- Input features at row t: EW(|x_s|), EW(x_s), EW(x_s^2) for x in {i0_dp0, i0_dp1, i0_dv0, a0}, over s <= t, half-lives 200/1000/5000, zero initial state per sequence (`scipy.signal.lfilter`). They use inputs at rows 0..t, which `predict()` has at row t.
- Own-prediction features: EW mean and std of the base prediction over rows s <= t-1 (shift by one).
- step_in_seq / 20000.
- Calibrator output at row t is a function of (features_t, base_t) and frozen parameters.
- Labels enter only at fit time, on training components of the 141-component 5-fold split (seed 271828). Parameters are frozen before the held-out fold is scored.
- Variant (c) uses a causal feature bin (quartiles of EW|i0_dp0| at HL 1000, thresholds from training folds), not the label-derived `market_class`.

## Calibrators (fit per target, weights |clip(y,±2)|)

- (a) `mult`: x * exp(z·beta), L-BFGS on weighted squared error, ridge 1e-4, 300k-row subsample.
- (b) `add`: x + v0 + z·v, weighted ridge (lambda = 1e-3 · sum w) on y − x.
- (c) `bin`: per causal bin, a + b·x ridge toward (0, 1).
- Control `mult_rowshuffle`: fitted (a) applied to held-out rows with features randomly permuted among held-out rows.

## Reading

- The row-shuffled control loses nearly as much as the real-feature variant. The features add nothing measurable. The loss is from fitting scale and offset on training components that do not transfer to held-out components.
- The additive calibrator is the most harmful. The output is unclipped, so it can push predictions outside the metric's ±2 range.
- Oracle context (H-281, label-delayed, not servable): per-sequence scale/bias information is worth a lot in-panel, but no causal feature set here recovers any of it.

## Limits

- Calibrator hyperparameters (ridge levels, subsample size, feature set, bin edges) were set once and not tuned. A tuned or regularized variant could differ; none was run.
- Scores are on the exposed 468-group panel. Bootstrap is conditional on fixed predictions.
- Nothing here supports a submission change.
