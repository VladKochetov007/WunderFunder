**Verdict.** No exact spread identity. In class 3, t0+t1 is not equal to any single feature or feature difference (best pairwise |corr| 0.58; residual median 1.28). Projecting predictions onto the assumed identity lowers WP by 0.0109 (oracle, not servable).

## Identity search (step 1)

- Features: 112 columns (`i0_*`, `i1_*`, `a0..a7`). Bid/ask columns not identified.
- Rows: all 468 eval sequences, rows t = 99, 109, ... (stride 10), grouped by market class from the label cache.
- Tested at the same row t: each target and t0+t1, t0−t1 against each single column and each pairwise difference F_i − F_j (corr from the feature covariance matrix).
- Exact check: residual of (t0+t1) + (F_i − F_j) for the best pair.

Reading. The best pair correlates with t0+t1 at only 0.58 in class 3. The residual of the identity is comparable to the spread of the sum (1.28 median against a sum std of 0.38). No single column or pair difference reproduces t0+t1 exactly, so the claimed identity t0+t1 = −(ask−bid) is not confirmed for class 3 with these columns. Search was pairwise and linear only; a richer map was not tested.

## Projection oracle (step 2)

- Base: H272S4 hidden-only. For class-3 rows, the prediction pair is projected onto t0+t1 = s_hat, with s_hat = −(p10 − p21) from the best pair and the residual split evenly.
- Rows outside class 3 are unchanged. Scored with the official metric on the official mask. Bootstrap: 2000 draws, seed 271828.
- Base WP 0.681363. Projected WP `base_wp + delta`: delta −0.010878, 95% CI [−0.013137, −0.008958].
- The oracle uses the market-class label to select rows, so it is not servable. Even with that label, the feature-based constraint lowers WP.

## Limits

- Exposed 468-group development panel. Not a public forecast.
