# H-281 delayed-label reveal test: fold0 468 panel

**Headline.** H-281 premise refuted for L<=100: y_t is not reconstructible from features at t+L (CV R² at most 0.19, falling with L). The recalibration numbers below use y_{t-L} that are not causally available, so they are a leakage upper bound (oracle), invalid for serving. Kept only as a diagnostic of how much per-sequence slowly varying target bias/scale is worth; this motivates causal feature-based scale tracking, not a submission gain.

Files (this directory): `H281_horizon.py` and `H281_horizon_20261008.json` (step 1); `H281_recalibration.py` and `H281_recalibration_20261008.json` (steps 2 and 3); `H281_controls.py` and `H281_controls_20261008.log`; `H281_diagnostics.py` and `H281_diagnostics_20261008.log`. Predictor: H272S4 hidden-only (`exports/H272_PARENT_V2_CLEANFOLD_VALID/hidden_only.npy`) and the equal pair with H272d multiplicative. Metric: `scorer.moments`/`pooled` (`research/campaign_2026-09-30/audit/campaign_score.py:85,119`), official mask (scored and step >= 99). Bootstrap: `wnn.evaluation.paired_component_bootstrap`, 2000 draws, seed 271828.

## 1. Horizon (step 1)

Only the 468 evaluation row groups of `datasets/valid.parquet` were read, with column projection (112 features plus t0, t1). For each lag L in 0..30 and {40, 50, 60, 80, 100}, y_t was regressed on the features at row t+L, using rows t = 99, 104, ... (stride 5). The 5-fold cross-validated R² uses the same component split as the blend lab. Market classes come from `cache/valid_targets.npz`. Sizes: class 0 = 85 sequences, class 1 = 92, class 2 = 122, class 3 = 169.

Reading. No lag reconstructs y_t. R² is at most 0.19 in any class, and it falls with L after L = 1 for every class. The t+L features carry little information about y_t even for L = 1 to 5. So the horizon cannot be pinned from these columns with linear or single-feature maps. The prior claim (t0 = F − ask, t1 = bid − F) is therefore not confirmed here. Two caveats: the test is linear in the features, and the ask/bid levels may not be among the features in the form assumed.

## 2. Recalibration oracle (step 2; leakage bound, not servable)

Causality (index arithmetic). Let x_t be the baseline prediction at row t and inc_s the increments built from (x_s, y_s) for selected rows. For reveal delay L, the label y_s is usable at row s + L. Then E[t] = lfilter(inc)[t] depends on rows 0..t, and the stats used at row t are S_t = E[t − L], which depend only on rows 0..t − L (zero for t < L). The output a_t + (1 + c_t) x_t uses (a_t, c_t) from S_t only, so no row s > t − L affects the output at t. Stats reset per sequence. The ridge prior toward a = 0, c = 0 (b = 1) uses κ_t = 0.05 × E_w[t − L].

Weights are |clip(y_s, ±2)| on selected rows. The affine fit is a + c·x on r = y − x. The scale-only fit is c·x with no intercept.

## 3. Controls (`H281_controls_20261008.log`, `H281_diagnostics_20261008.log`)

- Shuffled labels (y taken from another random same-class sequence, L=1, hl=2000): affine −0.430, scale −0.386. Wrong labels badly damage the output, so the mechanism is label-driven and high-variance.
- Oracle in-sample per-sequence fit (all labels of the sequence, static): affine +0.056, scale +0.026. The time-varying causal fit beats this static oracle.
- Leak check (stats through t + L, future labels, L=1, hl=2000): affine +0.126. The causal delayed version (+0.115) is close, so the delay costs little.
- Within-sequence weighted correlation: baseline 0.657; causal L=1 0.747; leak 0.771. Part of the pooled gain is a within-sequence correlation gain. Per-sequence affine maps are the largest part, and their median c is −0.094 (IQR −0.221 to −0.002), so the fit mostly shrinks predictions.
- Identity map: delta 0.

## 5. Servability and limits

- The serving `DataPoint` has no labels, so the recalibration cannot run under the official protocol. The horizon was not identified, so the delay L cannot be set from the data.
- Gains are measured on the exposed 468-group panel. The half-life, κ and delay grid were chosen on that panel, so the in-panel numbers are optimistic. A fresh-fold test is needed before any claim.
- The bootstrap is conditional on fixed predictions. It does not estimate training or public-transfer variance.
- No public-score expectation follows from these numbers.
