## 3. Hypothesis cards

### ASR-01 — Stage-specific optimizer transfer

- **Parents/family/lens:** A0 + own-Muon evidence; optimization geometry; factor by teacher/parent/final stage.
- **Intervention:** keep A0 final AdamW control; change only the final student's update rule to our explicitly named gate-wise Muon recipe, keeping target, parent, attempts, clip, order and nominal OneCycle horizon. Specify `--muon-scope rnn` or `hidden` once; choose `rnn` for the first screen. Name all group LR multipliers and do not assume teammate×6 is equivalent to our scaling.
- **Mechanism hypothesis:** parent representation benefits from Muon whereas adaptation to changed teacher targets may favor coordinate-wise AdamW; the reverse is also plausible. Predict a stage interaction, not universal Muon dominance.
- **Cheapest test/cost:** one matched final-stage candidate/control,2S total, using existing `--optim` flags and exported group/update-norm traces. Reuse the A0-analogue control if its exact inputs match. No new trainer is needed for the **own-Muon variant**.
- **Falsifier/breakpoint:** lower fitting target error with worse held-out WP or pair contribution defeats a simple “better optimization implies better endpoint” claim. One bad final-stage screen does not reject Muon parents.
- **Level2/reuse/serving:** fixed `.50:adamw` handoff via existing `--optim-switch` is a separate child if late adaptation is implicated; cold-start changed-rule matrix moments are explicit. Keep raw endpoint checkpoints, traces and predictions. The served architecture stays GRU256×2; training-only changes add no serving state.

### ASR-02 — Longer stable learning followed by a short cooldown

- **Parents/family/lens:** A0; horizon allocation; change time. Hägele et al. show constant-LR/cooldown trajectories can be reusable across training lengths in their studied setting; transfer to short recurrent distillation is a hypothesis. [Primary paper](https://arxiv.org/abs/2405.18392).
- **Intervention:** existing package `--optim adamw --sched wsd --warmup-frac .05 --wsd-decay .20 --wsd-final .0004 --lr .0001 --epochs 2`, versus A0 OneCycle at matched attempts. The.0004 floor ratio matches the nominal OneCycle minimum/peak; it avoids silently raising the floor25×. Record actual first/last applied LR because LambdaLR indexing differs.
- **Crucial attribution:** current WSD leaves beta1=.9 while OneCycle cycles it. This first run tests a **schedule-and-momentum package**. For a pure LR-shape conclusion, separately implement/freeze beta1 replay or constant-beta controls; this is not a prerequisite for the first useful package comparison.
- **Observable/test/cost:**2S with gradient/clip statistics, fixed-epoch target error, WP and prediction amplitude. Expect faster teacher adaptation if OneCycle cools too early; expect damage if the long peak erases the parent representation.
- **Falsifier/level2:** persistent larger train–evaluation divergence would oppose the proposed under-adaptation explanation. If useful, test half-peak5e-5 at full fidelity, then optional `--swa-frac .20` as a separately identified child. Existing SWA changes the saved endpoint; it is not an invisible evaluation option. SWA's benefit on the original vision experiments is not a GRU guarantee. [Primary SWA paper](https://arxiv.org/abs/1803.05407).
- **Reuse/serving:** same caches and pair serving; freeze cooldown/SWA window rather than selecting the best trajectory snapshot.

### ASR-03 — One finite reheat, then a separately measured noise pulse

- **Parents/family/lens:** A0 and ASR-02; optimization exploration/control; change time + instrument. SGDR motivates bounded warm restarts; gradient-noise work motivates stochastic exploration, but neither establishes that this GRU is trapped. [SGDR](https://arxiv.org/abs/1608.03983), [gradient noise](https://arxiv.org/abs/1511.06807).
- **Cheap existing-capability test:** `--sched sgdr --restarts 1 --warmup-frac .05 --wsd-final .0004 --lr .0001`, same two-epoch horizon, no noise, versus the matched control (2S). Two cycles end within the fixed budget. This tests scheduled reheating, **not** a detected plateau; beta1 is another package difference as in ASR-02.
- **Plateau child requiring implementation:** before training, select32 complete fitting sequences across fitting components by fixed hashes, with original main-target weights. Evaluate their deterministic training objective at progress.20,.35,.50 (fresh hidden-state resets; exclude auxiliaries from the trigger so a family-head transient cannot fire it). At.50, trigger once only if both successive relative improvements are below.002, all losses are finite, and no AMP skip occurred in the preceding observation interval. This is a policy hyperparameter, not a significance test. No trigger uses held-out labels. Cap monitoring at5% of fit time and record actual overhead.
- **Bounded intervention:** from.50 to.55, ramp applied LR to min(2×current LR,1e-4), then cosine-cool to4e-8 by the original end; retain optimizer moments and replay the control beta1 clock. Never extend the run. Compare this policy to a candidate with exactly the same reheat/trigger but a gradient-noise pulse during.50–.60. If the trigger does not fire, report `intervention_not_exercised` rather than negative noise evidence.
- **Noise scale:** after unscale, before global clip, normalize an independently seeded Gaussian tensor in each module to norm `.05 * max(||g_module||,1e-12)`, then linearly taper to zero across the pulse. Freeze this scale; no trial search. The existing `--grad-noise eta` applies `eta/(1+t)^.55` variance from the beginning and depends on parameter count; it cannot implement this pulse and should not be mislabeled plateau noise. Log actual pre/post-noise norms, clip fraction and AMP skips.
- **Falsifier/cost/level2:** noise improving training loss but damaging complete pair WP argues against a useful escape here. First pulse-vs-reheat comparison costs2S plus≤5% monitoring; do not require a three-way full-scale factorial before A0 runs. Deterministic noise RNG/trigger state must survive resume. Level2 combines a useful pulse with WSD cooldown. Training-only noise preserves deterministic inference.

### ASR-04 — Treat teacher amplitude as shrinkage, not housekeeping

- **Parents/family/lens:** A0 + historical normalized H230; target geometry; re-encode. Let `U=T/.8125`. Reference main target is `.3 clip(y)+.7 clip(.8125U)`; normalized target is `.3 clip(y)+.7 clip(U)`.
- **Intervention/test:** matched cache transform `T` versus `T/.8125` with identical raw family arrays, parent, optimizer, seed/order and clipping order. One2S comparison, or1S incremental when an exact control already exists. First perform a bounded streaming no-fit amplitude report: weighted fraction crossing±2, weighted RMS/means, and main/family gradient-scale proxies. No normalization of official weights or metric.
- **Why either can help:** normalization can restore signal if teachers are genuinely under-amplitude and clipped-tail saturation is rare. Shrinkage can denoise unreliable consensus and retain relative teacher ranks below the±2 saturation boundary. Scaling is not harmless merely because unclipped Pearson is invariant to positive global scaling: clipping, label mixing, nonlinear training, and the unchanged family objective break that argument. A family-specific scale also changes the mixture's direction. The existing public.6653 result confounds multiple recipe differences and does not isolate amplitude.
- **Falsifier/level2:** if changed target amplitude produces no meaningful saturation or relative main/family-gradient changes and the student endpoints remain effectively identical, deprioritize this exact amplitude explanation. If a real interaction appears, test ASR-02 × normalization with both parents linked; never add their marginal score deltas. Keep whole-pair predictions, cache identities and diagnostics. Serving remains the fixed GRU pair.

### ASR-05 — Combine own best with the full distillation endpoint

- **Parents/family/lens:** own clean reference/incumbent lineage + A0; ensemble/compression; change the search unit to the complete endpoint. Ensemble compression is established as a method, not a guarantee on this data. [Hinton et al.](https://arxiv.org/abs/1503.02531).
- **First no-fit endpoint:** for ancestry-compatible discovery predictions only, preregister `Q=.5 P+.5 D`, where `D=.5D9+.5D99` and `P` is the exact declared own-best analogue. Compare Q to P and D under the original metric. The actual public incumbent's exact components must be bound before claiming it is P. This is one fixed combination, not posthoc weight search.
- **Compression intervention:** if complementarity is plausible, replace the main teacher cache with `T_mix=.75T+.25*.8125P`; keep family targets, alpha, clipping order and final schedule unchanged. This preserves total coefficient mass.8125 while bringing own-best knowledge into **all** supervision directions. It differs from the already executed H230 history-swap, which replaced only the.30 strong contribution; do not rerun/relabel that completed arm.
- **Observable/test/cost:** no-fit Q grade first, then2S candidate/control. Positive Q with poor distilled transfer identifies a compression/optimization issue; weak Q does not prove auxiliary/representation use impossible. Report contribution to the whole endpoint, not standalone P/D rank alone.
- **Level2/reuse/serving:** ASR-02 × T_mix asks whether a longer stable phase transfers the combination. Larger GRU512/768 or recurrent/TCN teachers can enter only as independently trained, ancestry-clean component children with their own targets and budget. Distill to the pair if Q's direct serving cost exceeds limits; benchmark before proposing a direct three-or-more-model submission.

### ASR-06 — Ask family heads to learn disagreement with the strong teacher

- **Parents/family/lens:** A0 + heterogeneous family supervision; representation factoring. Classification KD studies show that teacher quality and student usefulness need not have the same ranking; this motivates a transfer test, not an assumption of gain. [Cho and Hariharan](https://arxiv.org/abs/1910.01348).
- **Intervention:** leave the main teacher and strong-family head unchanged. For the other three family targets, replace raw `F_j` by `F_j-S`, where S is the already permitted strong source. Preserve the four head slots, weight.1, original row/magnitude weights, and all final-stage settings. Do not standardize residuals in this first arm. Train-only auxiliary targets may encode useful disagreements even when the family is weak alone.
- **Observable/test/cost:**2S matched final stages; log auxiliary target RMS and actual shared-trunk gradient norms to distinguish information gain from mere loss-scale reduction. Predict less duplication between strong and auxiliary tasks, possibly greater own-best blend contribution. Existing family-cache primitives can represent transformed arrays; independently implement/hash the transform and validate actual producer/consumer fixtures. No architecture change is required.
- **Falsifier/breakpoint:** residuals that are almost zero, dominated by unstructured error, or simply shrink auxiliary gradients without better predictions oppose this formulation. If promising, a second child RMS-matches each residual using fitting-only moments, explicitly a second treatment; a schedule interaction is another separate child. Family heads are discarded for serving.

### ASR-07 — Teacher disagreement as a finite, structured dither

- **Parents/family/lens:** ASR-03 + ASR-06; stochastic target geometry; unconventional transfer from the random-library passage below. The book motivates replacing a complicated deterministic object with a controlled random surrogate; it does not establish any training improvement.
- **Intervention:** keep a fixed teacher sum `c=clip(T)`. Pick one prespecified disagreement direction `d=.5(F_full+F_raw)-S`; let `a=sign(d)*min(.05*abs(d), 2-abs(c))`. Use teacher `c+s_e a`, with a deterministic Rademacher sign per complete sequence on epoch0 and its opposite on epoch1. Thus each sequence's two target versions average exactly c and remain in[-2,2]; retain the original family targets, label weights and alpha. This is training-only, statelessly keyed by source-qualified sequence ID and seed.
- **Why test it:** disagreement-aligned stochastic gradients may explore directions absent from isotropic parameter noise without changing the two-visit target mean. **Expected squared-loss gradient is unchanged at fixed parameters** under symmetric signs; the proposed benefit is optimizer-path regularization, not extra mean information or a magic better target. Recurrent dynamics and evolving parameters mean antithetic visits do not cancel actual updates.
- **Cheapest test/cost:** verify the algebra and deterministic per-sequence sign reversal on tiny fixtures, then2S candidate/control on the same complete-sequence subset. Requires new epoch-aware target transformation; current fixed cache and all-step `--grad-noise` flags are insufficient. Compare target RMS, clipping-boundary mass, gradients and complete endpoint WP.
- **Falsifier/level2:** if no useful disagreement survives the clipping margin, this pulse is not exercised. If target dither worsens teacher matching and WP, defer this exact magnitude/direction. A matched-RMS unstructured dither is a level2 control to test whether alignment mattered; it is not an A0 dependency. Serving uses ordinary deterministic student weights.
