Main T3 is the strongest locally source-supported recipe family; this source port has no new GRU quality result yet.

The canonical trainer now accepts an optional common467-input layout: the unchanged211 raw/event columns,128 sparse-code/residual columns, and128 causal-history columns. Inactive slots are zero, and warm-start input expansion adds zero projection columns while copying existing tensors. Feature/history arithmetic is FP32, computed over the complete sequence before TBPTT chunking. Existing auxiliary offsets and absent-option defaults remain intact. This adapts the CPU label-only NLL to the Main T3 distillation target; it is not a literal replay of that pilot.
