# [Experiment] Cold-label mean/logvariance NLL on full GRU

1. **Status, lineage and owner.** Local implementation and packet only; not published and not launched. Branch: `experiment/b300-nll-labels-20261022`, based on `68ff682977b822f38351aac0f621146f5f13b440`, the source child used by the prior warm NLL result. This is a NEW cold-label objective adaptation, not a faithful replication of the warm MainT3 experiment. H/E IDs and owner remain to be assigned by the coordinating campaign. No parent checkpoint, teacher, cache, or learned preprocessing artifact is used.

2. **Why it should work.** A clipped-label weighted Gaussian NLL may learn useful scale-dependent errors while retaining the same mean outputs and score-facing predictions as WMSE. The new path uses the observed clipped labels, `w = abs(clipped_label) * main_valid`, and `w * (exp(-clamp(logvar,-4,4)) * (mean-target)^2 + clamp(logvar,-4,4))`, divided by `max(sum(w), 1e-8)`. The strongest alternative is that label noise makes variance fitting distract the shared representation; the matched WMSE arm distinguishes objective value from model size and initialization.

   Existing evidence is mixed and narrow. A prior warm/teacher NLL fit completed six epochs without nonfinite updates, establishing stability only. Its first exposed F0/seed1001 paired endpoint was +0.000738 WP versus WMSE, with a component-paired 95% interval of [-0.000293, +0.001870], crossing zero. That NLL arm used a warm H256x2 parent and a 0.9 MainT3 teacher blend. It does not establish the effect of cold, labels-only NLL. The source-qualified result receipt is in the coordinating checkout at `research/campaign_2026-10-19/full_gru_tweaks_r1`; it is not vendored here.

3. **Compute advantage.** The test changes the training objective without introducing teacher generation or cache preparation. It uses a three-epoch fixed endpoint and four total science fits across two matched cells. Each independent fit is single-GPU in the current trainer. This source has no DDP path, so this NLL cohort cannot use all eight B300s concurrently; the coordinating operator may schedule other authorized comparisons on the remaining devices. Do not duplicate fits merely to occupy GPUs.

4. **Frozen comparison.** Two arms per cell: (A) WMSE and (B) labels-only NLL. Both set `--mean-variance-head 1`, so the final layer has the same shape and zero-initialized two-row log-variance append. Paired arms use the same fresh seed and otherwise identical recipe. Proposed cells are F0/seed1201 and F2/seed1202. Each fit uses the complete source-qualified fitting membership in its frozen outer-fold manifest, no subset, and never trains on that fold's excluded evaluation components. Use the plain 2-layer H256 GRU, linear encoder, full source sequence context, batch32, chunk2000, AdamW at LR0.001, weight decay0.01, beta2=0.999, OneCycle schedule, global gradient clip1.0, three epochs, and fixed zero-based checkpoint epoch2. Strict FP32 applies to parameters, recurrent state, activations, gradients and floating optimizer state; disable autocast and TF32 and require highest FP32 matmul precision. Both arms fit their own normalization from identical fitting membership. Labels are clipped to [-2,2]; the same scoring mask and absolute-label weights apply to both losses. No teacher, distillation cache, initializer or parent state is admitted.
