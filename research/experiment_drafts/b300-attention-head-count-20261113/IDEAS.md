## Why compare heads now

At each layer the native block learns one 768-to-2304 QKV projection and one 768-to-768 output projection in both arms. Twelve 64-dimensional heads can learn twelve temporal attention maps. Six 128-dimensional heads have six maps and twice as many coordinates per dot product. The hypothesis is that each map benefits from scoring more feature combinations jointly. The competing explanation favors more independently addressable time patterns. The experiment changes the native SDPA scale and the RoPE frequency grid together with head size. A paired result describes **this full change in head geometry**. Equal trainable shapes do not establish equal throughput or memory use. [Pinned native attention implementation](https://github.com/VladKochetov007/WunderFunder/blob/8626000a4b965763a70011a0291a891aa6535d7e/src/wnn/training/sequence_attention.py#L49)

Use fresh plain controls for both seeds. The PR91 linear arm includes an additive input adapter and cannot serve as the plain twelve-head control. Keep the fixed E4 scores for each target and both seeds, even when E3 was higher. The official validation set and a two-seed screen support a follow-up decision. Evidence for a leaderboard gain would require an independently evaluated submission. [PR91 input mechanism](https://github.com/VladKochetov007/WunderFunder/blob/190d04be8d722daca598db3efd97728c1c29b32d/research/experiment_drafts/bilinear-entmax-b300-20261112/runtime/bilinear_entmax/input_block.py)

## Other ideas in priority order

1. **Since32 × clean distillation for the GRU.** PR95 reports mean E6 improvements of +0.002904220 for since32 versus zero and +0.001845795 for KD versus a same-cache labels control. The teacher and age studies use different seed pairs. Only the since32/zero endpoints also have independent exports. A matched factorial comparison would distinguish substitution from an additive benefit. Extend the existing #92 B03 card if the receiver can support the joint loss. [Card B03](https://github.com/VladKochetov007/WunderFunder/pull/92) · [E6 readout](https://github.com/VladKochetov007/WunderFunder/pull/95#issuecomment-6850953592)
2. **Corresponding i0/i1 field pairs.** #93 C06 already proposes a shared nonlinear encoder for 52 matched feature pairs, raw bypass and a deranged-pair control. A B300 Transformer transfer could test whether field correspondence helps after the global bilinear result. Preserve the same number of pairs, parameters and operations in both arms. [Card C06](https://github.com/VladKochetov007/WunderFunder/pull/93)
3. **First-layer value residuals.** Feed part of the first attention layer's value vector to deeper layers and compare against the same trunk with layer-local values. This tests whether deeper layers retain current-row information. It needs a separate cache/streaming parity check. The published evidence concerns language models. [ResFormer paper](https://arxiv.org/abs/2410.17897)
