Prepare and check once per family at this exact source revision. Reuse that
family's artifact for its other cells; use separate acceptance paths for T/G.
GRU preparation reads all fitting raw labels and records card10 tail feasibility,
even if the first chosen card is08 or09. Failed prevalence does not block08/09;
it blocks both profiles and fits for10. No valid labels enter preparation.

```bash
WF_CELL="$WF_PACKET/configs/$WF_ID.json"
COMMON=(--runtime-root "$WF_RUNTIME" --cell "$WF_CELL" --data-root "$WF_DATA" \
  --split-manifest "$WF_SPLIT" --owner "$WF_OWNER")
"$WF_PYTHON" "$WF_PACKET/runtime/launch.py" prepare "${COMMON[@]}" \
  --output "$WF_RUNS/$WF_FAMILY/preprocessing" --timeout-seconds 14400
"$WF_PYTHON" "$WF_PACKET/runtime/launch.py" check "${COMMON[@]}" \
  --preprocessing "$WF_RUNS/$WF_FAMILY/preprocessing/preprocessing.json" \
  --output "$WF_RUNS/$WF_FAMILY/acceptance/checks.json" \
  --devices "$WF_CHECK_DEVICE" --timeout-seconds 3600
```

## Profile, review, fit

```bash
MODEL_INPUTS=(--preprocessing "$WF_RUNS/$WF_FAMILY/preprocessing/preprocessing.json" \
  --checks-receipt "$WF_RUNS/$WF_FAMILY/acceptance/checks.json")
"$WF_PYTHON" "$WF_PACKET/runtime/launch.py" profile "${COMMON[@]}" "${MODEL_INPUTS[@]}" \
  --output "$WF_RUNS/$WF_ID/profile" --devices "$WF_DEVICES" \
  --profile-updates 50 --timeout-seconds 3600
```

Inspect real reload/VRAM/RAM/disk evidence. The following ceilings are examples,
not measurements. Replace them with the actual allocation; do not chain approval
blindly to the profile. Card08's profile must include scheduled noisy branches.
For card09 treatment inspect the signed `objective_terms.total_loss` as well as
the primary-only compatibility field `losses.total`; negative NLL is valid.

```bash
"$WF_PYTHON" "$WF_PACKET/runtime/approve_profile.py" \
  --runtime-root "$WF_RUNTIME" --cell "$WF_CELL" \
  --profile "$WF_RUNS/$WF_ID/profile/profile_receipt.json" \
  --output "$WF_RUNS/$WF_ID/approved_profile.json" \
  --reviewer "$WF_OWNER" --note "Reviewed real profile, reload, family precision and allocation" \
  --max-host-ram-gib 160 --max-vram-gib-per-rank 220 --approve
"$WF_PYTHON" "$WF_PACKET/runtime/launch.py" fit "${COMMON[@]}" "${MODEL_INPUTS[@]}" \
  --profile-receipt "$WF_RUNS/$WF_ID/approved_profile.json" \
  --output "$WF_RUNS/$WF_ID/fit" --devices "$WF_DEVICES" --timeout-seconds 28800
```

Eight hours is an attempt bound, not an ETA. Use the same physical devices/runtime
as the profile and within each matched pair. Preserve all epoch snapshots and
canonical `training_state.pt`. Resume only after diagnosis, at the original source,
with `--resume "$WF_RUNS/$WF_ID/fit/training_state.pt"`; no automatic retry loop.
