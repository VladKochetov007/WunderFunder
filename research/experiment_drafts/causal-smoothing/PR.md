# [Experiment] causal-smoothing: paired GRU fits with causal EWMA inputs

1. **Status, lineage and owner.** Implementation prepared for [draft PR #9](https://github.com/VladKochetov007/WunderFunder/pull/9); runtime unverified and no fits admitted. This tests an input representation in a scratch GRU student, with possible later teacher use. IDs: `H-DRAFT-CAUSAL-SMOOTHING-20261017`, `E-DRAFT-CAUSAL-SMOOTHING-20261017-R1`. Existing helper source is integrated into the canonical modular trainer; no separate trainer is copied. The receiving researcher owns hardware/data binding, target-host checks, profile and complete result collection. Original proposal and source history remain in Git.

2. **Why it should work.** A fixed causal summary may make persistent state easier for a finite GRU to learn, while the residual and raw bypass retain jumps. Candidate suffix: `[EWMA32(raw), raw-EWMA32(raw)]`; control suffix: `[raw, zeros112]`. Both retain raw112 and the existing event features, and add224 channels. The model shape, parameter count and initialization scheme match. This controls allocated capacity, not effective feature rank or optimization conditioning: improvement would support this representation, not uniquely prove denoising. Half-life32 is one predeclared event-row scale, not seconds or a value optimized on outer folds. The [NIST recurrence](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc324.htm) grounds the EWMA definition, not a predictive-gain claim; we initialize at the first observed row instead of a historical process mean.

3. **Compute advantage.** One GPU per independent small GRU fit; additional GPUs reduce the time to complete paired cells. The scientific purchase is full-data12-epoch training and variation across seeds/folds. Larger GRUs, multiple smoothing scales, Transformer teachers and distillation are separate experiments after this comparison. There is no measured B300 speed, scaling law or LB prediction. A new feature path must justify its preprocessing, training and eventual serving cost.

4. **Frozen comparison.** Two arms: `raw-plus-control` and `raw-plus-causal-ewma`. GRU H256×2, linear encoder, dropout0, two targets, scratch initialization, labels-only WMSE, no teacher/initializer/propensity. FP32 model/input/state/gradient/optimizer; autocast/scaler/TF32 disabled, matmul precision highest. Same full eligible source-qualified fit membership, sampler policy,12 epochs, batch8,2000-row update/detach chunks. AdamW LR.001, betas(.9,.999), weight decay.01 on all trainable parameters (canonical optimizer, including biases), preclip norm1. WSD warmup2%, stable region, last20% square-root cooldown to.1×LR. Fixed checkpoint zero-based epoch11, with outer evaluation disabled during fit. Existing fitting normalization uses two fit-loader batches and every seventh row; selected rows match for each pair, while transformed-channel moments naturally differ. Sequence features are constructed before TBPTT slicing and reset at sequence boundaries. No partial fitting subset, early stopping, seed winner selection or post-result tuning. Native loader drop-tail behavior is retained and recorded, not represented as a new subset. Checkpoints retain training state for diagnosis; this packet restarts failed attempts under a new identifier, without claiming exact midstream resume.

5. **Thirty paired runs.** F0/F1 seeds1001–1008; F2/F3 seeds1001–1007.30 cells per arm,60 fits total. Every cell uses its existing `research/campaign_2026-09-29/artifacts/splits/foldN.json`; the trainer verifies source-qualified membership. No fitted ancestors cross folds. An engineering profile is excluded from quality results. All existing folds are exposed; seeds are crossed identities, not30 independent datasets.

6. **Validation and significance.** Unchanged official `global_wp_clip2_v1`, ±2 clipping and original clipped-label magnitude weights on the exact scored mask. Export the fixed endpoint on all outer evaluation groups. Primary contrast is candidate minus control; `D = (1/4) Σ_f mean_s(delta_f,s)`, computed from separate per-fit scores. Primary null `D <= 0`, one contrast, no multiplicity adjustment needed for this single frozen family. Use the [workflow's crossed-seed and component procedures](https://github.com/VladKochetov007/WunderFunder/blob/experiment/causal-smoothing/research/unified/methods/EXPERIMENT_DRAFT_WORKFLOW_20261017_R1.md),10000 resamples, RNG17017. Report both marginal intervals and fold means; do not substitute seed-averaged predictions or row bootstrap. The approximate intervals condition on the four exposed folds and fixed data.30 cells do not guarantee power. Per-cell scoring is implemented; final paired uncertainty analysis remains a separate post-fit step and is not implied by a successful cell.

7. **Leakage and coverage.** EWMA uses current/past supplied inputs only; initialization uses the first observed row, with no future labels, centered windows or whole-sequence fitted scaling. Normalizers see only fitting membership. Target-host checks must cover prefix invariance, reset, whole-sequence/chunk agreement and checkpoint prediction reconstruction. Duplicate/component protection reuses frozen split validation. Report source/fold, target and sequence-age/target-magnitude sensitivity after fitting; anonymous clocks limit claims about future market regimes. Equal input width alone does not establish parity or representative validation.

8. **Decision-changing result.** Predeclare `D >= +0.0005` WP as the allocation target: this is the chosen minimum gain to justify maintaining an additional input path and testing downstream transfer, not a measured effect or universal statistical cutoff. Promote for downstream evaluation when the effect is useful and fold/seed behavior is credible; distinguish that decision from a formal positive-interval claim. Positive but imprecise, heterogeneous or smaller complementary results may justify a specifically bounded follow-up. A negative result constrains this half-life/model/normalization recipe. A CI crossing zero does not close the mechanism. Include time/memory cost and all failed/excluded cells; do not add local deltas to public scores.
