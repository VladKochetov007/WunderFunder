# Selecting a cheap field-age screen

Status: frozen scientific proposal; runtime admission and quality results pending. Hypothesis `H-AGE-READOUT-20261023-R1`, experiment `E-AGE-READOUT-20261023-R1`.

The user asks for faster local/Kaggle adaptations of B300 research and new best submissions. The [contract](CONTRACT_R1.json) reserves 7,200 inclusive local worker seconds from the existing strong-parent stage. The 30-hour ceiling and 12-hour production reserve stay fixed. No paid or B300 execution is authorized.

The [B300 review](../../unified/reviews/B300_PR_RUN_UPDATE_REVIEW_20261019_R1.md) contains positive partial width/depth evidence, negative broad geometry results, and no scored field-age pairs. We choose field ages in a small residual readout to test this unresolved representation without fitting another recurrent trunk. This tests the representation's conditional value on frozen parents, not a faithful replication of an unrun B300 GRU experiment.

The independent [first proposals](REFRAME_PROPOSALS_R1.md) recommended H640 scaling, segment memory and a signed-log basis. H640 requires more recurrent training and export; the proposed exact reuse of the i1 B control also needs correction because that control has 367 input slots, whereas the proposal names 211. We defer width for cost and comparison repair, not because it has failed. Segment memory needs a larger causal serving implementation. Broad geometry's prior negative lowers the signed-log basis's priority without disproving that distinct transform.

The [frozen recipe](recipe.json) has six new heads: A (112 zero age slots), G (seven group ages repeated over 112 slots), F (112 field ages), each on F0/1001 and F1/1002. Every head has the same 323→64→2 shape, zero output initialization, fixed 0.1 residual coefficient, three epochs and checkpoint 2. Canonical cached fitting weights, sequence order and parent normalization are reused. No GRU or teacher fit is added. The fitting parent predictions are in-sample, not out of fold. Group-coordinate repetition changes effective rank and optimizer geometry, so F−G is not a pure age-resolution comparison.

[GRU-D](https://arxiv.org/abs/1606.01865) motivates observation timing as a representation; unchanged anonymous values here do not establish missingness or validate its clinical results in this task. [Transformer-XL](https://arxiv.org/abs/1901.02860) motivates cached segment context only. The first-proposal record preserves the seeded selection and 17-word passage from the user's local article on nonlinear magnitude transforms, including pool and document hashes. These are idea sources, not local quality evidence. This round used independent native agents of the same model family; no external-provider diversity result is claimed.

The [cache verification](LOCAL_CACHE_VERIFICATION_R1.json) hashes all six reused NPY files (32,009,440,768 bytes), validates headers and producer sidecars, and checks 19 producer source hashes. It completes in 57.877 guarded seconds with zero observed cooling pauses and no swaps. It does not score targets or establish semantic ancestry by itself. The independent grader must verify membership, provenance and complete prediction coverage before reading labels.

[Kaggle readiness](KAGGLE_READINESS_R1.json) finds only 1,635.575 unreserved GPU seconds. We therefore plan all six small fits on one locally profiled device and a bounded private Kaggle CPU grade of the saved predictions. Transporting about 0.93 GB of predictions and the pinned target cache avoids rebuilding or uploading 32 GB of feature caches. Local cache integrity will be an explicit local attestation, not a claimed independent Kaggle payload rehash.

All folds are exposed; two cells cannot separate seed and fold variation. The primary comparisons are F−A, F−G and every complete corrected endpoint against its unchanged parent, with both targets, four position bins and paired component intervals. A useful screen still needs actual native endpoint quality, reset, ABI, size and runtime checks before a new ZIP is selected. No public score is forecast.
