## Frozen age screen

- Six total fits: A/G/F on F0/seed1001 and F1/seed1002. A is canonical211 + 112 zeros, G is canonical211 + repeated group ages, F is canonical211 + per-field ages. Each fold shares seed initialization across all three arms.
- Base inputs use the existing parent mean/std without extra clipping. Age inputs use existing capped reset-local log ages divided by log1p(10000), fixed to [0,1]; age normalization has no fitted statistics.
- One 323→64 tanh→2 head per arm; zero-initialized output; endpoint is cached parent + 0.1 residual. Three epochs, fixed CP2, AdamW 1e−3, weight decay 0.01, clip1, batches of 8,192, canonical cached WMSE weights, strict FP32. Cache sequences are traversed in frozen order and the last batch is retained.
- The cohort builds canonical base/group-age/field-age once per complete sequence per epoch, then updates all three heads on each shared batch. It never builds a full feature tensor for all arms or reloads/re-hashes the cache once per arm.
- Bounded profile is 16 complete fit plus 8 complete evaluation sequences per fold, comparing CPU and CUDA readout backends within the 300-second profile/engineering cap. The parent endpoint remains its cached strict-FP32 CPU output. Profile and full fit require separate root admission receipts. Six full fits plus independent grading must fit the frozen 7,200-second inclusive reservation; no projection is claimed until the profile receipt exists.
- The independent grader uses Kaggle CPU against six immutable candidate prediction arrays and two matched parents. It checks complete ordered coverage and all artifacts before opening the target cache. No Kaggle GPU or paid provider is used.
- The two screening folds use different inherited parents (F0 clean TL3 and F1 oldZ4 H230), so the screen is conditional on two different bases as well as fold/seed. The checkpoints and predictions are research artifacts, not a submission. A future complete endpoint must run the chosen TL3 parent, reproduce canonical raw+event normalization, maintain sequence-reset age state, apply the 64-unit residual and produce the official metric. It must be packaged through the repository native serving path and measured for native runtime, size and quality. The six cached-parent grades do not measure that serving cost or establish production transfer.
