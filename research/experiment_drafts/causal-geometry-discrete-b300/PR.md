2. **Why it should work.** Sampled raw EDA shows arcs and near-arcs in some per-sequence mean/variance summaries, with exact levels and long dwell runs in selected channels. Bounded or discrete-support mixtures can generate arc-like moment relationships, but this is not evidence for a universal circle, periodicity, market regime or physical meaning. The proposed 60 channels give a recurrent model explicit causal moment, arc-residual, anchor occupancy, current-level identity, row-occupancy, event-share and dwell summaries while retaining the raw/event input. The strongest alternative is that extra channels perturb optimization or parameterization and apparent changes are seed/slice noise. The four equal-width masks keep input rank and parameter count fixed while isolating the 20-channel continuous block, 40-channel discrete block and their interaction.

3. **Compute advantage.** Eight B300s can train eight independent small GRUs concurrently; each card handles one arm and one fold/seed cell. There is no DDP for these fits. The frozen matrix entails 120 fits and 5,371,320 planned optimizer updates. An eight-card H512×1 profile measures actual per-card update timing, finite gradients, CPU RSS and CUDA allocated/reserved memory before any matrix fit; no B300 wall time is guessed. A positive block or interaction would justify separately measured scale/context work and teacher/student follow-up. Larger GRU teacher scaling, warm continuation, teacher-only/student-only/both-feature factorials and geometry-feature distillation are future paths. The canonical trainer supports feature and GRU size flags; this packet does not implement the teacher cache/factorial runner. For a warm test, require a matching fold-clean parent for each of the30 fold/seed identities; a single F0 parent must never initialize other folds. Larger teachers may use torchrun/DDP only if their own measured profile justifies it.

4. **Frozen comparison.** Four fresh-from-scratch GRU H512×1 arms share identical data membership, 271-wide model input, seed-bound initialization and sequence order. All use train+valid under the frozen CampaignSplit, fitting-only geometry priors, 3 epochs, fixed epoch2, batch8 sequences, 2000-row chunks, wmse, AdamW, OneCycle, LR0.001, weight decay0.01, gradient clip1, deterministic mode, and no evaluation during fit. The official endpoint is produced afterward by feature-only prediction on that manifest's fixed held-out groups and unchanged global_wp_clip2_v1 grading. Expected updates per fit from the frozen R4 plan are F0 44,760, F1 44,790, F2 44,850 and F3 44,640; compare actual profile and terminal histories to these before interpreting. Neural inputs, parameters, activations, recurrent state, loss, gradients and optimizer state are FP32, with autocast, GradScaler and TF32 disabled and float32 matmul precision set to highest. The causal geometry statistics/counts are accumulated in FP64 and the 60 final channels are cast to FP32; the official metric retains its canonical FP64-centered accumulation. All arms compute the same feature transform and fitting prior; only indexed visibility masks differ. Reset the feature state for every sequence and preserve the model's usual hidden-state reset.

5. **Thirty paired runs.** Every arm receives all30 identities; matrix.json lists every pair and every GPU-slot assignment for all15 eight-fit waves. Pair index i maps to fold i mod4 and seed 1001+floor(i/4): F0 and F1 each use seeds1001–1008, F2 and F3 use seeds1001–1007. Thus there are8/8/7/7 cells per fold and30 per arm. Each wave uses consecutive pair indices 2w and2w+1; GPU slots0–3 run baseline/moments/dictionary/combined for pair A, and slots4–7 run those arms for pair B. Baseline zeros indices0–59; moments keeps0–19 and zeros20–59; dictionary keeps20–59 and zeros0–19; combined keeps0–59. These are true indexed masks, not a suffix-width approximation. The initial eight-card profile is a separate engineering activity and does not count toward the120 fits. All folds are exposed or potentially exposed. No teacher or initializer is used in this fresh matrix.

6. **Validation and significance.** Score each fixed endpoint with global_wp_clip2_v1 using the official ±2 prediction/label clipping, fixed scored-row mask and original clipped-label magnitude weights. Primary statistic is the equal-weight mean of four fold-level paired deltas for combined minus baseline. The preregistered secondary family is moments minus baseline, dictionary minus baseline, and the interaction combined − moments − dictionary + baseline. Report two-sided approximate centered seed-bootstrap p-values and Holm adjustment across these four contrasts. For each 10,000-draw seed bootstrap, sample the eight seed identities with replacement and reuse the same multiplicities across folds; renormalize over available seeds within each fold, redraw if any fold has zero sampled weight. Record the fixed RNG seed 20261018. Report the percentile95% interval, all four fold means/ranges and all paired seed deltas. Separately hold fits fixed and resample source-qualified evaluation components within each fold, using the same component multiplicities for every arm and seed in that fold; report this conditional component interval separately. Eight seed identities are few and all folds are exposed; intervals and p-values are approximate and do not support a fresh-regime claim. A zero-crossing interval alone does not reject the mechanism.

7. **Leakage and coverage.** The four committed split manifests bind source-qualified train/valid groups and held-out components. The model fits only each manifest's fitting groups; outer evaluation is invoked only after the fixed checkpoint is saved. Arc coefficients, anchor atoms and the top-three exact-level vocabularies are fit from fitting rows for each cell, with a deterministic tie break. Feature values are prefix-causal, include no future label or full-sequence statistic, and reset at each sequence boundary. All four validation folds have been seen or may have been seen in earlier geometry work; they remain exposed development evidence. Anonymous source encodings and sparse visual sampling do not establish physical semantics or future-regime coverage. Root’s separate local F0/seed3 warm probe is outside the matrix and cannot count as an independent cell or initialize another fold. Native build/ABI and synthetic 20,000-row event/geometry/prediction/reset parity passed after a retained first failure and correction; actual-weight parity, full competition runtime and package checks remain pending.

8. **Decision-changing result.** A+0.001 absolute WP change is a useful effect reference, not a kill threshold. A positive combined-minus-baseline result with compatible fold behavior and separate component uncertainty would keep the feature family active and motivate a distinct fold-clean warm/teacher/student follow-up. A positive dictionary block or interaction can justify target/mixture work even if the fresh combined model is not best standalone. A negative/noisy fresh H512 result narrows this exact recipe; it does not rule out a strong-model continuation, teacher target, feature-only student, distillation or fixed mixture. Preserve all negative and inconclusive cells. Do not add a local delta to public score; public transfer is unknown until actually observed.
