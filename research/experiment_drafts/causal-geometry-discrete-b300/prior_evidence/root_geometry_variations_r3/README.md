# Root local geometry block fits and correction-scale screen (R3)

Status: independent full-F0 grading completed for two root-owned local frozen-parent block fits and four inference-only scale aliases; one selected alias also passed an exact q16x package replay and Python 3.11 smoke. These are exploratory exposed-F0 evidence, not B300 matrix cells.

## Scope and lineage

Experiment IDs: `E-GEOMETRY-VARIATIONS-20261018-R3` (two block fits) and `E-GEOMETRY-CORRECTION-SCALE-20261018-R3S` (inference-only alpha grid). The two new fits use the same exposed F0/seed3 warm parent `warm_mechanism_f0_s3_c_r3@ep1`, 4,096 sampled sequences, FP32, fresh AdamW, OneCycle at LR 3e-5, zero weight decay, and fixed epoch 0. The moments-only arm exposes feature offsets 0–19 and masks 20–59; dictionary-only does the reverse. Both used the adapter-only path. The independent grade reports matched initializer, fitting membership, normalization, causal prior, split, sampler order and update counts across R2 and the two R3 fits: 5,120 attempted and completed updates, 512 batches, and zero AMP-skipped updates. The mask and gradient-statistic fields are intentional differences. Weight-proof receipts show the intended masked input block is zero and the listed non-adapter model tensors are preserved.

This “R3” is distinct from the earlier small H128×2, three-seed `summary_r3.json` linked in the parent evidence index. The present R3 is one later F0/seed3 frozen-parent follow-up. It adds two fits, not independent seed replications, and does not replace or rewrite the earlier evidence.
