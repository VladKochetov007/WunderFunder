# [Experiment] Causal teacher hints beyond two-output distillation

The original CP30 text is frozen in [PR_CP30_FROZEN.md](https://github.com/VladKochetov007/WunderFunder/blob/experiment/teacher-representation-hints/research/experiment_drafts/teacher-representation-hints/PR_CP30_FROZEN.md), and the historical [recipe.json](https://github.com/VladKochetov007/WunderFunder/blob/experiment/teacher-representation-hints/research/experiment_drafts/teacher-representation-hints/recipe.json) is unchanged. Root maintains this design; the receiving operator claims cells and binds data/artifacts. No result is claimed.

2. **Why it should work.** Two-output KD can omit useful temporal structure in a strong teacher's hidden state. Add a 64-dimensional fit-time representation target while keeping output KD fixed. Compare aligned teacher/student rows against output-only KD and against a component-permuted hint target. H−O tests whether hints add value; H−P tests whether alignment matters beyond adding the same auxiliary loss. Generic regularization or donor-distribution effects remain plausible alternatives.

3. **Compute advantage.** The amendment spends four new GRU256 fits across two cells and reuses the two exact same-fold PR28 teacher/cache pairs and output-KD controls. No teacher fit is added. The value sought is stronger student learning per added student fit; cache I/O is a known cost (64 hint values per row versus two output values). This screen has not measured throughput, memory, score gain or serving feasibility.

4. **Frozen comparison.** New arms H and P use raw112 inputs, canonical GRU256×2, fitting-only normalization over the first 32 fitting sequences, full 20,000-row sequence traversal, 256-row TBPTT chunks, reset between sequences, three fixed epochs, batch size one per rank and four-chunk accumulation. Strict FP32 is used for parameters, states, activations, gradients and AdamW; autocast, GradScaler, TF32 and quantization are off. AdamW uses LR 3e-4, weight decay 0.01, 5% warmup and gradient clipping at 1.0. The shared same-fold T768×24 teacher/cache uses 512-row sliding KV per layer and a frozen seed-1729 projection of its per-row-normalized final hidden state. The student projection is learned and omitted at inference. The additive objective is WMSE(clipped labels) + 1.0*WMSE(clipped teacher outputs) + 0.1*MSE(hints); label and KD terms use abs(clipped label) weights. The mask is is_scored AND row_index >= 99; all rows still update causal state. The endpoint is the configured final epoch. This is not the historical alpha=0.9 mixture.

5. **Bounded four-fit panel.** This is an explicitly bounded screen, not CP30: cells F0/student seed 1001/teacher seed 101001 and F2/student seed 1002/teacher seed 101002. Each cell reuses one output-KD control and one same-fold teacher/cache, then adds one H and one P fit. That is four new fits total, two reused controls and two reused teacher/cache pairs. The historical 30-cell-per-arm design remains preserved but is not being run by this amendment. Two cells do not support confirmatory across-seed or unseen-fold claims.

6. **Validation and significance.** Grade each endpoint with the pinned runtime's canonical global_wp_clip2_v1 pooled scorer on the identical held-out scored rows, excluding warmup rows 0–98. Report H−O and H−P for each fold, each target, and pooled official score; retain the source-qualified component breakdown. With one seed per fold, component resampling over fixed predictions is sensitivity analysis only. Do not present it as seed uncertainty or a calibrated confidence interval. Both folds are exposed.

7. **Leakage and coverage.** Reuse only PR28 teachers/caches whose complete ancestry has the same fold hash and exact source-qualified fitting membership, excluding evaluation components. Teacher targets on fitting components are in-sample by design. The P arm rotates fitting-component donors while keeping row position and aligned output-KD targets. Teacher outputs and hints are training-only; no teacher signal enters student inference. Preserve complete causal rows, warmup, reset and source-qualified membership.

8. **Decision-changing result.** H should improve over O to support added hint value, and H−P helps distinguish aligned representation learning from an unaligned auxiliary loss. A descriptive +0.001 WP signal is useful for deciding whether to follow up, not a pass/fail boundary. Smaller or mixed effects and an interval crossing zero do not automatically reject the mechanism; they can motivate a targeted continuation. Inspect both targets, both folds, actual compute and the separate CPU-serving gate. A result that beats P but not O does not establish benefit beyond output KD.
