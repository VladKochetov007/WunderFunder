No new model implementation or measured gain. [Recipe](https://github.com/VladKochetov007/WunderFunder/blob/experiment/teacher-representation-hints/research/experiment_drafts/teacher-representation-hints/recipe.json) has `launch_ready=false`. The canonical note deferred hidden alignment. PR #3 changes teacher family; this fixes teacher/student/output KD and changes only fitting-time representation supervision. It is not relation-KD or assistant KD.

2. **Why it should work.** Two regression outputs may hide useful temporal features. Compare aligned hints to output-only KD and a marginally matched but misaligned hint control. If H improves only relative to harmful P, there is no positive aligned-hint result. Full equations, architecture and falsifiers are in [Section24](https://github.com/VladKochetov007/WunderFunder/blob/research-team/research/unified/ideas/CAUSAL_AR_TRANSFORMER_GRU_DISTILLATION_B300_20261017_R1.md). Papers motivate the mechanism in other tasks; no competition gain is imported.

3. **Compute advantage.** 90 student fits,30 L teachers/caches unless exact grid sources are reusable. A64-channel FP32 hint is32times the two-output cache payload; measure I/O cost. Additional compute buys stronger clean teachers and complete matched student fits; its value is the downstream student's score/cost, not teacher size or GPU utilization. Teacher scale and student budget extensions are separately frozen follow-ups.

4. **Frozen comparison.** Proposed arms: `O`, `H`, `P`. The recipe fully specifies the comparison intent, not a launch freeze: source/data/cache/environment/strong-GRU bindings remain null. Common student: cold weights, all allowed fitting components,8epochs/terminal epoch7,32sequence slots,500rowcores and one update/core, AdamW1e-3, betas(.9,.999), eps1e-8, matrixdecay.01/no bias-normdecay, normclip1,2%linearwarmup(min100 capped belowtotal)/cosine to.1LR. Fit-only112-feature normalization; no extra features, propensity or EMA. Label loss is per-target normalized WMSE to clipped labels with weight.05+abs(clipped label); KD uses raw teacher outputs, same label weights/masks and alpha.9. All causal input rows update state; padding/warmup excluded only from loss. Strict FP32 throughout, autocast/GradScaler/TF32 off. No quantization. The fixed L207 teacher recipe uses12epochs, exact terminal checkpoint, fixed4096 anchored context and common1e-4 LR; same teacher source shared within a cell. Teacher context differs from student context by design.

5. **Thirty paired runs.** F0/F1 seeds1001–1008, F2/F3 seeds1001–1007;30 per arm, **90 student fits**. Teacher seed=s+100000, student seed=s. All ancestors exclude each outer fold across BOTH supplied sources and duplicate components. Shared teachers are not independent replicates. Identical historical cells may be reused only with exact recipe/source/cache/member/seed identity; none are claimed here.

6. **Validation and significance.** Official pooled `global_wp_clip2_v1` over identical scored rows, per fitted endpoint. Primary contrasts: H - O; H - P. Estimand is equal-quarter average of each fold's mean paired WP delta. Workflow seed/component bootstrap:10000 draws,RNG19019; shared seed multiplicities across folds, whole-component paired evaluation resampling. Report95% marginal and99.6875% Bonferroni-adjusted marginal intervals for the predeclared16contrast portfolio across these3packets. These approximate intervals have limited tail resolution/eight seed IDs and no guarantee of calibrated coverage. Separate teacher/fitting variation, component uncertainty, exposed-fold sensitivity and unknown public transfer. No row-IID p-values or automatic significance from30cells.

7. **Leakage and coverage.** Freeze source-qualified data, component, inner-selection, normalization, teacher/initializer/propensity ancestry and cache hashes. Outer-fitting teacher targets are in-sample by design; nested crossfit is separate. No true past competition labels, teacher outputs or hints are student inference inputs. Preserve warmup, full causal rows, state resets, row alignment and prefix invariance. Export teacher caches using their own anchored semantics, not the compact student's rolling cache. Report source/target/position/activity slices; anonymous clocks and exposed folds limit new-regime claims.

8. **Decision-changing result.** Proposed useful student gain is+0.0005WP for direct endpoint-versus-control contrasts only. For interactions, either sign can be useful: abs(interaction)≥0.0005 motivates a mechanism follow-up when endpoint results support it; an interaction alone never promotes a student. This threshold reflects a material allocation choice, not a power estimate. A KD endpoint must also improve its architecture-matched label-only control; winning a teacher/architecture contrast while losing to labels is not a promotion. For hints, use the source-identical label-only baseline from the transfer grid as a secondary endpoint floor; a new formal hint-versus-label claim requires its own frozen contrast. Inspect both targets/folds, actual total compute and downstream CPU feasibility before promotion. Positive but uncertain results justify a targeted bounded continuation; crossing0 does not close the mechanism. Negative transfer narrows this recipe. For hints, H−O must improve, not merely H−P. For streaming, a better student that cannot serve is teacher/assistant evidence only.
