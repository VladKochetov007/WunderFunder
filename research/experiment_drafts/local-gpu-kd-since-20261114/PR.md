# Cold Muon distillation: checked submissions and strict-FP32 follow-up

The legacy Muon factory left Newton–Schulz in BF16 even when model kernels used FP32. This PR forwards the requested precision through both ordinary factory branches. Existing measured scores and ZIP checks remain valid observations with corrected precision labels. Optimizer-switch conversion is outside this fix and is not used by this panel.

1. **Status and owner.** Codex completed the original 18 fits and three checked submission ZIPs. The user has resumed quality research. Strict KD90 s3 now finishes at fixed ep3 with full-valid WP **0.6915443853**; its matched pure-teacher comparison is running. Six private Kaggle fits are queued, with no cloud results yet.
2. **Mechanisms.** Compare alpha .5/.9 teacher mixing, unchanged-label future-teacher boot8 targets, and a local alpha1 versus .9 pair. A separate zero-fit diagnostic replaces TL3C's .34 fbc1k slot with KD90, preserving tiedlead weights .33/.33.
3. **Prior evidence.** Legacy KD50 s3/s4 score .690466/.690482; their fixed equal pair scores .691423. KD90 s3 scores .691442. The since32×KD interaction reverses sign across seeds; no replicated interaction claim. Component resampling supports a teacher/student blend's contribution but does not establish public transfer.
4. **Compute.** Six strict cloud fits: alpha .5/.9/boot8 × seeds3/4, sharing exact controls. Two reserved local fits: alpha .9/1 seed3. Up to two final-data refits are conditional. One interrupted legacy attempt remains charged. Caps remain eight local GPU-hours and eight cloud device-hours; no paid compute.
5. **Recipe and source.** Fixed four epochs, H256×2 GRU, WMSE, since32, matching teacher and split. Exact executed strict source is [48776fba8](https://github.com/VladKochetov007/WunderFunder/commit/48776fba8af26b16b7e6813def7ccf571f56c1ac); this branch mirrors its factory correction. No optimizer switching, autocast or TF32.
6. **Validation.** Unchanged global_wp_clip2_v1 on 1,873 official-valid sequences; all are previously exposed. Distinct seeds measure fitting variation, not unseen-fold significance. Independent metric-reference agreement is required for complete endpoints; component intervals do not include seed or transfer uncertainty.

No leaderboard coefficient fitting.
