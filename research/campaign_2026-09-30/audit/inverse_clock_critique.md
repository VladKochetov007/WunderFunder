# Shared inverse-clock proposal: execution conditions

Conditionally approve one bounded feature-only CPU falsifier after the following
specification changes. It can identify a useful shared additive coordinate
under explicit assumptions; physical elapsed time or units remain unidentified.
No target/auxiliary fit follows automatically. The same 64/32 component panel
is exploratory, and a fresh component reproduction remains required.

The principal failure mode is observed-increment collapse. Anchoring f5(.5)=1
can put almost all necessary slope in a knot interval rarely seen by fitting
rows, while both maps are almost flat on observed intervals. A slope floor0.01
prevents literal constants but does not rule out this effective degeneration.
Before fitting, measure support for every knot interval and jointly occupied
age-offset cells. Persist these counts; classify unsupported intervals explicitly.
The scale anchor must lie on observed support or use a positive scale constraint
on observed fitting increments. If the latter is used, replace the arbitrary
.5 anchor rather than silently imposing an incompatible second scale. Bound
both maps' total range under that declared scale and report feasibility.

Freeze a noncollapse rule using observed fit support, not held-out labels or
post-fit thresholds. At minimum report RMS, median and quantiles of reconstructed
positive increments, active-row fraction, concentration of squared increment mass
by knot/cell/component, and effective occupied bins. A map carried by rare bins
or almost-zero increments cannot pass even with low absolute discrepancy. Do not
normalize by an arbitrary epsilon that turns two collapsed clocks into agreement.

Use a symmetric relative error
`sqrt(mean((d5-d6)^2) / mean((d5^2+d6^2)/2))` on exactly the same jointly quiet
rows for candidate and scalar-aligned CDF/log-survival controls. Fit each control's
positive scalar only on TRAIN, then hold it fixed. Report absolute increments
and alignment error as well as the normalized result. Freeze held-out age bins
from fitting values, including support/unknown and clipped endpoints. Show
per-component errors and two-dimensional offset-cell errors; marginal bins
alone can conceal two clocks that are nearly always the same age.

Specify which trade block defines quiet (dp,dv or both, exact columns), whether
the quote quiet condition uses full raw code or the independently reproduced
a6 endpoint, and how zero/negative increments, all-zero differences, sequence
origins and upper/lower endpoint clipping are handled. Current/past code and
trade equality conservatively selects observed quiet transitions but cannot
prove absence of an unrepresented physical reset. The three nonorigin a6 endpoint
exceptions must be excluded/graded separately rather than called quiet age growth.
For `-log(1-u)`, freeze upper-bound clipping and unknown treatment before reading
the test panel; infinity must not be accepted as a valid increment.

The QP claim is valid only when interpolation basis, discrepancy weights,
curvature operator and knot-scale normalization are fixed. Persist the small
Gram matrix, linear constraints, objective gradient, solver convergence/feasibility
residuals and deterministic initialization. Explain whether curvature penalizes
height differences or slope changes on unequal knot spacing. Stop at200 iterations
or the 60-second process limit, retaining an inconclusive result on failure;
do not retry a better hyperparameter or silently change the penalty.

Publication-row age has identical joint quiet increments1 by construction.
It is therefore a degeneracy/identification control, not a competing physical
clock. Better cross-clock agreement than CDF/log-survival supports a latent
coordinate assumption only if the support and noncollapse gates pass. A useful
dimensionless coordinate needs an independently frozen causal task after that
gate. Observing the current increments of both clocks and predicting one from
the other on the same row is an algebraic reconstruction, not a forecast. A real
forecast must use information at t to predict an increment at t+1 or later,
with boundaries and row-age/CDF baselines frozen, without targets or masks.

If these changes are incorporated before execution, the one-thread/2GiB/60-second
TRAIN-only experiment is justified. Keep all failed bins and source classes;
no model score, physical units, preprocessing identity or public transfer claim
can be selected by agreement alone. The frozen competition grader stays intact.
