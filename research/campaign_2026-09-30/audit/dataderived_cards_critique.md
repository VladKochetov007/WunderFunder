## D1: active capacity is improved, positional information is restricted

The specified 128x96 Walsh matrix has uncentered Gram128I. It therefore fixes the earlier padded/low-rank position projection problem, provided actual TRAIN written-key inputs and gradients exercise the columns. Column0 is a valid constant intercept; its zero centered variance must not be confused with rank failure. Freeze rank/eigenvalue tolerances, exact selected rows, gradient checks and source hash before any score. Aggregate TRAIN rank96 does not establish adequate position exposure in every sequence; report write-count and per-class coverage, without adding a post-score threshold. The matrix has only128 distinct positions: query rows t and t+128 are identical, and keys with event ordinal n and n+128 are identical. On20k rows this is severe aliasing. C>P supports content over this periodic-position comparator, not over unrestricted temporal addressing. Disclose alias multiplicities, cycle boundaries and rank on written keys; positional full rank is insufficient evidence of comparable temporal information.

Freeze counter timing: whether a write uses ordinal before or after increment, initial observation versus genuine endpoint write, and whether row counters start at0. The same initial value injection, S/Z initialization, denominator guard and dtype must apply in C/P/R. Read-before-write versus read-after-write changes whether current value dominates retrieval. All arms must use the same causal choice. Equality must use source float32 a6 before feature normalization/autocast. Nonorigin quiet endpoints remain observed writes with unknown decoded movement; decoder unknowns never become zero. Map selection and target supervision stay within each fold's fitting TRAIN components.

The proposed recurrence decays by the arm's own write gate. Thus C/R changes both what is written and how quickly memory decays in publication-row time; raw-code refreshes may prematurely erase memory even when decoded movement is zero. Describe this as the joint endpoint write/decay policy. It cannot isolate content filtering alone. Three arms establish two separate contrasts, C/P and C/R; they do not identify an interaction between addressing and write clock. No fourth arm is requested here. Freeze this narrower claim before fitting.

Equal learned tensor shapes and every-row gated arithmetic are appropriate. Input rank alone does not demonstrate effective parameter use: independently check q/k/value/readout gradients and nonempty normalization across heads. Test native rounding/code lookup collision resolution, empty history,128-period boundaries, nonzero carried state, full/chunk/step outputs, input/state/parameter gradients, future perturbations, resets and long constant/endogenous-gate sequences. Denominator flooring and unconstrained key/value norms can still amplify sparse-memory transients; define bounds before synthetic tests. Exact scan must reproduce the gate-dependent affine recurrence; approximate detached memory is a different architecture.

The fixed-projection CPU probe is a limited information test; it cannot establish learned attention quality. Complete timelines, component-heldout TRAIN readouts and equal ridge/training data are required. A60s timeout is inconclusive. GPU estimates0.30h/arm are18min each, close to an existing parent run; measured successful optimizer updates, AMP skips, EMA steps, data order and final checkpoint must match across all arms. If one arm hits its cap first, do not compare truncated fits as the preregistered test. Report actual VRAM/train/package latency before scheduling. The shared80/20 blend is distinct from the label-only replacement-pair experiment and must never be substituted silently.

## D2: an optimization comparison with the same supervision

On known rows, `(s_current,s_proxy)` and `(s_current,s_proxy-s_current)` are invertible labels. A sufficiently unconstrained linear readout can transform between them; an invariant ridge check is a null identity, not positive or negative evidence about shared neural representation. The meaningful hypothesis is how fixed loss geometry changes shared representation. Separate per-coordinate standardization changes that geometry and relative gradient magnitudes. Freeze scales, offsets, masks, denominator and missing-coordinate treatment before fitting; report effective gradient weights and covariance/eigenvalues on interior/tail and each class. Rank2 globally can conceal a constant residual on the dominant interiors.

Static current-code inputs must be identical in both arms, fitted on each fold TRAIN only. Code-derived class is permitted supervision but never an oracle class at inference. Unknowns need an explicit bit and unchanged raw path. Main targets remain unconstrained; training future-tail labels cannot enter recurrent state. Exact Python/native lookup round4/little-endian grammar, hash collisions and unknown handling require independent parity. Full-fold table size/runtime are measured, not inferred from1k-code reports.

The card currently says two new factor losses consume the historical structural0.3 budget. It does not specify whether existing branch/class CE is retained, removed, or rescaled. This is a blocking implementation ambiguity: preserve branch/class with a frozen explicit formula, or disclose a jointly changed auxiliary family in both arms. Likewise freeze the shared128-GRU2 to96 fusion shape/activation and whether static fusion reaches main outputs. Relative to the unchanged campaign anchor, added inference lookup/fusion is a representation intervention; the equal current/proxy arm is the mechanistic comparator. This must remain separate from the smaller label-only12-bin screen.

Prior future-path/outcome/rich-head failures lower confidence. Current-code reconstruction exactness supplies no forecast guarantee and does not justify repeating a broad outcome-family fit. Complete the simpler matched label-only screen first; its result does not automatically approve D2. Same successful updates and resource caps apply. Rough local WP ranges in cards are uncalibrated engineering priors, not score expectations or public promotion evidence.
