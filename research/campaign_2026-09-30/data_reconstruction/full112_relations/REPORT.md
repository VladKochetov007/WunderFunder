# All112 feature relations and a6 event-coordinate identification

The strongest result is a feature-only current event marker: the exact float32 lower endpoint of `a6` identifies every known nonzero TRAIN-supervised price-code move and excludes every known zero move on the component-held-out panel. This distinguishes quote movement from representation-code refresh across all four classes. It is not a complete physical-price decoder or identified time unit. Independent replay is pending; no model/trainer, auxiliary cache or target relation was changed.

`preregistration.json` froze the 112-feature questions and methods before this phase read feature blocks. The 64 fit and 32 test TRAIN groups and component exclusion are inherited unchanged from `../selection.json`; all 32 test components are distinct. The panel is already inspected exploratory data. The primary full112, transformed-baseline/CDF, monotonicity and quote-endpoint probes each have their own contracts and source/output hashes. Held-out target labels, sequence IDs and masks are never read by this phase. The quote decoder reads only fit TRAIN targets to reproduce the unchanged primary interior-to-interior movement votes. Prior primary test-class records are used solely for retrospective strata. External data never fit this representation.

The historical context matters. `research/hypotheses.jsonl` H-003 proposed rank-Gauss encoding and the lower sentinel in 2026-09-15. `research/experiments.jsonl` E-091 described a6/book-age and a5/trade-age correlations on 150,000 validation rows, a7's 120 values/42% sentinel, and a2/a3 activity correlations. Its referenced scratchpad `acols.py` was not found locally in the file search. That evidence is correlation, and the wording that a physical real-time clock is already identified is stronger than its reported measurement. E-070 had earlier left the clock unknown; E-025 found weak a-feature direction information far from breaks. The new study independently measures exact plateau monotonicity, endpoint-versus-nonzero-move identity, disjoint TRAIN components and explicit unknown transitions. Age correlations, general rank-Gauss suspicion and a7 discreteness are reproductions, not novel model mechanisms.

A6's lower endpoint is `float32(norm.ppf(1e-7-float64epsilon)) = -5.199337482452393`. The official scikit-learn [preprocessing source](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/preprocessing/_data.py) defines the quantile bounds threshold as 1e-7, and the installed source matches. This exact numeric fingerprint supports a normal quantile clipping hypothesis; a shared clipping constant is insufficient to identify the transformer, fitted quantile map or original units.

The pooled price-code movement map is unchanged: fit TRAIN events whose old/new pair is interior, modal `(-Δt0,+Δt1)` with support >=3 and confidence >=.80. It takes only current/past 22-field code pairs at inference, with no supplied class. Its target identities assume the common future reference is stable over interior transitions; physical quotes are not independently recovered. A6 is graded against that accepted map on all held-out price-code events.

Known coverage is 59.79%, 85.49%, 98.67%, and 99.89% by class, 87.04% overall. The marker is exact on those 113,488 known code transitions, not proven on all 130,382 events or the full dataset. A6 has 76,825 endpoint rows in the 640,000-row panel: 76,812 price-code event rows, 10 sequence origins, and 3 nonorigin quiet rows in class 1. The origin addendum preserves earlier files and separates these explicitly. The three quiet exceptions match the earlier primary count of target changes without price-code changes retrospectively, but their physical cause remains unidentified. They should not be forced to zero movement merely because the price representation is unchanged. The unknown set cannot be labeled from the same held-out targets to boost reported coverage.

The causal input opportunity is the exact marker `a6 == -5.199337482452393` after preserving the source float32 value. Unlike the current all-price-code event flag, it distinguishes known zero code updates from known nonzero movement. A detector output, its current/past event ages and unknown handling require no targets, masks, future rows, chain IDs or external fitted state at inference. A matched model comparison must still establish value because the network already sees a6. Existing future-path auxiliary and generic age augmentation failures remain relevant; this finding does not authorize repeating them unchanged or claim public gain.

The exact monotonicity check gives an additional identification limit. Between i0 trade-block refreshes, a5 has 436,869 increases, zero decreases and 749 unchanged transitions across 437,618 quiet rows. Between i0 price-code refreshes, a6 has 501,827 increases, zero decreases and 7,759 unchanged transitions across 509,586 quiet rows. These observations are necessary for monotone elapsed-age variables and stronger than correlation. A reset is not universal at every code event: the a6 endpoint occurs only on a nonzero-move subset where known, consistent with its quote-event interpretation. Original elapsed time, units and inverse transformation remain unknown.

Other a fields reject a simple monotone elapsed-age identity under the tested six block clocks and lag0/lag1 alignments. At the best lag0 quiet clock, a0/a1/a4 have about 44–48% minority-sign changes, a2 about 18.9%, a3 about 7.5%, and a7 about 15.6%. A2/a3 can encode decaying activity measures, but their activity semantics are not identified by this result. A7 is not an exact simple publication-age/count variable under the tested controls.

The current104-field fixed ridge feature reconstruction uses at most 256 causal sample rows per fit group, TRAIN standardization and ridge .001. Adding eight log causal event ages raises held-out R2 for a2 from .068 to .476, a3 from .006 to .347, a5 from .725 to .772, a6 from .476 to .691 and a7 from .209 to .336. These are feature reconstruction scores, not target scores or an identified inverse. A7 retains 130 distinct codes across 640,000 rows, while a0–a6 are mostly continuous. A1 remains poorly explained, about .048 R2.

A separate inverse-normal-CDF monotone control fits 20 fixed causal age/count candidates per a field using TRAIN only and selects the lowest TRAIN MSE. In held-out CDF coordinates the selected controls give a6/i0-price-age R2 .661, a5/i0-trade-age .257, a2/i1-volume-age .374, a3/i1-trade-age .313, a7/i1-volume-age .307, and a1 only .007. Unknown candidate-value fractions remain explicit in `followup_results.json`. Selection is adaptive after the primary feature evidence, and this panel cannot validate a chosen representation as fresh evidence. The failure to identify a7 exactly is preserved.

A7 supplies a more specific quantile fingerprint than endpoint alone: 46/130 distinct inverse-CDF levels lie within 1e-6 of the half-step 100-quantile reference grid (denominator 198). Examples include .368686865 ≈73/198, .439393938 ≈87/198 and .540404040 ≈107/198. A0–a6 have only about .04–.08% distinct codes near that grid. These matches are consistent with tie-averaged quantile references for a discrete original variable. The remaining 84 codes do not meet the grid criterion, the 1,000-quantile grid performs worse, and no original integer count or full preprocessing algorithm is recovered. Full levels and the predeclared 198/1998/19998 controls are preserved; no target relation was fitted.

Literal dp/dv interpretation is falsified: across changed four-field blocks in both instruments, neither adjacent left nor right shift is exact once, and there are zero literal all-zero clear states. Unknown per-column transforms could still turn a physical shift/empty record into a different encoded shape. A TRAIN modal-code followup finds common transformed baselines: dp blocks share the mode `[-.9474013,.2954151,-.2169044,.9474013]`; i0 dv uses all-four `.03798835`; i1 dv all-four `.02532218`. Held-out baseline occupancy is 21.17%, 28.10%, 19.78%, and 50.11%. Transitions into/out of those modes are balanced, but only about 4.7–8.0% of changed events enter the mode. A frequent state is not independently identified as an empty trade buffer, and these are not universal transient clears. Component/class raw counts are preserved for review before assigning a physical meaning.

A single first field nearly determines the rest of an 11-field price block on supported values, but fails exact identification. TRAIN first-field maps have 53, 18, 77 and 41 ambiguous values across the four price blocks. Held-out exact supported event states are 85,005/85,053, 85,775/85,838, 42,613/42,656 and 34,114/34,127, with mapping coverage only about 56.9–71.6%. A first field alone cannot replace the full block without unknown/ambiguity treatment. Column order is not inferred depth order.

Cross-instrument equality refresh is asymmetric. I0 price/volume/trade blocks refresh 130,382/579,536/202,350 times; i1 63,238/287,268/177,072. Only 13,886 price refreshes are simultaneous between instruments. I0 price and i1 trade refresh together 22,681 times; i1 price and i0 trade 20,837. The full co-change matrix is in `results.json`. These are publication signatures that may reflect batching, coding or source refresh; no exchange-time causal direction is established.

The minimal next causal falsifier is an independently reproduced a6 endpoint event detector on a freshly frozen TRAIN component panel and a matched representation comparison against the existing raw price-code event flag. It should report unknown code transitions and the rare endpoint-with-unchanged-code cases, retain all classes, and use identical data/updates rather than selecting a new target horizon. If a common original time coordinate is needed, it requires a separate feature-only experiment: nonconstant monotone inverse maps f5/f6 should make their increments agree when both clocks are quiet, with lowerendpoint anchored to zero and an explicit nontrivial scale. Monotonicity or the quantile fingerprint alone does not establish that additive clock. No inverse-clock experiment has been launched in this phase.
