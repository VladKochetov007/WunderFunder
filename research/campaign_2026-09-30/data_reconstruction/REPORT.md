# TRAIN codebook reconstruction and tail-copula audit

The current 22-field price code supports a much cleaner supervised coordinate than the historical all-branch target inversion. A lookup trained only on interior target pairs gives exact held-out interior spreads in every class and also identifies class without an oracle class at inference. The fixed losing-offset-two law is contradicted on many class 0/1 tail rows. None of the future first-passage alternatives tested here explains that tail law completely. No model or trainer was changed, and no public-score claim follows.

`preregistration.json` fixed the primary question, all parameters and sample counts before any target read. `selection.json` froze 64 TRAIN groups for fitting and 32 TRAIN groups from distinct held-out components for testing using SHA256 metadata order. Fit excludes every test component and prior provided-decode/clock evaluation components. Only TRAIN `i0_p0..i0_p21`, `t0` and `t1` were read. No `seq_ix`, prediction mask, scoring mask, validation parquet or external data were accessed. The sample covers 640,000 held-out publication rows. Its class strata are diagnostic labels, and class-specific group counts are small in classes 0 and 1. All followups use the same already inspected panel and are adaptive exploration.

Evidence tier is B for observed supplied-data identities and C for interpretation as physical quotes or public transfer. The immutable primary and followup contracts, their hashes, source hashes, and exact group membership are preserved. Independent reproduction is pending.

The primary spread table uses only both-nonpositive target pairs. There the implied local spread is `-(t0+t1)` in integer lattice units. It never fits spread from outside-branch losing targets. A code mode is accepted with support at least 3 and confidence at least .95. The single pooled followup table accepts `(class,spread)` pairs under the same gates; its inference input is solely the current rounded float32 code. Target-derived classes and spreads are legal offline TRAIN supervision here, while test classes are used only for grading.

For each mapped outside-branch pair define `winner=max(t0,t1)>0` and `k=-min(t0,t1)-current_spread`. The offset-two copula assumes `k=2`. Observed alternatives are exclusively even offsets, extending to 22 in class 0. `k=2*winner`, `k=winner`, and rounded-even winner controls fail. The same `(current spread,winner)` can have several offsets: for spread 1/winner 2, class 0 has both offset 2 and 4; for spread 1/winner 4, it has offsets 2, 4 and 8. Thus local spread and one common winning reference do not identify the pair under the declared fixed-offset law.

`src/wnn/outcomes.py:invert` derives its outside spread as `-loser-2`. On these rows that equals `current_spread+(k-2)`, so the existing auxiliary's quantity includes future tail risk in classes 0 and 1. That is a naming/representation difference, not evidence of harmful training or leakage: future quantities are permitted as training labels. A correction should be judged against the useful extra supervision that the current auxiliary may provide. All existing model code and labels remain unchanged.

The primary interior-to-interior movement table takes modal `(-Δt0,+Δt1)` votes at price-code events, support at least 3 and confidence .80. It assumes the common future reference is stable across those transitions. On held-out eligible interior-to-interior events it is exact on 12,177/12,177 mapped class 0 events, 6,240/6,240 class 1, 14,350/14,350 class 2, and 49,842/49,842 class 3. Mapping coverage among those events is 67.89%, 90.16%, 99.10%, and 99.93%, respectively. The two target identities supply the coordinate; exactness is not independent identification of physical movement.

This graph cannot be an absolute price potential of the current code alone. Accepted edges generate nonzero closed-code displacements, always equal on the two sides in inspected examples. Reverse-edge pairs have ±1/±1 net shifts in every class. Whole-graph consistency checks have 824/2,418, 244/766, 64/188, and 14/60 nonzero constraint checks. These are correlated graph checks rather than independent cycles. The evidence is consistent with a relative shape code whose origin shifts along paths, and also leaves common-reference contamination as an identification limit. A useful transition decoder need not admit a static absolute-price map. Translations or reflections of external physical books must not be applied numerically to competition feature codes based on this evidence.

Quiet-row behavior is tightly locked to current codes: only 3 of 76,815 held-out target-change rows occur without an i0 price-code change (all three class 1), and zero inverted-spread changes occur inside such plateaus. There are zero invalid spreads or both-positive target pairs in the held-out sample. These are publication-row identities; they do not identify elapsed time or a future horizon. The three exceptions also mean that assigning origin targets to every row in a plateau is not mathematically exact everywhere.

The adaptive path probes use the unchanged interior-only TRAIN maps. Future rows serve diagnosis only. A shared future bid/ask mark without stops is also insufficient. Its required future spread would be `k-winner`. That value is less than 1 on 22,203/34,003, 22,253/34,155, 61,764/93,926, and 36,730/86,198 mapped outside publication rows. These rows cannot have a positive future spread under that simple mark equation. Remaining rows merely permit the equation; they do not identify future spread or its time. No stop law or alternate horizon was selected.

The highest-value next falsifier is a matched auxiliary experiment on frozen clean data: original target-proxy spread auxiliary, code-derived current-spread auxiliary, and code-derived current spread plus separate future excess-offset auxiliary, with identical masks, weights, updates and model size. A current-code map must be fitted within each training fold, expose an unknown flag/fallback, and be built without validation targets or masks. The original auxiliary is the required control. A nonlinear full outcome head would repeat prior failed families until the generator or new useful coordinate has additional evidence. No such experiment was launched here, and this actor cannot promote its own result.
