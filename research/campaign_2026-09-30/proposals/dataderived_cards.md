## Facts and boundaries driving the cards

1. **A6 marker:** source float32 endpoint `-5.199337482452393` occurs on all 67,839 mapped held-out nonzero transitions and none of the 45,649 mapped zero transitions. Overall move-map coverage is 87.04%, but class0 only59.79%; unknown transitions remain unknown. There are three nonorigin endpoint rows without a price-code refresh plus ten endpoint sequence origins. The equivalence is between the marker and **accepted decoded nonzero moves**, not independently observed physical quotes or all events.
2. **Current versus future-derived spread:** the interior-only TRAIN current-code map exactly recovers interior spread on mapped held-out rows. Coverage is80.54/95.85/99.90/99.99% by class. Outside, with winner `w=max(t0,t1)>0` and loser `l=min(t0,t1)`, `k=-l-s_current` is not always2. The old proxy `s_proxy=-l-2` equals `s_current+(k-2)` there. Fixed offset2 holds only57.60/71.57% of mapped outside rows in classes0/1. Current spread and winning magnitude do not identify the entire pair.
3. **Clock feasibility:** a5/a6 are nondecreasing on the tested corresponding quiet intervals, with zero decreases. Monotonicity and a shared quantile endpoint do not prove additive elapsed time. A nonconstant common inverse could be constrained by equality of increments at different age offsets, but this experiment is still proposed, not established.
4. **Negative evidence:** E-025 gives weak far-from-break a-feature direction AUC; E-056 event-code GRU is flat; E-070/E-079 future movement/horizon results are oracle diagnostics; E-091 clock semantics exceeded its correlation evidence; E-270 frozen rich heads overfit. The cards change the observed coordinate or factorization and do not rerun unchanged raw-book event GRU, future quote-path auxiliaries, or generic age labels.

## D1 — Endpoint-written associative content memory

**Representation change:** write an associative memory on the direct a6 endpoint clock rather than every price-code refresh. Use causal current-code features and accepted transition coordinates as contextual metadata; never assume an unknown transition is zero. This has two separate claims: endpoint writes beat code-refresh writes, and content addressing beats position-only addressing.

**Model:** h96 one-layer row GRU plus four linear-attention memories, each key8/value16, event half-lives[2,4,16,64]. Query/key inputs are96 dimensions. Write on `endpoint_t && t>0`, after extracting endpoint equality from the original float32 a6 **before normalization, rounding or autocast**. Handle the origin as an explicit initial observation in all arms, excluded from move counts. Quiet endpoint exceptions are valid observed writes with movement unknown. Values see the same causal hidden embedding, mapped-current-spread/unknown and mapped-transition/unknown flags in all arms. If movement labels are unavailable, use the raw embedding and unknown bit; never manufacture decoded displacement. A decoder supplies only local transitions, never a static absolute-price potential or an indefinitely accumulated physical price across unknown edges.

```text
S_j <- a_j*S_j + E_t*phi(k_j) outer v_j
Z_j <- a_j*Z_j + E_t*phi(k_j)
a_j = 2^(-E_t/half_life_j); phi=ELU+1
r_j = phi(q_j)^T S_j / max(phi(q_j)^T Z_j,1e-6)
prediction = shared_head(h_row,z,retrieved_memories)
```

S/Z are FP32; all keys, values and query embeddings are current/past only. This is the normalized memory design from the earlier cards, now conditioned on a newly identified supplied-data event marker. It is not the E-056 extra event GRU or a future path label.

**Matched active-capacity controls:** three arms with identical tensors, state size, head dimensions, value/readout maps and optimization. C: endpoint writes/content queries and keys. P: endpoint writes/position queries and keys. R: raw-code writes/content queries and keys. C must beat P to support content retrieval and R to support endpoint selection. Different write counts are the intended C/R intervention; execute the memory arithmetic every row with a0/1 write gate in both, so active FLOP budget remains equal. Position generation is also executed and content encoding retained in every arm since all use h for values/head; no dummy projection is counted.

**Exact96-dimensional position basis fixing the earlier critic finding:** define

```text
b_j(n)=(-1)^popcount((n mod128) AND j), j=0..95.
q_position=b(row_counter); k_position=b(endpoint_write_counter).
```

The128x96 matrix over a complete128-position cycle has `B^T B=128 I96`; all96 columns are real, varying active coordinates except the legitimate intercept column. Use **no q/k biases** in either arm, avoiding duplicate intercept parameters. The input dimension and96x8 learned q/k maps are exactly the same as for content. Query positions traverse all128 row positions; keys traverse all128 write positions. Because key positions use event ordinal, sparse writes do not select the same few row positions. Preflight must show rank96 for actual query and written-key input matrices aggregated on TRAIN, positive variance/eigenvalue coverage, and nonzero gradient exposure for every q/k column; if fewer than128 writes provide inadequate rank, screen is blocked rather than padded. This removes constant/low-dimensional age-code dummy parameters. It does not prove identical function classes: position and content are deliberately different information sources, and linear-attention product symmetries exist in both. The basis is periodic and may offer its own cyclic shortcut, so report a negative result honestly.

**Cheap falsifier:** independent feature-only endpoint replay on frozen new TRAIN components, stratifying known zero/nonzero/unknown, origins and quiet endpoints. Then a fixed-projection causal memory probe on the report-sized96 groups, fit TRAIN-only linear residuals with the same ridge penalty and96-dimensional maps in C/P/R; full timelines, no treating scored-only cached rows as consecutive steps. Cap60s/1thread/2GiB; if it cannot finish, no expensive continuation follows automatically. This is an information probe, not validation of learned attention. Reject endpoint equivalence on any known-move mismatch; reject simple memory lineage if C loses both controls on complete rows, while distinguishing unknown coverage from known errors.

**Frozen fit:** D1 C/P/R share seed3/epoch3 and protocol above; maximum0.30GPUh per arm,0.90GPUh total first-fold reserve. Same maps/hyperparameters fixed before score. No auxiliary horizon changed. Confirmation runs C plus whichever single matched comparator was strongest on fold0, with comparator identity frozen before folds2/3.

**Prior/effect:** a6 is already an input, so the marker might only improve optimization and may yield zero gain. Unknown class0 moves and future unpredictability limit upside. Working prior is centered at zero; most plausible useful fixed-blend gains are on the order0–0.001 local WP, not a forecast or CI. No evidence supports the required+0.0038 public gain. Content-memory overfit remains plausible after E-270.

**Cost/deployment:** approximately0.12–0.18M parameters, h96 plus544 FP32 memory floats, about2.6KB state; roughly90–140k MAC/row. Pair/triple cap as above, estimated2–4.8GB observed VRAM. Content versus position adds no additional memory; Walsh rows can be precomputed as a128x96 int8 table (~12KB). Rust needs small outer products, exact endpoint extraction and causal counters, no softmax cache. Fixed raw-code map around1k states requires an explicit compact lookup/hash index, collision verification and unknown fallback; no giant code dictionary. Runtime plausibly no worse than one h128 two-layer GRU after port, but this must be measured. Check128-step periodic boundary, chunk boundary, zero endpoints, rare quiet endpoints, unknown decoder edges and resets.

## D2 — Separate present-state code from future tail excess

**Representation change:** a supplied-code view provides the current interior spread coordinate, while a recurrent view predicts future excess over the old proxy. This factors present state and future supervision instead of treating the old inverted quantity as a pure current spread or hard-coding a new outcome law.

Fit the pooled interior-only `(class,s_current)` lookup on fold TRAIN, support>=3/confidence>=.95, preserving the full22-field source code and explicit unknowns. No validation-derived classes or code table. Give all candidate/control models the same bounded static code embedding `(s_current,code_class,known)` and recurrent embedding; no class supplied externally at inference. The lookup is a supervised TRAIN representation. Its apparent exactness on mapped interior transitions is **not** coverage on arbitrary future codes.

Attach two equal affine96-to1 heads to a shared96-dimensional factor representation, with both outputs active on all code-known training rows. Candidate labels are `(s_current,e)`, where `e=s_proxy-s_current`, zero when the accepted interior rule gives s_proxy=s_current and varying on outside tail rows. Mechanism control labels are `(s_current,s_proxy)` with identical tensors, losses, masks, sample weights and updates. This is an invertible target-coordinate change on known rows, not additional information: the control retains exactly the same current/future target information and actively exercises both output directions. Fit each label scale with TRAIN statistics only; record the2x2 target covariance on supported tail/interior rows. If either label is constant or the target matrix is rank1, the active-capacity claim fails and the corresponding two-factor comparison is not launched. Include the untouched original auxiliary recipe as the separate campaign anchor; do not present it as the equal-capacity mechanistic comparator.

The main two-target head stays unconstrained. Future excess is a training label only; no realized outside branch, winner, loser, excess, future hit or scoring mask reaches the inference representation. The current-code input can enter the head through a small static/recurrent fusion map, identically in candidate/control. Unknown codes use zero coordinate plus unknown bit, preserving the ordinary learned raw-input path. Auxiliary losses mask unknowns identically; main losses continue on all rows. Do not force s_current from exterior labels or extrapolate the fixed-offset2 law to classes0/1.

**Mechanism:** the static factor can explain known current-state variation, and the residual tail factor encourages the recurrent representation to encode future conditional risk without spending capacity relearning their mixture. It may also deprive the model of useful supervision, since the old proxy intentionally or incidentally combines both. Because labels are invertibly related and scales are matched, large gains would warrant a loss-weight/optimization audit, not a claim that new data information was created.

**Cheap falsifier:** first independently reproduce the current-code map on fresh TRAIN components with interior-only votes, held-out unknown coverage, code-collision checking and quiet-row exceptions. Then compare TRAIN-only two-output ridge predictors for `(s,e)` versus `(s,s_proxy)` using identical finite causal code/activity features and fixed regularization; grade main-target cross-validation on component-held-out rows via the same shared linear main readout, not oracle target inversion. Cap60s/1thread/2GiB. If a fully unconstrained ridge formulation is algebraically invariant to this invertible label transform, record it as a null-control identity rather than pretend to test the neural hypothesis; the cheap useful result is label covariance/conditioning, and neural regularized shared representation remains untested. No outcome head fit is justified solely by spread lookup exactness.

**Frozen fit:** two arms under shared protocol,0.25GPUh each,0.50GPUh total first-fold reserve. Two-factor auxiliary total weight fixed at the historical structural auxiliary weight0.3, split0.15/0.15 after TRAIN standardization in both arms. Existing next auxiliary remains0.3; do not rescale main weights. Freeze static fusion shape/activation and both96-to1 heads before fit. Candidate/control final epoch3. Confirmation uses the same candidate versus current/proxy control on folds2/3; unchanged anchor predictions are reused.

**Falsifier:** fail if disentangling does not beat current/proxy control, if no exact fixed-blend gain>=0.0005, if gains are only on mapped interior rows but unknown/full-row performance worsens, or if class0/1 tail behavior is not improved. A candidate gain solely versus the untouched auxiliary with no matched-coordinate win rejects the claimed residual factorization. Never replace output predictions using a target-derived lookup or selected tail law.

**Prior/effect:** even-current-code labels can be easy/ redundant, while old proxy supplies useful future supervision. Prior centered at zero with meaningful negative probability; plausible local differences roughly-0.001 to+0.001 for a fixed blend are engineering expectations, not calibrated probabilities. No claim of public improvement follows.

**Cost/deployment:** underlying h128GRU2 stays near0.26M parameters; factor fusion and194 head parameters add little training work. The shared static feature fusion, if used by the main head, must be exported in both arms; training-only factor heads are omitted at inference. Compact current-code table likely<0.2MB with1k full22float keys plus values/index, but full-fold cardinality must be measured. Inference overhead consists of one code lookup on code refresh plus a small projection; no new temporal state beyond previous code/unknown cache. Native lookup rounding/hashing must exactly match Python and retain collisions/unknowns. Plausibly<5% member latency overhead, unmeasured; package measured<=52min remains decisive. Current-state map fit memory is capped2GiB via streaming support counts; abandon map completeness rather than expand the job without a budget.

## D3 — Feature-identified monotone time warp driving continuous decay

**Representation change:** recover a shared additive **feature time coordinate up to scale**, then use it to control stable decay. Do not call inverseNormalCDF, row age, or monotonicity a physical clock. Model work is conditional on the separate inverse-clock proof.

**Proof stage:** use the frozen proposed16-knot CDF-domain monotone inverse f5/f6 with endpoint0 anchors, f5(.5)=1, positive slope floor.01, f6(1)<=100 and curvature penalty1e-4. Fit one convex quadratic objective on up to512 fixed TRAIN hash-selected transitions/group where both i0 price-code and trade-block are unchanged; excluded origins and clipped endpoints are separately graded. Objective is `(delta f5-delta f6)^2`. Max200 optimizer iterations,1CPU/2GiB/60s. Compare identity-CDF and log-survival inverses with a TRAIN-only positive scalar; row-age gives equal increments tautologically and is a negative identification control. No clocks or hyperparameters are selected using target outcomes.

**Discriminating proof requirement:** materially lower held-out normalized increment disagreement than both fixed-coordinate controls across components and age-offset bins, nontrivial increment variance, supported anchors/slope coverage, no agreement concentrated on unsupported knots or a narrow source class, and independent fresh-component replay. Require current observations of one quiet clock to reconstruct the other's increment at different offsets. Report all extrapolation/clipping/unknown mass. This can support a common additive coordinate, not seconds, true arrival times, full reset semantics or a target horizon. If the inverse collapses increments or cannot transfer, stop this lineage before GPU.

**Causal duration extraction:** when both blocks are unchanged and inverses valid, delta_tau is the average of their nonnegative increments, provided feature-only disagreement is within a frozen TRAIN tolerance. When one block refreshes, use the nonrefreshed clock only if its increment is valid. If both refresh, either clips, a clock decreases unexpectedly, or no quiet clock supplies an identified increment, set an unknown flag and use a fixed TRAIN median increment. The median is a model fallback, never a recovered physical duration. Origins use the same fallback and initialized states. a6 quiet endpoints and unidentified resets are handled explicitly; they must not silently generate negative time or be treated as zero movement. Scale delta_tau by the fixed TRAIN median; no per-sequence full-history normalizer.

**Model:** two width96 blocks of diagonal state96 with nonlinear gated readout. Each state update is

```text
alpha_i,t = exp(-lambda_i * delta_tau_t)
s_i,t = alpha_i,t*s_i,t-1 + sqrt(max(1-alpha_i,t^2,0))*B_i*u_t
```

All state/decay computation uses FP32; lambda_i>0 with fixed initial half-lives[2,8,32,128] **in normalized feature-time units**. The same immediate raw-input and unknown-clock flags reach every arm. Matched control uses delta_tau=1 for all rows, and executes the same exp/injection/state maps. It has identical trainable tensors, active state modes, parameters, FLOPs and updates; no ignored time adapter is counted. A second frozen control can use standardized positive CDF increment coordinate only if declared before any target fit, but is not added after a promising first score. This differs from age auxiliary and the old row/event GRU by changing state evolution under a feature-proved additive coordinate.

**Cheap causal falsifier after inverse proof:** same fixed linear state bank under inferred delta_tau versus1, identical bounded basis/features/readout ridge and TRAIN component rows. Grade complete-row target prediction and unknown-duration slices. This is a bounded information probe, not an end-to-end SSM claim. An impulse/full-versus-partitioned update and time-scale invariance check can reject an invalid implementation before train. If a positive effect is driven by unknown fallback frequency alone, add a predeclared flag-only analysis to reveal it; do not tune routing or clock tolerance on held-out targets.

**Frozen fit:** inferred-time versus row-time pair,0.30GPUh per arm,0.60GPUh total; shared seed3/epoch3 protocol and80/20 blend. Freeze the inverse table and validity rules from feature-only TRAIN fit before any candidate score. Use the same variable-coefficient associative scan in both arms, with the control's coefficients computed by the same function at delta_tau1; a faster custom control would confuse compute matching. Confirmation refits inverse functions on each confirmation fold's TRAIN components using the same knots/anchors/settings, not a global inverse fitted across folds.

**Prior/effect:** strongest reason to continue is feature-only common-increment proof; before that model prior is diffuse and centered at zero. A fitted inverse may be an arbitrary warp satisfying limited age constraints. Even a valid additive coordinate may carry no extra target signal (E-025) and the network already sees a5/a6. Expected local fixed-blend effect should be treated as approximately0, with a useful+0.0005 screen possible but unsupported. This is the most conditional proposal and earns no GPU before clock proof.

**Cost/deployment:** roughly0.09–0.15M parameters,192 FP32 state floats768B, two small16-knot interpolation tables, ~70–110k MAC/row plus192 exp calls in the simplest implementation. Reuse one exp per grouped decay rate if lambdas are tied by fixed bands, but tie them identically in both arms and freeze before fit; do not claim full per-channel capacity while deploying tied modes. Piecewise-linear inverse tables and causal validity bits are Rust-streamable. Scalar exp latency may outweigh saved MACs; unknown-duration fallback and clipping must be branch-consistent. Estimate single-member runtime below a two-layer h128GRU only after optimized profiling;2–4.8GB observed VRAM estimate remains unmeasured. Native FP32 interpolation/decay and flat tuple states must match batch/chunk/native implementations within frozen tolerances, including very slow modes and long constant inputs.
