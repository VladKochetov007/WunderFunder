# GALAM source identity and fidelity

The user supplied four screenshots on27October2026. The architecture image is
[preserved unchanged](galam-original-diagram.jpg). [IMAGE_MANIFEST.json](IMAGE_MANIFEST.json)
binds all four original files by SHA256; three phone screenshots remain in the
user's Downloads because they duplicate the linked author post and contain phone UI.

[PUBLIC_SOURCE_SEARCH.json](PUBLIC_SOURCE_SEARCH.json) records the bounded public
search, primary URLs and observed repository revisions. The author's public post
and Discord text describe GALAM but do not supply original source, full dimensions,
weights, original training hyperparameters or the four-model FiLM orchestration.
Other public Wunder RNN repositories are distinct solutions, not GALAM references.

- [FIDELITY.md](FIDELITY.md) maps the supplied graph to code, known matches,
  explicit assumptions, source contradictions and missing reference evidence.
- [SOURCE_IDEAS.json](SOURCE_IDEAS.json) preserves all four user-requested source
  directions and links. They are external reports and unrun hypotheses, not gains
  measured by our team.
- [Reconstruction packet](../../../experiment_drafts/galam-reconstruction-20261027/README.md)
  links code, two separately labelled shape configurations, tests and fit-admission
  limitations. No training is launched.
