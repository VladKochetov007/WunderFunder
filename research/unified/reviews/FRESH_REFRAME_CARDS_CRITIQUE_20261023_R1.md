# Independent critique of the fresh input-representation cards

## Verdict and scope

The four directions remain plausible proposals, with three distinct new mechanisms: shared pair pooling (H-395), input-triggered update skipping (H-396), and a randomized degree-two sidecar (H-397). Per-channel age is an elaboration of the already retained H-PER-FIELD-AGE-20261022-R1, not a new arm. The cited papers support the component methods in their original settings; none establishes Challenge2 quality or runtime improvement.

This is a source-only review of the [cards](../ideas/FRESH_REFRAME_20261023_R1.md), [source receipt](../sources/FRESH_REFRAME_SOURCES_20261023_R1.md), [reframe contract](../../campaign_2026-10-21/next_cycle_r1/REFRAME_CONTRACT_R1.json), objective, tree mappings, and cited primary papers. I did not inspect model code, data, predictions or run receipts; perform a data scan, replay, fit, test or profile; or assign numerical priors. All local folds are exposed. No test is admitted by this review. The contract grants zero additional fits to reframing, and the in-flight 12-head panel should proceed independently.

The proposal notes disclose that a broad search exposed fragments of older idea notes before the cards were committed. That weakens the claim of blind first-proposal independence; retain the cards as source-grounded proposals and keep the exposure attached to later interpretation. This critique is an independent review of the written sources, not a blind ideation replication.

No such reusable same-stage controls were identified in this source review, so 6/4/4 is the defensible planning count for the proposed two-cell student screens. ## Mechanism and control findings

**H-395 — conditional pass after count correction.** [Deep Sets](https://arxiv.org/abs/1703.06114) studies functions invariant to permutations of set elements. That result applies only if the proposed pair elements have a useful exchangeability symmetry. Anonymous column names and the hypothesized 52 `i1`/`i0` correspondences do not establish such symmetry. The raw bypass is a good protection for fixed channel identity; keep the pair map and its direction convention frozen. The deranged control must preserve the same architecture, pair count, feature scaling and initialization, changing only the correspondence map. A raw-only control is also needed to tell whether the sidecar helps at all.

The card's “four fits” and “two challenger fits” alternatives do not say which arms those counts include, while the intervention and falsifier name raw-only, proposed-map, and deranged-map endpoints. The full matched comparison is three arms × two cells = six fits when none of those endpoints is an exact reusable match; the current tree entry records this design. A valid four-fit shortcut is to fit only the proposed and deranged maps on both cells and report the frozen raw parent as an **unadapted reference**. That tests map-specific value but leaves the candidate-versus-parent delta confounded by additional adaptation. Two new fits would require exact same-stage raw and deranged controls for both cells, leaving only the proposed map to fit; no such artifacts were identified here. State which design is intended and align the card text to it.

**Per-channel age — source-grounded elaboration, with an operational definition still missing.** [GRU-D](https://arxiv.org/abs/1606.01865) uses masks and elapsed time for irregular or missing clinical observations. Challenge2 rows are observed, so informative missingness does not transfer. A narrower transferable component is per-feature elapsed time since a causal, train-calibrated change event. Define the change tolerance and age cap per feature from fitting inputs only, append age beside the raw path, and reset ages at every sequence boundary. Without a fixed tolerance, ages may mostly encode floating-point jitter or become nearly constant. Keep the existing H-PER-FIELD-AGE ID and provenance; the new card is not duplicate scientific evidence.

For the 4-fit comparison, keep the parent function identical at initialization: zero-initialize the new sidecar's contribution, then fit age and zero-age controls with the same parent, stages and update budget. This makes the treatment the information in age rather than a changed cold-start function or extra input-head capacity. The card's proposed falsifier “nearly every feature resets every row” requires a fitting-only input diagnostic; that diagnostic is useful but was not run or authorized here.

**H-396 — good cheap falsifier, but a different claim from the cited method.** [Skip RNN](https://arxiv.org/abs/1708.06834) learns when to skip updates and uses update-budget pressure. A standardized input-difference threshold is a deterministic heuristic, not a reproduction of that learned gate. It assumes low input novelty means the recurrent state is not useful to update; long unchanged-input runs can still contain target changes or accumulated state error. The frozen-checkpoint replay is a defensible first test of inference-time quality/runtime only. Freeze the training-only scaling, threshold tie rule, first-row forced update and gate computation. Read out every required row, hold state only on skipped steps, and reset previous-input and recurrent state at sequence boundaries. If gating overhead erases the recurrent savings or later outputs degrade, the stated inference claim fails on this screen; one fold remains a cheap exposed-data screen, not a family-wide rejection.

**H-397 — conditional pass, with a narrow approximation claim.** Pham and Pagh's [TensorSketch paper](https://researcher.itu.dk/en/publications/fast-and-scalable-polynomial-kernels-via-explicit-feature-maps/) uses CountSketch and convolution to approximate polynomial-kernel features. That establishes a way to construct a randomized interaction map, not that appending it to a nonlinear recurrent model improves this endpoint. The paper's asymptotic cost is not a local training or serving guarantee. Fix either 32 or 64 dimensions and the exact hash/sign maps before the first screen; test one hash across the two paired cells, then treat another hash as a new follow-up. Otherwise a dimension/hash sweep silently expands selection. Use a matched zero-sketch sidecar so both arms have the same model shape and parent function at initialization. Record collisions/map hashes and check training/export operator parity under strict FP32; confirm the chosen FFT/convolution implementation is deterministic on the serving path. Profile full per-row and full-sequence costs before fit admission, since the input is dense and there are about 20,000 rows.

## Shared invariants and one transferable component

Every eventual comparison must preserve strict FP32 with autocast and TF32 off, deterministic feature maps/gates, causal prefix-only computation, sequence-state reset, source-qualified memberships, and the fixed `global_wp_clip2_v1` outcome: fixed `need_prediction AND is_scored` mask, clipping at ±2, original clipped-label magnitude weights, and the mean over both targets. Fit all normalization, thresholds and tolerances using fitting inputs only; do not use validation labels to define events. Compare complete endpoints against matched controls. Report the two-cell paired deltas and model-seed/fold exposure separately; conditional component resampling on these exposed folds does not provide fresh confirmation or public-transfer evidence.

One defensible transfer is GRU-D's per-channel elapsed-time state, limited to **time since last meaningful input change**. Keep raw values, add a causal age with fit-only threshold/scale, and reset it per sequence. Do not import the missingness-mask or clinical missingness claim. This supplies a concrete, low-dimensional feature to test while preserving the parent path.
