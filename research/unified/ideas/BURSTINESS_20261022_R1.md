# Burstiness versus sustained movement

Compare recent squared input changes with adjacent absolute-change products, keeping one bounded causal summary per existing semantic group. The hypothesis is that isolated bursts and sustained movement can have different target relationships even at similar total change energy. This transfers a descriptive component of [power and bipower variation](https://shephard.scholars.harvard.edu/publications/power-and-bipower-variation-stochastic-volatility-and-jumps).

Anonymous competition fields do not establish market prices, continuous-time sampling assumptions, or identifiable economic jumps. Any energy/product contrast is a representation, not a jump estimator claim. Test incremental target and complete-endpoint value against a matched control if separately allocated; an attractive feature histogram alone is insufficient.
