# Matched warm-parent alpha-0 continuation packet

Status: code-only recipe packet, not independently reviewed or admitted for training. The intended primary contrast is the incremental effect of applying the current clean-T3 target during a six-epoch continuation of a fixed warm parent. It is not a cold-start KD test, a clean test of teacher ancestry, or a teacher-capacity experiment.

## The controlled contrast

Use the same seed-3 H256×2 GRU parent, `c20261003_combo_s3_f0@ep3` (checkpoint SHA-256 `d4a1e50b1892b4d9edd7c255908b68073a760c059ca80223e98a63c7e023371e`), in both arms. Hold fold-0 membership/order, normalization, batch/chunk, precision, optimizer, OneCycle schedule, propensity, auxiliary losses, seed and six-epoch budget fixed. The only model-objective change is `--distill-alpha 0` versus `--distill-alpha 0.9`.

The alpha-0 arm still inherits its initializer's history: the parent itself was trained for four epochs with alpha .5 distillation from `c20260929_since_s3_f0` and `c20260929_since_s4_f0`. Therefore this estimates the marginal value of continuing the new homogeneous T3 target on top of that warm parent; it does not estimate the value of all distillation versus a model with no teacher ancestry.

The alpha-.9 reference already exists as `clean_t3_f0_control_s3_a9_t3r5_r2_p3_envr1`, graded at fixed epoch 5 with WP `0.6811553603333363` on 468 repeatedly exposed F0 groups / 141 components. Its exact initialized parent scored `0.6809412068071548` in the historical grade bank (bank SHA-256 `cc2a690c978d0bfa30124401141c1cb55874756aadcbea48a8e1f910c0ee825c`); an independent critic verified the same fold split, fit/eval membership, normalization and initializer checkpoint. The parent bank does not record inference precision, so the parent number is lineage context rather than a precision-matched effect estimate. The raw six-epoch continuation delta is `+0.000214153526`, with no paired interval. This is context, not evidence of a distillation effect.

Reuse the existing alpha-.9 endpoint and its saved epoch-1/3/5 checkpoints only after the execution owner revalidates the pins below and confirms the stage artifacts are present. If any pin fails or a true rerun is needed, train a fresh alpha-.9 arm from the same parent and recipe rather than substituting a nonmatching result. The only new fit needed when reuse passes is alpha 0.

## Frozen recipe and single-flag diff

Common model/trainer recipe: `gru`/`gru`, hidden 256, 2 layers, dropout 0; seed 3; train source `train+valid`; fold 0; train/valid sequence selectors `10607`/`600`; `no-eval-during-fit`; split manifest `research/campaign_2026-09-29/artifacts/splits/fold0.json`; six-epoch OneCycle horizon; fixed selected checkpoint zero-based epoch 5; AdamW, LR `1e-4`, weight decay `.01`; FP16; B16, C2000; WMSE with chunk normalization; `c20260929_prop_f0`, power 2, epsilon `.03`, cached propensity; valid true mask `.03`; structure and next auxiliaries `.3` each; since weight 0 / floor `.25`; homogeneous clean-T3 cache below; MSE distillation, channel weights `1,1`, chunk denominator, alpha tau 32, bootstrap 0, reanchor 0, family weight 0; label-weight power 1 / floor 0; fast/sync-free/fused-Adam/pinned memory; same initializer checkpoint.

Keep the same cache path and loss path in both arms, including alpha 0, so the cache consumer and all code paths remain fixed. In the alpha-0 arm the blend is the clipped original label, so the teacher coefficient is exactly zero; the cache's continued presence is not a teacher-target exposure. Do not change `T`, rescale predictions, add/remove auxiliaries, alter the scheduler horizon, or change the precision/batch to make the run cheaper.

The current alpha-.9 recipe's target is `T = float32(0.8125 * float32_mean(F0 clean-T3 teacher seeds 3/4/5, epoch 2))`; the cache is not clipped at construction. The trainer clips labels and teacher values to ±2 when blending. Its six-epoch A9 recipe is `0.1*clip(y,2) + 0.9*clip(T,2)`. Alpha 0 uses `clip(y,2)` as the main target, while preserving the same loss weights and auxiliary terms.

Stage layout follows the existing continuation runner so each two-epoch segment has a durable resume state and cannot silently restart the OneCycle schedule:

All stages retain `--epochs 6`, the same six-epoch scheduler horizon, and `--checkpoint-policy fixed --checkpoint-epoch 5`; do not treat the stage boundary as a selected checkpoint. Use distinct stage run names and the existing `cleanfold_exec.py` + `train_rnn.py` source snapshot. The trainer saves per-epoch `model_epN.pt` snapshots as well as the resumable state. Score alpha-0 and alpha-.9 at their declared epoch-1, epoch-3 and epoch-5 snapshots with the same post-fit feature-only prediction/export, `--inference-precision fp32`, and official fixed-fold grader. These points describe the trajectory; they are not an early-stopping or checkpoint-selection rule. The endpoint comparison remains the predeclared fixed epoch 5.

Only change the alpha flag in the trainer argument vector. For P1, clone the existing control P1 vector, changing the run name and alpha; for P2/P3, clone the matching stage vectors and change run/stage/output and alpha exactly as required by the new alpha-0 source-bound contract. Preserve the previous root contract/admission protocol, fresh output-absence checks, and recoverable-state SHA checks. Do not launch a stale template directly.

## Resource basis, outcomes and gates

The three successful A9 continuation stages took 2,142.48 s, 1,936.84 s and 2,076.10 s, total 6,155.42 s (about 103 minutes) for one six-epoch arm. Worker peak RAM was about 4.95 GB under a 5.5 GB reserve; observed VRAM peak was about 2.64 GB under a 5 GB ceiling. The full worker used one CPU, zero loader workers, and a 4.3 GB allocator cap. This is a host-specific planning estimate, not a reservation or current admission. A newly fitted alpha-0 arm is therefore expected to cost roughly 1.7 hours plus checkpoint verification and three fixed snapshot grades. If the A9 trajectory cannot be safely reused, rerunning it doubles fit time. Fresh aggregate memory/GPU/CPU accounting and root admission are mandatory before any stage; the packet authorizes none.

Record stage attempts, terminal states, resume-state hashes, checkpoint hashes, update/AMP-skip counts, wall time, peak RAM/VRAM, and OOM deltas. In particular, do not assume an existing profile/capacity receipt replaces a fresh system admission.

Primary analysis: paired component bootstrap on the same 468 groups and 141 components for epoch-5 alpha-0 versus epoch-5 alpha-.9; report raw difference and interval. Also report the fixed checkpoint trajectory at two/four/six epochs without selecting among them. If A9 improves over alpha 0, that supports a marginal benefit of continuing the current T3 target for this warm parent/seed/fold/recipe. If alpha 0 matches or beats A9, this challenges alpha .9 as the best continuation treatment here, not teacher use in general. In either case, the parent already has distillation ancestry, F0 is exposed, and cross-fold/distinct-seed confirmation is required before promotion. No public forecast follows.
