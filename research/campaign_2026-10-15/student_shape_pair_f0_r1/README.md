# F0 seed-3 matched student shape pair R1

This packet prepares a private Kaggle T4 resource profile for the fresh-init H256×2 and H512×1 GRU students. Both arms share the audited clean F0 T3 cache, seed-3 source-qualified B16 order, 211-feature fitting normalization copied from the clean F0 H256×2 CP5 control, B16/C2000 batches, FP16, and identical AdamW/OneCycle settings. Only the recurrent width/depth changes between the two profile jobs. The intended later quality comparison is a three-complete-epoch pair at fixed CP2; that fit is not admitted by this profile packet.

The first GPU job runs the actual `train_rnn.py` CLI for five complete B16 batches per shape, or 50 chunk-level optimizer attempts per worker. The two shapes run serially in one private profile kernel. The measured 50-update rates will inform a later root-owned full-fit admission; they do not establish quality or provide an unmeasured three-epoch runtime guarantee. This profile loads no student checkpoint, saves no checkpoint, does not evaluate labels or predictions and does not export predictions. The previous ladder screen used one epoch, B8 and FP32, so this new matched pair also changes exposure, batch size and precision relative to that historical screen.

The consumer source edit is frozen in [student_frontier.py](../../../src/wnn/student_frontier.py) and hash-pinned by the recipe contract. It lets the explicit stage validate FP16, its initial AMP scale, the declared five-batch profile bounds, and the bundled relative source root while retaining the strict cache/provenance validator.
