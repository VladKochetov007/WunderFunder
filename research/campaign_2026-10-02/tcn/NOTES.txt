H-065 causal dilated TCN student (train side), 2026-10-02
==========================================================

Goal: an L2-resident student (weights <= ~0.9 MB at int16) as a cheap, architecture-diverse bag partner or
replacement for the distilled GRU256 since student (2.2 MB of weights, ~234 kcyc/row, memory-bound in the engine).

Code
----
src/wnn/nn.py        TCNModel = inp (Linear n_in->C) + GELU  ->  TCN (L CausalConvBlock + LayerNorm)  ->  RNNModel's
                     head Linear(2C->C) GELU Linear(C->n_out) on [tcn output; projection skip z]. Same n_out layout, so
                     wMSE / distillation / aux-struct / aux-next / EMA / GCLP FT run unchanged.
                     Block i (dilation d = 2^i, kernel 2, pre-norm residual):
                         a(t) = GELU(LayerNorm_i(x(t)));  x(t) += W_i [a(t-d); a(t)] + b_i   (W_i: Linear(2C -> C))
                     optional --tcn-mix 1: y = Linear(GELU(y)) before the residual add (off by default: +C^2 per block
                     pushes C128/L12 to 1.31 MB at int16).
                     State h = tuple of per-block tails a(t-d..t-1) (zeros at a sequence start); a chunked forward
                     equals the full-sequence forward exactly, for any chunk length (also chunk < d). Gradients are
                     truncated at chunk boundaries like the GRU's detached h (train_rnn.detach_state handles tuples).
src/wnn/tcn_ref.py   TCNStream: numpy float64 row-at-a-time reference with one ring buffer of d rows per block
                     (slot t mod d holds a(t-d) when row t arrives; read, then overwrite with a(t)). Spec for the Rust
                     port; the docstring has the per-row equations. GELU exact erf, LayerNorm eps 1e-5 biased var.
scripts/train_rnn.py --arch tcn (--hidden = channels C, --layers = blocks L, receptive field 2^L rows), --tcn-mix,
                     tcn_mix inherited on FT (--inherit-init-preprocessing), provenance hashes src/wnn/nn.py.
                     make_model rejects a --freeze prefix that matches no TCN parameter, so ft_gclp.sh's default
                     head_freeze=inp,gru fails loudly on a TCN parent instead of silently fine-tuning the trunk.
                     Every other --arch path is unchanged (new branch only; argparse gains the tcn_mix key, default 0).

Head-only FT: trunk parameter names are inp.* and tcn.* (tcn.blocks.<i>.{norm,conv[,mix.1]}.*, tcn.norm.*), head is
head.*. Pass --freeze inp,tcn; scripts/ft_gclp.sh forwards --freeze to its head stage:
    FT_STAGES=head bash scripts/ft_gclp.sh PARENT@ep3 OUT FOLD 3 ... --freeze inp,tcn

Tests (tests/test_tcn.py, 13 pass, CPU):

  - receptive field: input change at row s moves outputs exactly on rows s..s+2^L-1 (L=6: rows 100..163)
  - numpy TCNStream == torch forward to 1e-5 (C16/L5 with and without mix over 150 rows, so rings wrap; default
    C128/L12/n_in 211/n_out 23 over 160 rows); reset() restarts a sequence
  - make_model + inherit_init_arguments + --freeze inp,tcn leaves exactly head.{0,2}.{weight,bias} trainable;
    --freeze inp,gru on a TCN raises

Inference weights (inp, 12 blocks incl. LayerNorms, output LayerNorm, head layer 0, the 2 used rows of head layer 2):
458,370 params -> 916,740 bytes at int16 = 0.874 MiB (fits the 1.25 MB L2 with ~0.35 MB to spare).
Full checkpoint params with aux heads (n_out 23): 461,079.
MACs/row: inp 27k + blocks 12 x 32.8k = 393k + head 33k = ~453k, about 0.47x a GRU256 (~971k), and L2-resident.
Ring buffers: sum(d) = 4095 rows x 128 channels (2 MiB f32, 1 MiB i16) but each row touches one slot per block
(12 sequential streams, prefetch-friendly); rings of d <= 64 stay in L1/L2.
Receptive field 2^12 = 4096 rows (20% of a 20k-row sequence). Justification: the GRU members train with TBPTT chunk
2000, so every dependency they learn by gradient spans <= 2000 rows; RF 4096 covers twice that. Market class /
tick quantum is visible in any window with quote moves, and the since/event inputs carry event timing. L=13 (RF 8192)
would cost +33k params (+66 KB) if long-range context turns out to matter; C=128 is the widest power of two that fits.
Training memory (CPU estimate, saved activations, B=32 x chunk 2000): ~0.9 GiB (mix: 1.2 GiB); state 32-67 MB.
