  z = GELU(inp(x_norm))                                   inp: Linear(n_in -> H)
  o = gru(z)                                              row clock: --layers x GRU(H), every row
  at an event row e:  s = gru_event([o(e); mean of o over rows (prev event, e]; log1p(that count)], s)
                                                          event clock: GRU(2H+1 -> Hs), event rows only
  non-event rows:     s carried unchanged
  out = head([o; s; z; log1p(rows since the last event)])  head: Linear(2H+Hs+1 -> H), GELU, Linear(H -> n_out)
  (the count runs from the sequence start until the first event; 0 on event rows)
  State (h_row, h_event, seg_sum, seg_rows): seg_* = fp32 sum and count of o over rows after the last event.
  Within a chunk the event GRU runs over the compacted event rows (stable argsort, one host sync per chunk for the
  max event count, as in DualClockModel); segment sums are fp32 cumsum differences (exact in the streaming form).
  Default size H=192 (2 layers), Hs=128: 786,263 params (n_out 23); inference 782,210 params = 1.56 MB at int16.
  MACs/row: 581,760 on every row + 196,992 per event row -> worst case (event every row) 778,752, at the 17.5%
