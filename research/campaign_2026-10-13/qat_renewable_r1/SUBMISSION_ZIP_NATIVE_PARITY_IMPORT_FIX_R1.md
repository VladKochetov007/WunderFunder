# ZIP parity import-path correction R1

Static review of the first checker revision `51c54a67` found a predicted import failure before any actual callback run: it executed extracted `solution.py` by file spec but did not add the ZIP extraction root to `sys.path`. The pinned QAT ZIP's top-level `solution.py` imports `read_qat_archive` with `from qat_archive import ...`; under this loader path that sibling module would be unresolved. This was a source-control-flow finding, not an observed CLI failure, and no model or native library was executed for diagnosis.

The successor adds a package-aware loader that temporarily adds the extracted package root, executes `solution.py`, verifies that any imported `qat_archive` resolves to the extracted sibling, and restores package-root entries from `sys.path`. The helper module stays cached in `sys.modules` for the already-imported solution while the extracted package remains alive; newly cached helpers are removed if import fails. The focused temporary-package regression makes a tiny `solution.py` itself insert the same package root, imports a local `qat_archive.py`, checks that the exact original `sys.path` is restored, and calls the retained helper without native code or GPU. This tests the complete observed failure mechanism without reading or executing the actual weights.

The original `scripts/benchmark_submission_callbacks.py`, `scripts/validate_submission_callback_panel.py`, and `scripts/check_submission_python311.py` also load by `spec_from_file_location` without adding the extraction root. Root separately applied the same minimal `HERE` path setup in `scripts/templates/qat_solution.py`, which is the correct package-local repair for the shipped QAT callback and benefits those existing consumers. That root source change is reviewed independently and is not included in this isolated successor commit.

The generic parity checker still has no actual ZIP/native execution or quality approval. Root owns the next run. See the [checker recipe](SUBMISSION_ZIP_NATIVE_PARITY_CHECK_R1.md) and its indexed [inference entry](../../unified/inference/README.md).
