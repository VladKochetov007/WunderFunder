The v5 error is an admission rejection, not an OOM.

The existing runner’s host gate remains unchanged: per-worker reservations must fit `min(0.8 * capacity, available - 0.2 * capacity)`. It still rejects a reservation larger than that budget and admits two workers only if their summed reservations and CPU counts fit. Before admission, v6 verifies the exact declared code/input bytes, then sends bounded `POSIX_FADV_DONTNEED` hints through read-only FDs for those exact files and takes a second host/GPU inventory. The pre- and post-hint inventory and per-file results are kept in the phase receipt; if the call is unsupported or fails, the fresh memory reading still controls admission and is never overridden. This prevents serial probe waste and preserves the required paired design.

The candidate reserves 8 GiB (8,589,934,592 bytes) per worker, a 56.5% increase over the larger probe peak when computed from raw bytes, and above the requested 1.4× headroom. This is a watchdog reservation, not a provider cgroup limit: the runner samples worker RSS every 250 ms and stops the worker group after exceeding its cap. v6 does not relax the sample-based VRAM stop. Before each phase admission, it records a host/GPU inventory, verifies exact code and input byte identities, then issues `POSIX_FADV_DONTNEED` only to the exact declared regular files through read-only file descriptors. It records a second inventory and the per-file advice result, then applies the same host gate to that fresh reading. No global cache drop, host override, or admission relaxation is used. Advice failures are recorded, but admission still depends only on the actual post-advice memory inventory. Each worker's exit record also captures fresh host/GPU state; the fit phase performs a new admission after both probes. Phase receipts retain pre/post inventories, per-worker exit host/GPU inventories, the cache-advice result, and explicit admitted/rejected state, including on admission failure. If both reservations do not fit after the advice and fresh sample, the phase fails closed before starting workers.
