**Disposition: do not run this grader against the fit yet.** The fitted experiment and its recorded runner attempt appear complete and healthy, but the test-data path has a deterministic label/mask shape error that will stop scoring on the first component. This is a grader integration defect; it does not invalidate the fit or its registered comparisons.

## Findings

1. **Blocking: selected labels are returned with a full-length mask, then indexed with that mask again.** In `read_test_sequence` ([score_head_mixture.py:292](score_head_mixture.py:292)), `raw_y[mask]` is clipped and returned, so the label array has shape `(selected_rows, 2)` while `mask` remains `(20000,)` ([line 310](score_head_mixture.py:310)). `evaluate` indexes that selected-only label array with the original full-row mask at `[line 420](score_head_mixture.py:420)`, and also passes it with full-row predictions and mask to `score_sequence_moments` ([lines 444–447](score_head_mixture.py:444)). Both paths require a `(20000, 2)` label array; the latter explicitly rejects any other shape ([score_head_mixture.py:331](score_head_mixture.py:331)). A bounded synthetic reproduction confirmed the expected `ValueError: sequence labels/predictions misalign`. Keep `raw_y` full length in `read_test_sequence` and return it with `mask`; select and clip only at the scoring/export boundary. This preserves the pre-clip finite check and makes the official mask apply exactly once.

2. **Runner proof is mostly matched to the actual E477 receipt, with two missing fail-closed checks.** I read only the small attempt record and hashed the declared fit-manifest artifact. The attempt has `kind=gpu`, `status=finished`, exit 0, no failure or signals, verified teardown, and the current runtime file-hash map matches the recorded map. Worker OOM counters did not increase; parent OOM counters were already nonzero and unchanged across this attempt, so the correct rule is comparison of initial and final counts, not requiring absolute zero. The single declared artifact is the fit manifest; its current size (38,489 bytes) and SHA-256 (`9416beda…cbe7c7`) match the attempt record. The sealed spec and fit-manifest identity checks are otherwise appropriately strict.

   `verify_sealed_run` does not currently compare `attempt.runtime_sha256` to the current runtime file-hash map, check that worker and parent OOM-event counters did not increase, validate `signals == []` / `kind == "gpu"`, or require the complete attempt artifact list to equal the spec artifact set. These are receipt-hardening gaps rather than evidence of a bad current attempt: the observed attempt satisfies those conditions. Add them before relying on the grader for a durable admission proof. The fit-only cohort JSON is not a declared attempt artifact; the grader correctly does not claim it is runner-digested and instead recomputes mean/scale from the sealed 24 fit row groups and requires exact equality ([score_head_mixture.py:271–289](score_head_mixture.py:271)).
