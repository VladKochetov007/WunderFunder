# Blind design critique: E486 activation counterfactual

Reviewed `E486_DESIGN.md` at SHA256 `1f51d07c818e3103140a879f2b6e964f567296cdda4642e219cb9307d135c508`. This review is design-only: I did not inspect E486 implementation or results, load checkpoints, or read test rows.

## Verdict

The crossed checkpoint-by-inference-shape design is a useful, bounded diagnostic of fixed-weight activation swaps. It can separate the effect of applying a different recurrence at inference from differences between weights trained under the two recurrence choices, conditional on these 18 already exposed fits and these 16 test components. It cannot establish a generally useful training recipe or optimizer mechanism. The design's limits and no-public-forecast language are appropriate. Proceed to source review only after binding the fit and grade artifacts and resolving the controls below.

## Identification and interpretation

For each seed and momentum, the four cells form a 2×2 table: training recurrence (base/sine) and inference recurrence (base/sine). `B−A` and `C−D` are fixed-checkpoint inference interventions. `C−A` and `D−B` compare checkpoints trained under different recurrence choices at a common inference recurrence. The difference-in-differences `(D−B)−(C−A)` measures whether the trained checkpoints respond differently to the inference swap on this panel. `D−A` repeats the already reported matched-shape contrast. The four cells make these quantities identifiable as finite-panel score contrasts; they do not isolate an internal representation or show that the model learned a particular mechanism.

The off-diagonal cells change the causal recurrent computation and can move hidden states outside the training distribution. Therefore score changes include altered hidden trajectories, output scale, and official clipping. The design correctly disclaims a pure representation or amplitude interpretation. Report finite preclip prediction ranges and hidden-state extrema/quantiles for every arm as descriptive diagnostics, without thresholds or arm selection; this will make severe off-diagonal extrapolation visible even when clipping masks it in the official score.

## Conditions before implementation and scoring

- Bind the E483 fit manifest, all 18 checkpoint hashes, successful fit proof/attempt, official grade attempt, frozen v3 scorer, raw selected exports, and root raw-export reproduction receipt. Verify these identities, layouts, identity buffers, fit-only normalizer, data/cohort/mask identity, and arm order before opening test-role rows. The diagonal baseline and sine cells must each match their own E483 exports exactly by component ID and selected-mask order, with raw prediction dtype/shape checked before equality; also reproduce all nine existing diagonal `D−A` point estimates and bootstrap intervals. This confirms the baseline for the counterfactual contrasts rather than presenting it as new evidence.
- Same seed does not by itself prove matched training. For each seed, verify baseline and sine fits started from byte-identical model parameters/buffers and used the same cohort traversal, minibatch/order trace, optimizer/LR recipe, and update count. If existing receipts do not establish this, describe training-shape contrasts as paired checkpoint differences, not a controlled effect of training recurrence.
- Keep parameters and buffers fixed within each checkpoint across both inference modes. Construct a fresh zero recurrent state for every complete sequence/component; preserve canonical row/component order, causal feature construction, fit-only normalizer, target order, and the unchanged full official score mask. Check raw predictions and targets for finiteness before metric clipping. Do not carry state across components or use test data to derive normalization or activation settings.
- Derive all six registered contrasts from the same four component-level outcomes. Use one pinned numeric-sorted component order and one deterministic 2000-draw multiplicity matrix per seed for every cell, target, and contrast. Bind the RNG algorithm/version, draw construction, percentile convention, score arithmetic, and mask/metric helper to the frozen E483 implementation. In each bootstrap replicate calculate the interaction from the same four sampled cell values; do not combine independently bootstrapped intervals. The diagonal `D−A` draw-wise result should reproduce E483's existing paired contrast.
- Retain all 36 cell results and 54 registered contrasts in the output, including dependent contrasts. Keep the three seeds separate and label the 16-component bootstrap as uncertainty over this already exposed panel, not independent replication or population generalization. Never rank/select a model or revise the public forecast from these outcomes.
- Use a new no-overwrite output identity; preserve all original E483 artifacts and failed contract records. Keep the source/run single-threaded CPU-only, bounded to the registered six-GiB/2400-second envelope, and have an independent source review before test scoring.

The main scientific value is the paired off-diagonal comparison under frozen weights. Repeated diagonal evaluation is a stringent implementation check and a transparent bridge to E483, not additional evidence for the registered activation result.
