## What is prepared and what it tests

The experiment continues the fixed public E424 seed-3 combo checkpoint `c20261004_combo_s3_final_r1@ep3` (`artifacts/runs/c20261004_combo_s3_final_r1/model_ep3.pt`, SHA-256 `64c2b28651b414778d6af3c33bb9d54f653a46fb0be087de2e3c44ca88c31166`; provenance SHA-256 `4ab01e3a468e6d86dd9dad0771569723ff0fd76562c0edcd0351f1f24de247557`). It keeps the parent 211-input, 256-hidden, two-layer GRU and 23-output training head. The overlay adds a rank-8 projection of 28 causal volume-context features into only the first layer's GRU update-gate (`z`) input columns. Reset/candidate extension columns are projected to exact zero after Muon attempts and EMA updates. All arms begin as the parent predictor and have equal parameter layouts: parent 980,759 parameters; E427 allocates 6,376 added coordinates, holds 4,096 structurally fixed, and exposes 2,280 effective added parameters (983,039 effective total).

The 28 features use raw input offsets x22:x44 plus path/change/net summaries for the two anonymous 11-channel halves. The endpoint marker at raw x110 resets the cumulative context. `aligned` uses the prefix through the current row; `stale` holds the immediately preceding completed cycle's terminal context until the next cycle, falling back to the fit-only mean before two markers; `noop` sets the added context to zero while retaining the same parameter budget. The code reads input features only, not targets or scored masks. `research_features_torch` uses rowwise difference and prefix cumulative sums; synthetic tests check future-suffix invariance, endpoint semantics, uneven-chunk state carry, zero-extension parity, equal topology, and z-only gradient support. This is a credible causal state-gating comparison, not a physical interpretation of the anonymous channels.

The fit retains the E424 recipe: seed 3, one epoch from fixed EP3, batch 32, chunk 1,000, FP16, Muon on recurrent matrices plus the existing AdamW groups, peak LR 1e-4, WD 0.01, EMA 0.999/eval EMA, `wmse` + auxiliary structural/next losses, fixed `prop_v1` and two distillation teachers, and no fit-time evaluation. The fit membership is 10,606 TRAIN plus 1,505 fit-VALID groups: 12,111 groups, 242,220,000 rows, 378 full batches, 20 chunks per batch, 7,560 optimizer attempts per arm (22,680 total). All fits save fixed epoch 0. The existing stats worker scanned only raw x for that membership, read no labels, excluded the 368 evaluation groups, and bound its output to the exact parent and Parquet hashes.

The frozen scorer compares only `aligned − stale` and `aligned − noop`, with 2,000 paired component-bootstrap replicates (seed 271828). Panels are the 468-group fold-0 panel (374 groups overlap E427 fit; 94 do not), the 368 stats-excluded panel (zero E427 fit overlap), and the 94-group nonfit diagnostic subset. Every panel, model teacher lineage, and campaign-era validation has historical exposure; this is a descriptive mechanism screen, not independent public generalization or a path to claim expected 0.7000 by itself. A future competition deployment also needs a streaming/native implementation and parity against these features; the staged FP32 prediction exporter is only for research scoring and does not modify the submitted/native inference path.
