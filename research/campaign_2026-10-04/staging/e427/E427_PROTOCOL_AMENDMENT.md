# E427 protocol amendment — fixed by root implementation instruction

Date: 2026-10-04. This amendment resolves the implementation choices left open in `E427_IMPLEMENTATION_PROPOSAL.md` before source changes.

The three arms are **aligned**, **stale**, and **no-op**. All start from the exact public E424 seed-3 combo checkpoint `c20261004_combo_s3_final_r1@ep3`, preserve its full model input projection and preprocessing as recorded in the checkpoint (parent `n_in=211`), hidden width 256, two-layer GRU, and 23-output head. The gate is rank 8, attached to the first GRU layer's input only, and only contributes to first-layer update-gate (`z`) preactivations. Its added recurrent columns are initialized to zero. The root checkpoint's recorded dimensions are read and checked at initialization rather than assumed from the 112 raw channels.

Each arm performs one complete continuation epoch and writes a fixed epoch-0 checkpoint. Optimizer recipe is Muon on recurrent matrices (`--optim muon --muon-scope rnn`) and the trainer's ordinary AdamW groups for all other parameters, peak learning rate `0.0001`, weight decay `0.01`, and the trainer's OneCycle schedule. All arms use seed 3, the same sampled fit rows and order, batch 32, chunk 1000, FP16 autocast, EMA teacher decay 0.999 with eval EMA, propensity `prop_v1` (power 2, epsilon 0.03, true-mask epsilon 0.03), distillation teachers `ab67_final_since_s3,ab67_final_since_s4` at alpha 0.5 / bootstrap horizon 8, since-weight 32 / floor 0.25, and the original `wmse` + `--aux-struct 0.3 --aux-next 0.3` objective. No target, future-row, or scored-mask data participates in gate routing.

The stale context at a row is the volume28 vector from the row immediately before the most recent endpoint marker, held through that cycle. Until two endpoint markers have appeared, the stale context is the fixed volume28 training-pool mean computed from exact fit membership without labels. The sampled endpoint window is recorded before fitting. All output/evaluation membership and objective details remain identical across arms. Aligned-minus-stale and aligned-minus-no-op are exploratory paired contrasts on the historical exposed panel; intervals crossing zero remain inconclusive.

A fused two-layer `nn.GRU` is retained. The first-layer input matrix has eight additional columns; structural zeros in reset (`r`) and candidate (`n`) gate rows are enforced after every optimizer-step attempt and audited before every forward. Gradient masking alone is insufficient under Muon and is not relied on for this invariant. The raw parameter tensor count (including constrained coordinates) and effective free-parameter count are reported separately. No fit, export, score, or launch is authorized by this amendment.
