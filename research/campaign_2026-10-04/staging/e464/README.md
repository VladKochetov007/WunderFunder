# E464 complete-architecture head-transfer drafts

This staging tree binds the eight preregistered E424 epoch-3 parents to the incumbent one-epoch head fine-tune procedure. All eight architecture/routing/adapter arms are retained; no parent is selected from its exposed evaluation score.

`python research/campaign_2026-10-04/staging/e464/scripts/build_specs.py` builds eight **unsealed** local-GPU draft specs using only the standard library and `scripts/continuation_recipes.py`. It hashes source files, parent checkpoint bytes, parent provenance, and each existing E424 sealed v2 source spec; it verifies that all 48 parent-fit code files still match those sealed source hashes. It does not import Torch or open training arrays. The drafts point to `run_head_fit.py`, which first loads each actual parent through the frozen root `make_model` factory and checks every named parameter against the architecture-specific freeze contract. It runs `scripts/train_rnn.py` as a subprocess using the helper's `head_args`, replaces only the freeze prefixes, suppresses evaluation, and verifies fixed epoch 0.

Before training, the wrapper fingerprints every state tensor including buffers. After fitting, it requires exact parent equality for every non-head parameter and every buffer, and requires the allowed head tensors to retain their shape and dtype. It also verifies parent bytes remained unchanged, inherits all listed auxiliary settings, requires a 23-output checkpoint, and compares the child validation fit-group set against the parent's exact 1,505 groups. Audit sidecars are written under `audits/` only after the training process is terminal; a failure is retained as `failed_closed` evidence.

Specialist heads are the only trainable parameter families in specialist variants: `universal_head.*` and `expert_heads.*`; the frozen prefixes are `inp,gru,experts,prefix_proj,router`. Adapter arms freeze `inp,gru,adapter_,prefix_prior`, leaving `head.*`. Ordinary GRU controls freeze `inp,gru`, leaving `head.*`. These prefix sets are derived from actual parent architecture and checked against every instantiated parameter name; no generic `inp,gru` shortcut is used for specialists or adapters.

The draft resource cap is one local GPU, 8 CPUs, 24 GiB host RAM, 4.2 GB allocator and 4.8 GB stop, with a 20-minute per-worker timeout. The registered estimate is 0.5–1 GPU-hour for all eight fits and exports; at most 3 GPU-hours may be reserved. Root admission remains required after the E425/E426 and one-GPU queue completes and the cumulative 80-device-GPU-hour budget is reconciled. No fit, prediction, score, or provider action has been launched from this tree.

`tests/test_e464_scope_audit.py` uses synthetic parameter names and byte fingerprints only. It covers specialist and adapter prefix collisions, unknown parameters, head-only mutation allowance, non-head parameter/buffer changes, missing state, and head shape drift. It was not run locally; root may execute these source-only tests before any fit.
