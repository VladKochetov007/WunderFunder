# H096 strict within-fold teacher exposure: preregistration draft

Status: design/source review only. Nothing here is sealed, launched, uploaded, or fitted. Root must seal exact code, data, teacher, propensity, and manifest hashes before admission. This experiment uses the existing H098 ordinary component-crossfit implementation; it does not alter the shared trainer.

## Question and estimand

Does a causal student trained on predictions from an alpha-0 teacher that fitted each row (own-fit exposure) differ from an otherwise identical student trained on predictions from the same two teachers when each teacher predicts only components it excluded (out-of-fit exposure)? The primary contrast is paired fold-0 global weighted Pearson score on the 468 evaluation groups (141 connected components) excluded from all teacher and student fitting. A positive OOF-minus-own delta is evidence consistent with less in-sample teacher-target bias; an interval spanning zero is inconclusive. This is one-fold, one-seed evidence and cannot establish generalization across seeds/folds.

This is narrower than a full lineage comparison: both target caches use exactly the same two alpha-0 checkpoints and cover each fit row once. It changes only which of those two checkpoints predicts each fit component. It does not claim that a single full-pool teacher is equivalent, or that this tests the historical generation-3 teacher ensemble.

## Frozen populations and assignment

Use the existing fold-0 split `research/campaign_2026-09-29/artifacts/splits/fold0.json` (SHA256 `09263ad4fe2b18e2b2f3b79f4562678dce801b067b868134ddc79279f9316a3d`). Its fit pool is 10,535 TRAIN groups plus 1,405 fit-VALID groups (11,940 total); its evaluation set is 468 VALID groups in 141 components. No evaluation component is eligible for either teacher or student training. Preserve the fold manifest's absolute row-group identities and exact split membership.

Freeze two inner component folds using H098 `scripts/privileged_crossfit.py prepare --inner-folds 2 --seed 98`. Components are hashed once and kept intact across TRAIN and fit-VALID. Seed 98 is the existing H098 assignment, chosen before any H096 outcome. Expected counts from the frozen manifest are:

| Component assignment / predicted half | TRAIN | fit-VALID | total | full batch-32 batches/epoch |
|---|---:|---:|---:|---:|
| inner assignment 0 | 5,125 | 683 | 5,808 | 181 |
| inner assignment 1 | 5,410 | 722 | 6,132 | 191 |

`inner0` is fitted on assignment 1 and predicts assignment 0; `inner1` is fitted on assignment 0 and predicts assignment 1. The 324-row (2.71% of fit pool) imbalance is retained rather than outcome-tuned. Each teacher gets four complete epochs; because the existing loader drops incomplete batch-32 tails, they receive 181 vs 191 full batches per epoch and their OneCycle schedules have correspondingly different lengths. This is a small unavoidable component-size/scheduler difference and limits exact teacher-capacity equivalence; record actual update counts and schedule endpoints. Do not pad, duplicate, or drop whole components to make the counts appear equal.

Cache `own` uses `--exposure fitted`: assignment 0 rows are predicted by inner1 (which fitted assignment 0), and assignment 1 rows by inner0. Cache `oof` uses `--exposure excluded`: assignment 0 rows are predicted by inner0, and assignment 1 rows by inner1. Each cache must cover exactly all 11,940 outer-fit rows once across TRAIN+fit-VALID; each must mark the 468 evaluation rows NaN/ineligible. Both use the exact same two checkpoint byte hashes. The cache's value at position t predicts original label y[t]; no row/target shift is allowed.

## Teacher and student procedures

Fit two fresh ordinary causal GRUs from the same initialization seed 3, each using its H098 inner membership. Both are alpha-0 supervised teachers: no privileged inputs, init checkpoint, cached distillation, propensity estimator, or future labels. Use the original 211-input, hidden-256, two-layer GRU and the original 23-output wMSE + `--aux-struct 0.3 --aux-next 0.3` label/objective, batch 32, chunk 1000, four epochs, lr .001, wd .01, Muon with `--muon-scope rnn`, since weighting 32/floor .25, EMA .999/eval-EMA, fixed epoch 3, and `--no-eval-during-fit`. Preserve the original target tables. Teacher predictions are pointwise causal predictions, with the same model checkpoint used for all rows assigned to that teacher.

**Propensity caveat:** the existing H098 `fit-groups-manifest` guard rejects `--propensity`, `--prop-input`, `--distill`, and `--init`. Do not bypass it. Therefore the alpha-0 teachers are fresh label-only teachers without the fold-level propensity model; their fitting weights are not identical to the historical combo student's propensity-weighted main-loss weights. This affects absolute teacher quality but is held fixed across own/OoF caches because the checkpoint pair is identical. A future experiment that gives each half its own propensity fit would test another learned ancestor and requires a separately preregistered protocol; it is outside this contrast.

Fit both students from scratch with seed 3 on the full 11,940-group fold-0 training pool, using identical sampler/optimizer/EMA/objective/source closure. Only the cached target name changes (`h096_own_s3_f0` vs `h096_oof_s3_f0`). Keep the public combo student recipe: TRAIN+fit-VALID, original fold-0 `c20260929_prop_f0` and its row-group-aligned propensity caches, propensity power 2/epsilon .03, `--valid-true-mask .03`, since weighting 32/floor .25, hidden 256/layers 2, batch 32/chunk 1000, four epochs, lr .001/wd .01, seed 3, Muon `rnn`, EMA .999/eval-EMA, `--distill-alpha .5 --distill-boot-h 8`, fixed epoch 3, and no holdout evaluation during fit. Retain the original 23-output auxiliary objective and labels; do not substitute shift/sign heads or transformed targets. The H096 teacher cache replaces the teacher prediction source while preserving the SBD bootstrap horizon, alpha, row targets, and blend rule.

The existing student `--valid-true-mask .03` remains active through the fold-0 propensity model for fit-VALID rows only. Evaluation labels and evaluation masks are not used by fitting, teacher generation, or checkpoint selection. The student training normalizer is fit from the same full fit pool in both arms. Teacher normalizers are separately fit on each teacher's actual fit membership and are recorded; do not pool the halves or inherit a full-pool normalization.

## Provenance, evaluation, and decision rule

Bind the fold manifest, both inner manifests, component identities, source closure, target parquet/NPZs, chain caches, prop checkpoint/cache, teacher checkpoints, crossfit cache arrays/sidecars, student checkpoints, and fixed epoch-3 all-VALID FP32 prediction arrays/sidecars by SHA256. Validate cache sidecars before student fitting: exposure label; checkpoint hashes; exact row-map hashes; eligible groups equal outer fit membership; exact once-only coverage; NaN outside fit pool; origin alignment. Reject TRAIN group 528 and require absolute-group handling so group 529 retains its correct propensity-cache index.

Export each student's epoch-3 EMA model in FP32, resetting recurrent state at the start of each sequence and streaming/chunking without changing predictions. The exporter may write all 1,873 VALID groups for later inspection, but the primary paired score must select only the frozen 468 evaluation groups. Use official `global_wp_clip2_v1`, the official `need_prediction AND is_scored` mask, and paired component bootstrap over the 141 evaluation components (2,000 resamples, seed 271828). Report point delta (OOF minus own), 95% component-bootstrap interval, both arm scores, class-wise deltas, and exact scored-row/component counts. Full-VALID score is descriptive only because 1,405 VALID groups were in fit. Teacher scores on the excluded evaluation components may be reported as post-fit diagnostics only; they cannot select checkpoints or alter the student procedure.

**Falsifier / interpretation:** no OOF advantage with a paired interval entirely at or below zero argues against this mechanism for this recipe; an interval spanning zero is inconclusive; an OOF gain is suggestive, not replicated evidence. A large teacher arm score difference on evaluation is a warning that the two half-teacher identities/fit populations dominate the student contrast, even though the cache design keeps the same pair and one teacher per row in each arm. Report teacher-by-assignment diagnostics and actual optimizer updates so that risk remains visible.

## Cost and gates

One observed ordinary fold-0 four-epoch combo fit took 2,572.4 s (`c20261003_combo_s3_f0`). The two half-teacher fits combined process approximately one full fit-pool's rows per epoch; the two student fits add two full fit-pool runs. Budget roughly three ordinary-fit equivalents (about 2.15 GPU-hours of fitting at that observed rate), plus two cache extractions, two prediction exports, and scoring; reserve 2.5–3.5 GPU-hours total on comparable hardware. This is an estimate, not a resource measurement. Bounded CPU work for manifest/provenance checks and scoring should remain below 10 minutes and 2 GiB; the actual trainer CPU fixtures already cover the H098 path, but do not replace the full production fit. Use the campaign's standard per-run resource cap and stop conditions; do not overlap these fits with another GPU job.
