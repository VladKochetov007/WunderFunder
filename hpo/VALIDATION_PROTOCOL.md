# Validation protocol: how much to trust fold 0/1, how the teammate selects, and what we do instead

Status 2026-10-10. Evidence: `hpo/evidence/scratch_effects_fold1.json` (47 scratch models on fold 1, generated by
`scripts/evidence_report.py`), the 28-recipe fold1-vs-fold0 comparison, the teammate's log
(`research/iterations/2026-10-02-slow-fast/README.md` on `origin/research/creative-iteration-20260930`), the public table.

## 1. What the data says about single-fold evidence

Measured on fold 1 (468 evaluation sequences, 4 default-recipe baseline runs, official WP):

| Quantity | Value |
|---|---|
| Baseline mean (default scratch recipe, 4 seeds) | 0.66642 |
| Seed-to-seed training noise (sd of baseline runs) | 0.00106 |
| Evaluation-unit noise of a model-vs-model difference (paired component bootstrap sd, median) | 0.0018 |
| Total sd of one A/B comparison (one run each, one fold) | 0.0022 -> 95% interval about +-0.0043 |
| Spread of true effects across everything we varied (empirical Bayes) | 0.0015 |
| Recipe-specific fold1-vs-fold0 deviation (28 recipes) | sd 0.0016; level shift +0.0131; Pearson 0.81, Spearman 0.73 |
| Public vs local rank (4 matched recipes) | Spearman 1.0 (n=4: indicative only) |

Consequences:
- Of the 43 changed recipes, only six have an interval that excludes zero, and all six are *harmful*: 6 epochs (-0.017), 8 epochs + EMA (-0.036),
  the `corr` loss (diverged), Huber (-0.009), TCN (-0.007), Muon x6 (-0.0055).
- No positive lever is distinguishable from noise. After shrinkage (true-effect sd 0.0015 vs measurement sd 0.0024, shrink factor about 0.4) the best raw
  effect (+0.0028) is about +0.0006. Our earlier ranking of small levers (width, gated, dropout, schedules) was mostly noise.
- Muon x3 (-0.0015) and x6 (-0.0055) did not reproduce the teammate's multiplier gain.
- Fold 0/1 are fine for **rejecting disasters and for large effects (> 0.005)**. They are not fit for ranking small levers.

Minimum detectable effect (80% power, two-sided 5%), using the sds above (eval noise falls like 1/sqrt(folds), seed noise like 1/sqrt(seeds)):

| Folds per arm | Seeds per arm | sd of the difference | Detectable effect |
|---|---|---|---|
| 1 | 1 | 0.0023 | 0.0064 |
| 2 | 1 | 0.0019 | 0.0053 |
| 4 | 1 | 0.0017 | 0.0047 |
| 4 | 2 | 0.0012 | 0.0034 |
| 4 | 3 | 0.0010 | 0.0028 |

So a +0.002 lever needs about 4 folds x 3 seeds per arm (and as many control runs). Seeds matter for *measurement*, not for the search space.

## 2. Other threats to fold-0/1 evidence

- **Exposure**: folds 0 and 1 have supported hundreds of selection decisions (many screens, banks, blends). Anything chosen on them is optimistic.
- **Distribution shift to the test set**: the test is harder than valid, with the loss concentrated in class 3 (teammate probes: classes 0-2 lose 0.005, class 3 loses 0.024).
- **Size**: 468 sequences per fold; class 3 about 160 of them.
- **Fold difficulty**: fold 0 is 0.013 easier; mixing folds without adjustment biases comparisons toward trials that happened to run on easier folds.
- **Training sets differ per fold** (each fold trains on the other folds' valid data).
- Folds 2 and 3 have been used only in small screens: they are the least exposed data we have.

## 3. How the teammate selects (from his log) and what is good or weak about it

1. Many small screens (h128, folds 0 and 1) then promotion to d256; **seed calibration** (4 seeds: sd 0.0012 under Muon, so single deltas below 0.002 are noise; later >= 2 seeds per arm).
2. **Composite validation**: parents trained on half of train plus valid folds != 0; evaluation on valid fold 0 (true scoring mask) **and** held-out train half (propensity-estimated mask);
   accept only if neither domain is negative (5/5 signs matched public deltas for 5 calibration arms, magnitudes inflated; the valid fold alone missed one sign, the train-holdout alone another).
3. **Nested simulations** for pipeline questions (valid bagging on pseudo-test folds 3 and 2).
4. **Public board as an instrument**: probe submissions (class-3 zeroed, class-3 only, class-3 scaled) measured the test composition (class-3 weight share about 0.556) and refuted a recalibration idea.
5. **Oracle ceilings** to bound ideas (level oracle, state-only lookup).
6. Honest corrections: Muon Q-weighting "+0.0013" failed replication; composite blend gains overstated public gains (+0.0008 local, none public).

Strong: two domains with a veto rule, seed calibration, probes. Weak: still two exposed valid folds, no formal intervals, public calibration from five points,
train-holdout needs separate model fits (so it is used late and rarely).

Ours so far: folds 0/1 with matched controls (good), closed-form blend theory (good), but single-run deltas treated as rankings (the weak part this report exposes).

## 4. Protocol going forward (exposure-aware tiers)

| Tier | Data | Used for | Rule |
|---|---|---|---|
| T0 screen | fold 1, 1 run | kill disasters (effect < -0.005) and big-axis choices (epochs, loss family, optimizer family, architecture family) | no ranking inside +-0.004 |
| T1 dev | folds 1 and 0, fold-difficulty adjusted, paired against a control run with the same seed | search objective (HPO racing) | report delta with interval; shrink before comparing |
| T2 confirm | **folds 2 and 3, reserved**: one evaluation per finalist, no feedback into the search (`orchestrator confirm --k 5`) | unbiased estimate for the top candidates | pre-registered: confirm if mean delta over folds 2,3 >= 0 and class-3 delta >= 0 |
| T3 veto | train-holdout composite (teammate's second domain) for the top 3 only | block candidates that win only on valid | neither domain negative |
| T4 public | >= 2 packages per lineage decision | lineage-level only (public seed spread inside a lineage was 0.0002) | never rank sub-0.0005 differences |

System level: judge blends and students by out-of-fold predictions over all four folds (1,873 sequences) where possible; this cuts evaluation noise by 2x
and is the quantity that is eventually submitted. Component-bootstrap intervals accompany every reported difference.

Decision rules: adopt a lever if the shrunk mean effect over T1 and T2 is >= +0.001 and the T2 interval lower bound is above -0.001; stop an arm when its
posterior probability of a +0.001 effect falls below 10%; replicate with a second seed only when the first interval overlaps the decision threshold.

## 5. What changed in the optimizer because of this

Search folds are {1, 0} only; folds {2, 3} are confirmation-only. The objective is the mean of fold-difficulty-adjusted scores (offset estimated from trials that have both folds, prior 0.0131).
The space dropped the options the evidence closed (epochs above 5, `corr`/Huber, TCN, widths above 384, Muon multiplier above 2, LR extremes).
Single-fold noise means the search can find *regions* (epochs 2-4, loss family, width, schedule family) but not resolve fine continuous tuning; the finalists carry the decision.
