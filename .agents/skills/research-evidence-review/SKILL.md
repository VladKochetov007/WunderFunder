# Independent research evidence review

Start from the declared claim/comparison and original artifacts. Separate the user objective, observed effect and proposed explanation. Do not inherit actor conclusions as facts. Read only relevant sources; agent independence does not make evaluation data statistically independent.

Check:

- What actually ran: commands, exact code/data/checkpoint/prediction identities, exit status, phase logs and terminal outputs. Code/test/profile success does not imply a fitted model or scored submission.
- Candidate/reference comparability: data membership, teacher/initializer ancestors, propensity sources, seeds, optimizer/update budget, checkpoint rule, metric/mask and fixed blend. Account for differing training cohorts or model selection.
- Leakage and exposure: all known fitted/inspected units, related-group overlap and descendant exposure. Repartitioning or a new agent does not restore fresh confirmation.
- Uncertainty and selection: conditional fixed-prediction bootstrap versus training variability/public transfer; complete attempted set, adaptive slices/blends and prospective confirmation status.
- Claim-to-deliverable gap: teacher versus student gain, standalone versus ensemble contribution, proxy versus official metric, toy case versus actual shape, float model versus delivered serving package.

Use the empirical-validation reference in `conduct-creative-research` when making statistical/promotion claims. Reproduce decisive calculations or counterexamples with bounded checks when authorized. Do not demand a genuinely untouched holdout when none exists; label exposed discovery honestly and define the next useful confirmation.

Return confirmed bugs separately from uncertainty, preferences and deferred checks. Each finding names supporting/contradicting artifacts, its consequence and a useful resolution. Classify unrun or infrastructure-censored attempts separately from negative science. A weak standalone recipe may still justify a declared combination test. Do not predict a public gain by adding a local delta.

If no blocking finding remains, state precisely what evidence was checked and which claim it supports. Never call an actor's own review independent, treat majority agreement as validation, or claim scientific replication from replaying fixed predictions alone.
