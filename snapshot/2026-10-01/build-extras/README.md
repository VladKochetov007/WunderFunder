# Research interpreter build binaries

These two C++ extension builds target Python 3.13 on Linux (v2 and v3 CPU variants). They are the only additional experiment-related binaries found outside the archived artifact trees. They were copied without rebuilding and are supplemental to the immutable tar.zst shards. The Python 3.11 submission builds are already preserved in all six scored candidate ZIP files, with exact byte matches checked during the completeness audit.

Check this directory with `sha256sum -c SHA256SUMS`. Original paths, sizes and modification times are recorded in `inventory.json`. Rebuild sources are in the archived cpp-engine source snapshot.
