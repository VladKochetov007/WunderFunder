Leaderboard: GRU (2 epochs, train+valid) 0.6548; blend 0.5 GRU + 0.5 organizer baseline x0.25 = 0.6569
(best); top of LB 0.6651. Validation (full, global WP): baseline x0.25 0.6728, GRU e2 0.6799, blend 0.6817.
Validation overstates test by ~0.02; a "softened mask" metric (unscored rows weight 0.02) tracks LB.

What failed / saturated (evidence in research/experiments.jsonl E-080..E-092):
- GRU recipe saturated at devB 0.671-0.672: 3 epochs, width 192, lr 2e-3, LSTM, depth 1/3, longer TBPTT
  chunks all within seed noise (~0.0014). Two epochs was the only clear gain (+0.004).
- 114 causal heuristic features (event recency/rates, EMA deviations, depth sums, trade flow, i1
  cross, a-column transforms): zero linear lift on GRU residuals; zero gain as extra GRU inputs.
  Nonlinear (GBM) residual correction: +0.004 class 0, +0.002 class 1, -0.034 class 3 (overfits).
- Online per-sequence recalibration from rebuilt labels hurts.
- Class-3 next-move direction far from a move: AUC 0.62-0.70 from snapshots (volumes via ICA
  included); near moves 0.96-0.99 (bounce mechanics).
What worked:
- Blending with a different model (organizer baseline) +0.002 LB; two GRU seeds averaged +0.0014 valid.
- Symbolic regression finds transferable residual terms (corr ~0.11) in classes 0/1, e.g.
  min(v9,0) - tanh(trade-volume EMA16); trade-volume flow appears in all small-tick classes.
Decoded semantics: a6 = real time since last i0 book change; a5 = since last trade; a2/a3 = book-event
intensities; is_scored depends on a3, i1 activity, a5, book state (symreg corr 0.34).
Open questions: time order / adjacency of sequences (unknown), train-vs-test shift, how to validate so
that validation ranks models like the hidden test does.

## Update 04:00

  (median 3, max 33); targets identical across 92% of links; train and valid are blocks cut from the same
  streams (90 links cross train<->valid). seq_ix/file order carry no time. Rules forbid carrying state
  across sequences at test time. Old dev halves leak chain neighbours; decisions now use 4 chain-grouped
  folds (scripts/decide.py). E-095.

  feature-only per-sequence statistics (volume-code levels, i1 volume stats, a5/a6/a7). Different
  instruments/regimes; the test probably differs again. E-094.

  GRU hurts (-0.0010); it only helps the weaker baseline. E-093.

## Update 07:40

  passes all chain folds; + aux head predicting rows-to/sign-of the next target change: +0.0030 total
  (0.6829 vs 0.6799). Distillation from a 3-model ensemble adds little on top. Class-mass matching adds
  nothing beyond the floor. Label-aware mask model: only +0.002 AUC (mask barely depends on labels).
- prop_v1 over-predicts class-3 scoring 1.42x; p^2 puts 60% of loss weight on class 3 vs true 48%.

  flow in all classes; book-shape codes in classes 0/1; queue imbalance in class 3; i1 trades in class 2.

## Update 08:35
- Stress panel (2/3 least train-like valid sequences per class, softened mask lambda 0.05) orders all 3
  known LB comparisons correctly; used as a robustness check (E-110).
- Best train-only recipe: propensity floor + next-change aux head (full valid 0.6829, +0.0046 over the
  2-epoch baseline recipe on the stress panel). Blend 0.7 GRU + 0.3 organizer baseline x0.25 is optimal.
- Diversity is the bottleneck: our GRU variants have residual corr 0.99+ with each other; the organizer
  baseline 0.956. Alternative members (plain-weighted GRU, correlation-loss GRU, GBM, raw-input-view GRU)
  add <= +0.0007 or subtract; a 3rd member adds +0.0002. The baseline's value is not explained by its raw
  input view alone.
- Refuted this morning: distillation in the final fit, weight soups, online normalization, price-impact
  split trade flows, per-class offsets, class-mass weights. Mask explanations: class-specific activity/book
  state (class 3 a3 AUC 0.83), not a pure real-time sampling grid.
