# Findings, 2026-09-15

Evidence ids refer to `experiments.jsonl`; hypothesis ids to `hypotheses.jsonl`.

## What the data is

- Rows are book snapshots of two instruments. Targets change only on rows where
  the i0 bid and ask price columns both update (H-001), so targets live on an
  event clock while predictions are required on every row.
- Every sequence belongs to one of four market classes, identified by the
  target quantum (H-002). Class 3 is large-tick: about eight distinct book
  states per sequence, bid/ask bounce bursts, long quiet stretches.
- Price columns are relative encodings, not price levels: raw `p0` future
  changes are uncorrelated with targets (E-015). Column groups move with
  consistent signs, so levels can be partially rebuilt from signed differences.
- Train and validation have different class mixes: classes 0/1 are 24% of
  train and 40% of validation (E-024). Validation is likely a different period.

## What the targets are

- In class 3 the target moves at an event mostly by minus the price move
  (R^2 0.90, E-019), which looks like anchor minus current price. But the large
  jumps that dominate |y|-weighted scored rows exceed the price move and are
  anchor changes, i.e. future information (E-021, research/visual/02).
- Class-3 scored rows sit far from the next break (E-016), where the break
  direction is close to unpredictable (AUC 0.55-0.60 beyond 20 rows, E-013,
  E-014). An oracle with perfect near-break knowledge only reaches class-3 WP
  0.42 at 20 rows (E-018).

## What did not work (all logged as refuted)

Event-lag state features (H-008), snapshot queue imbalance (H-010), in-context
Markov transitions (H-011), mask proximity to breaks (H-012), i1 lead-lag
(H-013), a0-a7 (E-025), level deviation from an EMA equilibrium (H-016),
pure correlation loss (H-018), dense native speedups beyond FLOP bounds
(H-005, H-017).

## What works so far

GRU 256x2 on raw plus causal event features with a corr + weighted-MSE loss:
0.596-0.604 on dev600 (E-006, E-007, E-023). By class roughly 0.76-0.80 / 0.73-0.75
/ 0.65-0.69 / 0.37-0.40.

## Goal arithmetic

With validation class shares 21/19/23/37%, overall 0.80 requires class 3 near
0.70 or classes 0-2 near 1.0. Current evidence caps class 3 near 0.45-0.50, so
0.80 is not supported by any information source found so far.
