# Class-3 future-path label denoising: CPU gate

The next candidate keeps the existing point-prediction GRU and native inference.
For training only, condition the approximate four-event class-3 payoff law on
the first future decoded book move. A train-fitted first-order kernel integrates
the remaining three moves. Its two clipped-label moments are
`m1 = E[|y| | first move]` and `m2 = E[|y|y | first move]` for each target. A
future training label can reduce realization noise, but the kernel may bias the
causal conditional expectation. The CPU screen must measure both effects.

## Locked screen

- Fit a 17-state transition kernel for class-3 midpoint increments in half
  ticks, retaining transitions within [-8, 8], on 200 train sequences selected
  with seed 41. Rows whose observed first move is outside support are ineligible.
  Use the already train-fitted price-code decoder. Add 0.5 pseudo-count to
  each transition. Enumerate the next three event moves under this kernel and
  apply the existing four-event midpoint/stop-out law; clip both targets to
  [-2, 2] before calculating moments.
- Check all class-3 scored rows on the two pure development folds. Reference
  the frozen seed-3-since plus seed-4 pair. Do not use validation targets to
  fit the kernel.
- Eligible scored target weight must cover at least 60% of class-3 target
  weight in each fold. On eligible rows, the weighted residual MSE of the
  pseudo target versus realized target must be at most 70% of the frozen
  pair's weighted residual MSE. The weighted covariance between the frozen
  pair and the pseudo target may differ from its covariance with the actual
  target by at most 5%; estimated weight mass may differ by at most 5%.
  Apply the thresholds to both outputs in both folds.
- Only if all gates pass, mix the new moments into 25% of the class-3 wMSE
  loss and run one matched seed-3 fold-0 GRU. Promote only on the existing
  exact-mask pure-chain pair gate (+0.0005); then check fold 1 and untouched
  folds before final fitting.

The first future event and later paths remain unavailable at serving time.
The screen tests a training-label transformation, not a live lookahead model.

## Result

The 200-sequence train-only Markov kernel finished in a CPU-only run. On all
273 pure class-3 validation sequences, coverage was 99.0-99.5% of scored
target weight and the hindsight residual MSE ratio was 0.50-0.54. However,
the pseudo weight mass exceeded actual mass by 23-25%, and the covariance
with the frozen pair was 64-68% below the actual weighted covariance. Both
folds and both outputs fail the locked 5% bias limits by a wide margin.
See `artifacts/rb_class3_screen.json` for every target and fold.

**Reject this Markov-kernel label transformation.** The apparent variance
reduction comes with a large change to the conditional target. No GPU arm,
native inference work, or submission follows from it.
